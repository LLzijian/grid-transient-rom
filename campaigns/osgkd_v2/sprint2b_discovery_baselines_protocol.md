# Sprint 2B · 有效结构发现与同合同基线

本协议冻结拟议比较、侧信息和统计口径。当前阶段交付实现和秒级合成资格。正式作业依赖 Sprint 2A 的四个固定末点、Table 1 及独立复核。三个图种子各保留一个父点和完整的来源身份。[架构简报](../../designs/osgkd_v2_discovery_preparation_20261125.md) · [Sprint 2A](sprint2a_spectral_matched_protocol.md)

## A · 三种子功能贡献与重拟合

分别对三个图父点，用完整 `train` 上最长 8 s 的自主轨迹计算同状态贡献。每条样本按真实可用时长的梯形积分取时间均值，再等权平均 385 条。状态导数用相角 1、冻结速度尺度和隐初态界 4/2/4 归一。全向量场均方作用为分母。逐边按基准与调制相加后的向量场贡献排序，并用节点对字典序打平。对两个静态环境幅值项，分别在 $C_g<0.0002$ 时封锁。阈值在结果前给定，贡献为有交叉项的同状态比值，结构必要性由配对重拟合判断。[功能分解](../../experiments/osgkd_v2_p2a_post_audit_20261124/contributions.py)

| 方案 | 封锁范围 |
| --- | --- |
| 完整、静态项剪除 | 同一个父点重启 Adam。静态项方案对满足去除条件的一次或二次环境幅值项施加精确零掩码 |
| Top-30、Top-20、Top-12 | 在同一排序下取嵌套支撑，应用静态项规则，同时封锁删边的 $c$、$\beta$ 与边上的五类幅值、记忆和环境系数 |
| 删动态调制 | 固定 $\beta=0$，保留幅值经其余路径起作用的可能 |
| 删环境记忆 | $e$ 初值、RHS、直接读出和驱动掩为零。保留其他允许的环境项 |
| 删内部耦合 | $c=\beta=0$，保留允许的幅值与环境边特征 |
| 冻结机械动态 | $\dot p=0$，保留从历史估计的 $p_0$ 和常量机械读出 |

每个方案独立从同种子父点开始。重拟合使用固定顺序的末 128 批，完整 `train` 385 条均覆盖。使用 8 s 数据目标、末 128 段的余弦学习率和裁剪 5。全部方案在该短程比较中统一采用数据目标，便于冻结或删除状态后的有效子空间仍服从同一损失。原模型 8 s 训练中的谱铰链和对应来源继续记录。启训资格比较共同的粗细步长，细步长须有限，正式比较采用四组已有同一网格。连续 3 次或累计 16 次非有限拒绝停止。若拟追加适配，须在读取本轮 `val` 前记录与完整参照相同的额外预算。[流水线](../../experiments/osgkd_v2_discovery/prepare.py) · [精确掩码](../../src/kiki/models/osgkd_restricted.py)

四个固定源点的训练和本轮候选分别留存。末点评分沿用原始 `val` 双步长（0.005/0.0025 s），报告稳定风险、误报 `/95`、自主失稳召回 `/12` 与 `/22`、真实区间风险和触发滞后。Pareto 表使用有效边路径、模块数、活动参数、稳定 8 s 风险、误报和召回。三个随机种子报告逐组值和均值±样本标准差。用末点 $c>0$ 的交换支撑按同一节点对计算所有种子两两 Jaccard 与集合一致性 F1，双空标未定义。支撑一致性属于重复性证据。所有方案另记录实际维数、包含闲置坐标的积分维数、成本和数值覆盖。

## B · 同一运动信息下的机制对照

从头训练开放图模型和两个机制参照的同种子 `24111`。两种参照用完全相同的 1,928 参数图编码器及初始权重、11 点相角与完整转速历史、4/2/4 初态界。沿用 Sprint 2A 的 512×2 s、384×4 s、1,152×8 s，`train` 每批 7 稳定+1 失稳，分段运动目标、0.1 端口、0.01 隐态一致性、两组学习率、余弦与裁剪。共享 8 s 局部铰链，记录局部谱及其工作量。首批与两次变更时域的双步长梯度资格沿用原协议。每组只评价第 2048 次。[共同训练实现](../../experiments/osgkd_v2_sprint2a_20261125/train.py) · [基线入口](../../experiments/osgkd_v2_discovery/prepare.py)

- **等变图 Neural ODE。** 671 个动力学参数通过共享有向消息和节点函数学习两个转矩读出及三个隐态导数。两个转矩均进入同一惯性平衡。已知运动学与冻结惯量、阻尼共用，通用网络具有完整非零和读出自由度。共同角不变、节点置换等变、参考零点按单位测试核对。
- **封闭被动 Kuramoto。** 学习 K10 的 45 个非负静态边系数，势为 $U=\sum_e c_e[1-\cos(\varphi_e-\eta_e)]$，$Ḣ=-\omega^\top D\omega\le0$。共同 5N 积分接口含三个零初值且独立衰减的闲置块，有效动力学为 2N。共享编码器的隐态读出对预测的有效参数量为零。端口监督保留，机械与环境读出为零。该比较检验净交换及隐态闭合在同信息预测中的作用。[基线实现](../../src/kiki/models/osgkd_baselines.py)

真实 `train`/`val`、重拟合和训练的执行由后续登记释放。新 FOM 为 0，`test` 关闭。准备阶段生成的合成断言属于工程资格。
