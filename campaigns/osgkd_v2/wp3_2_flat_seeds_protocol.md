- 从头调用 Sprint 2A 的 train.new_model(constants, 'flat', seed) 与原优化器，编码器 6,144 参，ODE 680 参，50 维。完整 train 385 条、每批 7 条稳定及 1 条失稳，重建计划须与冻结 SHA256 b11463b14f01ed1c26f60b6227f7ce0072a90d5f465e61593fbc056878e8ae55 完全一致。沿用原常数、观测、隐态初始化界和物理初值。
- CPU float64、一个 Torch 线程、共享 Python 3.12、0.01 s RK4 内步长、2,048 次尝试。课程为 512×2 s、384×4 s、1,152×8 s。分段运动均值权重 0.4/0.3/0.3，端口 0.1，隐态一致性 0.01。空 Adam，编码器/ODE 基率 0.001/0.0003，余弦由 1 倍至 0.15 倍，总梯度裁剪 5。第 897 次起应用原谱铰链 $0.05\max(0,\alpha+0.05)^2$。
- 两个起点各用共同首个完整批次和独立子进程，做 8 s、0.01/0.005 s 双步长零更新资格，计子进程峰值 RSS。共同粗网格是匹配比较的一部分。任一资格失败记录停止证据。每组第 513、897 次前，一稳一失按原阈值复核。细步非有限、粗网格失格、连续 3 或累计 16 次非有限拒绝，以及模型或 Adam 更新后不有限，按原规则停止并保存回执。有效端点为 2,048 次尝试、至少接受 2,033 次。
- 使用 Sprint 2B-1 的 Windows 常驻顺序机制，每个任务是独立子进程。训练顺序为 flat_24121、flat_24131，前一组有效封存且正常退出才释放下一组。最大训练并发为 1。每 64 次及固定末点保存模型、Adam、随机数状态、已封存批次、门禁与资源计时。技术中断后按相同来源、批次和检查点恢复，核对已保存尾段的科学字段。全程 test 轨迹零访问，新 FOM 为 0，default none。
