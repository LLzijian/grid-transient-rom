# GFTD 初始化数值资格：固定状态辨别与有界修正

本轮回答：Run 3 的资格损失主要来自 RK4 对冻结 ODE 的离散误差，还是当前参数与因果初始化形成的难以延拓状态；据此测试一个最小修正。先保持同一参数、同一初态，再改变数值方法或初始化流程，避免把不同原因混在一起。

这是既有 GFTD Campaign 下的新 `discrimination + adaptation` Run，父 Run 为 `gftd_fit297_20261107`，架构引用 `designs/gftd_repair_design_20261107.md`。用户已授权诊断并按证据改进。本协议在新科学计算前冻结；root 的释放记录绑定本文件、执行源码、模型与输入哈希。Scientist 的实际调用身份由宿主回执记录，未返回的服务端模型名写 null。

## 1. 固定对象与判断范围

- 两个冻结 50 维 ODE、全部共享参数和尺度保持不变。本轮不重新拟合 K、beta、耗散、记忆或功率参数。
- train fit297 原分母为每模型 297（267 稳定、30 失稳）。原结果 static 46/297、modulated 1/297 合格，547 项未通过、14 项 exp 溢出；原结果与已关闭预算不改。
- 部署仍为 11 点、100 ms 的 δ/ω 历史、末点真实 p 和冻结常数。诊断积分只调用模型 RHS，不读未来真值、故障身份或未来高阶量；事件 ID 只作文件对齐。原 val/test 关闭、新 FOM=0、TASK4 暂停、default none。
- 父模型文件位于 `private_data/gftd_fit297_20261107/`：static SHA256 `97714cfed13b4e243924d87a6de7590f76bd7fded68c4322d22d4f907fa4c032`；modulated SHA256 `86adef0b5db08f56594ebbd4b78924e6b9fb43e7aa2c47f1d8fc91baec1ea7a5`。初始化索引为 `resume01/all_initializations_frozen.json`，SHA256 `64836dd3357bae7153deb0e11a84d9eab9d17f5745d649e060efb36c4fefde35`。路径迁移只接受字节一致映射。
- 恢复保存的 `best.state`，不得为恢复失败状态重新优化。stage1 阻断取 stage1 点；stage2 后失败取实际被选择的 stage2 点；成功取原返回点。另保留 5 个“stage1 合格、stage2 失格”事件的两端状态。状态缺失记 missing，不用零或新解替换。
- 本轮估计对象是数值资格及其原因、修正后覆盖与历史目标变化；不重新计算总体 L1、L2 或 L3。连续参考正常不等于预测正确，参考求解失败不等于证明连续解爆破。

## 2. 先用确定性小集合辨别原因

只依据旧诊断分组，不依据新计算选例。各模型按以下优先顺序分成互斥组：stage2 失格、exp 异常、历史门失败、未来 RMS 与 peak 同时失败、仅未来 RMS 失败、成功。每组按原事件顺序取至多 4 个均匀位置 `floor(j*n/m), j=0..m-1, m=min(4,n)`；再并入全部 14 个 exp 异常、全部 5 个 stage2 失格及其 stage1 对照。去重后最多 80 个状态；运行前保存清单与哈希。未抽中的事件仍留在全体表中，诊断类别为 unknown，不能将分层样本比例当总体比例。

每个状态执行以下配对，初态字节相同、float64、观测比较网格固定为 0.01 s：

1. 未来 [0,1] s：RK4 步长 0.01、0.005、0.0025、0.00125 s。历史 [-0.1,0] s：从末点反向积分，步长 0.0025、0.00125、0.000625、0.0003125 s。每个历史轨迹起点再以同一步长正向回到末点，保留全状态往返误差。更细步长仅作诊断，不作为原门的通过结果。
2. 连续参考分别积分历史和未来：Radau 的 `(rtol,atol)=(1e-9,1e-11)` 与 `(1e-11,1e-13)`，加 DOP853 自适应参考 `(1e-11,1e-13)`；`max_step` 历史 0.00125、未来 0.005 s。每次积分最多 20000 次 RHS 调用，达到上限记 reference_unresolved；不增加墙钟或进程配额。容差不能代替实际交叉一致性。
3. 以原 `core.observations` 的相角质心去除、完整转速和除以 0.1 的尺度计算差异。参考合格要求两档 Radau 与 DOP853 两两相差：历史 RMS≤1e-8；未来 RMS≤1e-6 且 peak≤1e-5。另报全状态分量差异与 p/a/r 范围，防止观测投影隐藏隐变量误差。
4. 对相邻 RK4 网格报告 RMS、peak 和 `log2(E_h/E_h/2)`；差异≤1e-12 时阶数写 floor_limited。报告最细 RK4 与参考之差。若参考合格、细网格误差下降且两个可计算阶数均在 [2.5,6]，或最细两级已达上述参考一致性阈值，则归为“已证实存在离散误差解释”。是否完全解释原失败仍逐门报告，不合并历史和未来结论。
5. 在参考可得的 t=-0.1、0、0.1、0.5、1 s 记录状态、RHS、指数 `gamma_i*a_i+gamma_j*a_j`、幅值梯度、H 与功率平衡。指数异常另保存首次异常之前的已接受状态与首个失败RK子步；分别列出活跃/非活跃调制边的指数、中心化势能psi的符号及beta*psi。有限差分 Jacobian 使用相对扰动 1e-5 与 5e-6，比较谱稳定性，报告负实部模态的 RK4 稳定多项式 `|1+z+z²/2+z³/6+z⁴/24|` 在原步长下是否超过 1。只把稳定谱支持的快衰减模态称为刚性证据；高频精度不足、局部正实部增长、非线性指数放大分别记录。

同一状态在更细 RK4 与两个参考方法中持续大幅增长，可支持“此状态存在连续动力学增长”；求解失败、局部正特征值或 exp 溢出单独不足以证明有限时爆破。参考之间不一致则保留未决。历史反向不适定与未来正向问题分开统计。

源码还存在一个待验证的求值疑点：非活跃调制边仍计算exp。允许至多4个无FOM的人工恒等式用例，检查全部调制关闭、部分关闭、大幅值的非活跃边及正常活跃边。若证实零系数项引发无意义溢出，可对该数学恒等变换作一次工程修复，确保H、全部梯度与RHS一致跳过确实为零的项，并冻结修复源码。真实14例是否受影响必须由上述失败子步证据逐例判断；活跃边上的beta*psi<0仍可能驱动幅值增长，不能用零项修复或H耗散保证全局有界。修复前后配对限于原14例，计入诊断工作量；不得夹断任何活跃指数或改变势能。

## 3. 按诊断选择一个修正分支

分支选择按模型分别判断，最终采用同一候选算法统一验证两模型；不为单个事件选择求解器。修正前登记小集合上的类别计数及触发依据。

### A. 精度解释成立：固定步长八阶积分候选

如果旧失败状态中至少一个获得合格连续参考及上述 RK4 收敛证据，先在这些冻结状态上测试固定步长 DOP853 的八阶主公式。冻结 SciPy 中该公式的系数与来源；不启用自适应控制、不增加隐藏子步、不使用密集输出替代固定网格。记录实际 stage/RHS 次数，不把一个八阶步等同一个 RK4 步的成本。

实际主/细步长仍严格为未来 0.01/0.005 s、历史 0.0025/0.00125 s，原六门不变：两个全状态往返 scaled max≤1e-7、历史观测 RMS≤1e-7、未来观测 RMS≤1e-5、未来 peak≤1e-4、末点 p 误差=0。新的方法标为 `fixed_dp8`；旧 RK4 结果仍标为 `rk4_run3`。这改变新 Run 的数值实现，不改变 ODE、部署信息、时域或门槛；不能写成旧 RK4 合同新增通过。

固定状态小试须使至少一个旧失败变为合格，且小集合原成功点不失格，才继续在对应小集合的独立观测包上运行完整两阶段初始化。完整流程从原零起点开始，history residual、往返、未来资格和后续预测统一使用 `fixed_dp8`；不混用 RK4 拟合初态与八阶返回点冒充完整算法。每包保留原 simple 600、smooth 1200 次残差上限与终止条件。小试若至少新增一个完整合格输出且原成功包不失格，进入第4节。

如果固定状态改善但完整初始化不改善，说明数值方法与历史推断的相互作用尚未解决；停止此分支，不继续调容差或更换高阶公式。精度证据仍保留。

### B. 先行资格门或状态选择有证据：初始化流程候选

仅在 A 未进入全体验证，且观察到合格 stage1 被 stage2 替换后失格，或 modulated 的 a=0 stage1 不合格但历史可正常求解时，测试一个明确流程变更：保持 RK4、参数、合法变量边界和目标不变，对 stage1 未过门但存在有限历史最优点的 modulated 包允许一次原 smooth 尝试；最终只在原六门合格的 stage1/smooth 点中按原历史目标取优。对原已合格 stage1，smooth 失格时保留 stage1。static 的 simple 与 smooth 在 sigma=0 下变量相同，不重做无新增自由度的优化。

此分支不放宽最终数值资格，不以未来真值约束初始化，不更改幅值/记忆边界，也不夹断 exp。每包最多一次 smooth、1200 残差，保留原损失、KKT/终止状态与旧合格点。先在诊断小集合尝试；若至少新增一个合格输出且原成功点不失格，按统一规则验证全体；否则停止。所有新输出属于新 Run，原 5 项失败不能事后改成原成功。

若两个分支均无证据支持或小试均无效，本轮完成诊断并结束改进尝试。共享参数或储能结构修改另需有界机制设计；不以无限初始化调优掩盖该问题。已获得精度收益时不再并行搜索初始化或参数变体。

## 4. 全体验证、有限工作量与停止

- 诊断小集合≤80状态；每状态≤12次固定网格积分（4未来、4反向历史、4正向往返）和6次参考积分，≤10个有限差分 Jacobian（5位置×2扰动）。固定状态八阶资格小试≤80套六门检查。
- 两个条件分支的小试各≤80个独立观测包；A 每包≤1800残差，B 每包≤1200残差。两分支最多各尝试一次，选择顺序 A→B；A进入全体后B不再执行。所有失败和到限成本都计入，不重新启动以重置计数。
- 最多一个候选进入全体：两模型×297，沿原顺序各执行一次完整新初始化，A总残差上限594×1800；B复用已冻结stage1并按上述规则最多297次smooth×1200，不重拟合或重新求simple。小试中已按同一冻结配置完成的包沿用原字节，扣除相应剩余机会；不能重复选择更好的重跑。
- 每个完整合格输出再做原 future 主/细步长的15 s自治配对，最多594对；仅验证数值延拓与成本，不读取真实未来。必须保留1/2/5/8/15 s模型间步长差及失败时间，不能由1 s门替代长时数值结论。失败输出留在297分母。
- 对全体候选的“新合格且旧失败”状态，执行一次Radau严格容差1 s参考（每次≤20000 RHS），与候选细步结果按未来 RMS≤1e-6、peak≤1e-5核对；不一致记额外参考未决，分别报告六门合格和参考确认数。该步不重新选择初始化器。
- 遇到输入/模型哈希不符、p锚点或因果接口破坏，暂停对应作业修复身份或实现；不产生科学否定。一般数值失败逐事件记录并继续剩余分母。实现修复只修明确缺陷，保留失败成本与修订来源；改变本协议候选或条件须在追加科学计算前另行前瞻登记。
- 记录 wall、实际RHS、优化残差、成功/失败积分及有效输出数；不从不同覆盖计算加速比。完成上述上限或预设无收益停止后关闭工作量，不转移旧余额。
