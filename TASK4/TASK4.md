# TASK4：预测态锚定的神经—符号功率结构发现

> 2026-09-29｜独立于TASK2的新探索路线。本文是待实施算法设计，不是实验结果。保留100 ms初始化、逐机记忆、显式自治ODE及预测优先；不覆盖TASK2检查点、数据分割、历史结论或工作流文件。不启动电网训练，不使用或恢复TASK2已退役预算，不授权读取TEST。数学细节见 `docs/architecture_math.md`。

## 1. 一句话与核心假设

**先在物理结构内部学习足够灵活的低维动力学，让记忆解释真实未来；再把已学会的储能、交换、耗散和供能函数压缩为简洁公式，而不是先钉死七组模板，再期待调系数解决所有误差。**

核心假设：`预测性记忆约束 + 函数级功率结构 + 充分联合优化 + 保结构符号压缩`，可能比“固定小库、固定系数乘积关系”的路线更容易取得高精度，且能降低只对训练曲线有效的模型歧义。它不保证真实隐藏变量唯一、全局收敛或稳定域自动成立。

TASK4不以“证明TASK2错误”为目标。它承担一个更激进的架构包试验；TASK2继续承担相对保守的小库优化路线。

## 4. 模块A：让q成为“预测性记忆”，不让它只迎合自己的ODE

### 4.1 状态与初始化

默认N=10，每机状态

\[
z_i=(\delta_i,\pi_i,p_i,q_{i1},q_{i2}),\qquad \pi_i=M_i\omega_i,\quad p_i=P_{m,i}-P_{m,i}^{*}.
\]

默认50维，去一个共同角度后的分析维数为49；不是50个真实器件状态。先不加全局状态。只在已有证据显示局部模型遗漏共同动态时，允许一个单独登记的两维全局模块（最大52维），不逐级扫描全局rank。

\[
q_i(t)=E_\phi\bigl(\mathcal H_i^{100\mathrm{ms}},\mathcal A_i(\mathcal H);\mu_i\bigr).
\]

共享GRU32、单层，输出2维；输入仅来自既有角度/完整转速及固定参数。网络摘要使用当前历史内的相对角差、邻域速度与系统共同频率。中心化保证静止参考历史对应q=0。p0按原实验条件已知，但不增加p历史或未来变量作为编码器输入。

**局部状态属于各机，规则共享；不要求q统计独立，不提前命名励磁/磁链，也不保证一个二维块足够。**

### 4.2 预测锚定

在TRAIN滑窗终点t，用冻结M3物理基线从当前已知物理状态作短预测。构造真实未来与该基线的差：

\[
a_{i,t}=\operatorname{stack}_{\tau\in\{.02,.05,.10,.20,.50\}\mathrm{s}}
S_y^{-1}\bigl[y_i(t+\tau)-\hat y^{\rm M3}_{i,t}(\tau)\bigr].
\]

其中y=(δ,ω,p)，尺度S_y只由TRAIN确定。M3只定义这一训练用参考，不是隐藏真值、不锁定TASK4的p动力学。每个τ只用实际存在的未来；短失稳事件不丢弃、不补尾，各τ损失按合法样本数归一化。可用性mask不是编码器输入，不另加从轨迹截断长度推断标签的任务。

用一个共享浅层预测头

\[
\hat a_{i,t}=D_\psi(q_i(t),\mathcal A_i(q(t));\mu_i)
\]

预测这些量。头不直接读取原历史或当前y，不允许绕过q。它只在训练使用，不能在部署中直接输出未来。其作用是让q保存“瞬时物理基线之外的未来信息”，而非恢复唯一真实状态。

预训练后继续联合适配，锚定权重逐渐减小；它不是永久要求q等于某个固定M3残差坐标。若预测头不能准确重建全部锚量，不据此单独否决主ODE；最终单次初始化物理预测优先。去锚定对照用于判断它是否有价值。[R1,R2]

### 4.3 滑窗轨迹的正确用法

GRU可对全部TRAIN合法窗口给出q序列；序列是候选表示而非标签。通过同一ODE在10/50/100 ms等短段上的推进与相邻编码比较，同时用真实物理未来监督。开发/TEST阶段从初始100 ms开始后禁止任何重编码。禁止“只拟合q的自洽性”，禁止通过潜状态整体缩小而掩盖不一致；固定尺度并记录实际作用幅度，而不强迫所有通道单位方差。

## 5. 模块B：函数级功率结构，而不是固定七组系数

### 5.1 全系统生成式

\[
\boxed{\dot z=f(z)=[J(z)-R(z)]\nabla H(z)+B_m p+B_u u(z).}
\]

B_m只把当前p送入π行；其系数、惯性和链式法则固定。p也是ODE状态，因此整个系统仍是自治的。其他函数只读取当前z和固定物理参数，不读取未来真值、事件ID或绝对故障时间。

H固定动能块，其余结构学习：

\[
H=\tfrac12\pi^TM^{-1}\pi+U_{\rm init}(\eta)
+\sum_i h_N(p_i,q_i;\mu_i)
+\sum_{(i,j)}h_E(\eta_{ij},p_i,q_i,p_j,q_j;\mu_i,\mu_j).
\]

U_init提供M3初始化势能，不意味着其全部经验系数永远固定。除动能外H不含π；角差采用sin/cos和相应工作点中心化，边能量在交换端点时对称。每个学习势能做值和一阶项中心化，使H(0)=0、∇H(0)=0；不强制H全局正定/凸。

固定J的δ–π规范块，其他J/R/B的角度行列为零，得到严格的δdot=ω。保留展开角度供失步判断，不将2π滑移折回后宣称同步。

### 5.2 在结构内部开放函数表达

\[
J(z)=J_{\rm kin}+\sum_g m_g\kappa_g(\chi_g)(a_gb_g^T-b_ga_g^T),
\]
\[
R(z)=\sum_g n_g\ell_g(\chi_g)^2c_gc_g^T,\qquad m_g,n_g\ge0.
\]

a,b,c为不含角度分量的稀疏节点/边方向，可在归一化的低维方向库中学习；标量κ可正可负。方向、系数函数和组门共同学习。耗散平方因子从非零值初始化，避免零梯度锁死；剪枝后整体删除，不逐行破坏配对。

节点χ可含(ω_i,p_i,q_i,μ_i)，边χ可含角差sin/cos、相对速度与两端内部状态。允许q-q、p-q和必要跨机作用，不要求隐藏恢复是固定单指数。每机两维内部块允许学习衰减、旋转或组合响应，但不预设它必然是振荡器。

h_N、h_E、κ、ℓ、u首版各用共享的两层32宽tanh网络或相当成本的光滑低维函数网络；不使用一个输出全部50维导数的无约束残差MLP。参数上限建议5万（不含GRU），实际实例数与参数数开跑前登记；这是探索预算，不是物理定理。

**状态相关反对称J保证零净供能，但不自动满足Jacobi恒等式。主线准确命名为“功率结构/反对称梯度结构”，不是未经验证的严格Poisson系统。**若要严格Poisson子模型，只保留常数J或经证明的Poisson构造，再做独立声明；不以一个Jacobi软罚项很小冒充证明。[R3,R4]

### 5.3 供能通道必须有限、可检查

B_u无角度行，首版每机最多两个非保守通道，方向为状态无关的共享/参数依赖稀疏方向；u是当前局部/边状态的低维函数。禁止同时把B_u和u放成任意全维函数，使端口吞掉全部动力学。

p的初始一阶恢复可作为u/R的M3嵌入，但p方程本身由完整生成器给出；不再永久固定为−Ap−Bω。对于真实转矩辅助监督，使用当前f给出的总反作用 `p−πdot`，在原工程单位和阻尼/电磁转矩定义核对后对齐真实量。这个固定+p分解本身不证明其他作用完全不含p；额外的p依赖须显式导出，不能伪装成重新发现惯性或唯一的机械供给定律。

所有供能计入

\[
\boxed{\dot H=-e^TR e+\omega^Tp+(B_u^Te)^Tu(z),\qquad e=\nabla H.}
\]

这是数学功率账，不自动是焦耳或真实负荷功率。按归一化作用记录H/J/R/端口贡献和抵消程度，抑制巨大耗散与巨大供能互相抵消的病态解；不把“端口必须接近零”当真实物理规律。[R3,R4]

## 6. 模块C：先学会，再在结构内部压缩成公式

### 6.1 两个模型不是两套物理

- `T4-N`：上节的高容量结构模型，检验同一信息与状态下能达到什么预测能力。它是结构化神经ODE研究模型，不是已经完成的简洁公式发现，也不是理论性能上界。
- `T4-S`：把T4-N的低维标量函数替换为少量显式表达式，保持同一状态、运动学、交换和耗散构造，随后与GRU一起用真实TRAIN再训练。

这不同于“先任意黑盒拟合，再事后加能量约束”：N和S从第一步起就在同一个功率生成框架内。

### 6.2 只压缩低维组成函数，不对50维RHS整体做符号回归

对每个共享h_N/h_E/κ/ℓ/u，收集TRAIN编码状态、TRAIN自主状态及在声明有效域内的小扰动样本。小扰动的函数值来自T4-N，只作蒸馏，不冒称新的高阶真值。

在有类型/量纲记录的语法中搜索：低阶多项式、sin/cos、乘积，以及必要的安全有界分式 `1/(1+g²)`；可参数化基函数与局部SINDy回归先给初值，表达式搜索再组合/简化。首轮每个共享函数至多16项或40个表达式节点，度数默认≤3；不展开全系统高阶多项式。数值变量先无量纲化，输出恢复对应单位。

拟合储能时同时比较函数值和**对局部状态的梯度**；仅H值接近不能保证ODE接近。结构常数、交换系数及平方因子一起优化。ℓ压缩后仍平方；边对称化、中心化及配对关系作为编译器外层保留，不能靠回归近似实现。

\[
L_{\rm compress}=L_{\rm truth\ rollout}
+\lambda_f\|S_f^{-1}(f_S-f_N)\|^2
+\lambda_h\|S_e^{-1}(\nabla H_S-\nabla H_N)\|^2
+\lambda_c C_{\rm expression}.
\]

教师场/梯度只辅助，真实轨迹始终是最终目标；不要求分解参数逐个唯一。每次替换一个共享函数后联合适配，再逐步去掉神经教师。完整SINDy候选选择与符号搜索都在TRAIN/内层TRAIN进行，不用开发集反复筛公式。[R5,R6]

若N准确但S无法在预定精度容差内压缩，报告“结构化预测成功、简洁公式提取未完成”。保留N结果，但不得把N改名为已完成的稀疏显式模型，或把蒸馏合成样本算作高阶验证。

## 9. 模块D：用模型分歧决定是否补数据，而不是强求唯一q

只在两套**各自预测合格**的候选对未见物理情境存在显著分歧时触发。比较同一100 ms历史初始化后的物理输出，不比较不同模型中同数值q的含义，不用强制模型相互一致的损失压掉分歧。

- 候选物理条件仅来自TRAIN母线/原始TRAIN高阶状态；先在允许的高阶状态方向作小扰动，保持原运行点与故障后系统，重新满足代数一致性。
- 可先生成少量100 ms高阶历史，以候选间未来物理分歧挑选最有信息的条件，再补完整高阶轨迹。默认至多两批、每批8个新增条件，所有候选生成/未选条件成本和失败保留。
- 这些是主动采集的新增TRAIN，而不是新TEST。比较新增数据收益时，相关对照获得同样数据；没有重训练的历史模型只作静态参照。
- 对FOM做适合物理事件的步长核验。0075/0077不合格边界数据不直接合并；无法生成可靠参考就记录该分歧未解决，不强制改标签。
- 额外FOM调用须有独立明确授权；没有授权不妨碍先完成固定数据的TASK4。

作用是压缩会改变物理预测的模型歧义，而不是唯一化所有GRU权重。多个模型一致也不证明正确，可能存在共同偏差。

## 10. 欠约束具体怎样被缩小，哪些仍然保留

| 约束 | 排除什么 | 不能保证什么 |
|---|---|---|
| 未来响应锚定 | 只满足q自洽、没有物理预测价值的表示 | 不唯一确定q，不增加原始观测信息 |
| 多窗口共同表示＋单次初始化预测 | 只靠不断重编码才能工作的内部轨迹 | 不保证全局可观测或100 ms覆盖所有初态 |
| 固定运动学、尺度、图共享 | 任意坐标/单位漂移与逐事件记忆表 | 不恢复全部真实器件参数 |
| 共享H、反对称交换、PSD耗散、有限端口 | 各行随意拼接与无限残差供能 | 不自动是严格Poisson，也不自动有稳定域 |
| 保结构压缩与真实自主精调 | 仅靠大网络拟合、公式不能独立运行 | 不保证必然可压成短公式 |
| 分歧驱动的新物理验证 | 只在旧轨迹上无法区分的部分解释 | 不能靠有限数据证明全局唯一 |

允许等价坐标表示；目标是指定范围内的动力学等效，而不是唯一的隐藏变量名称。若主结构比普通模型更一致但共同不准确，应优先怀疑模板偏差，不把一致性当正确性。

## 11. 稳定域和模态：在最终同一模型上做，不提前强迫结果

### 稳定性

优先在T4-S固定后，用H及少量中心化交叉项构造V；全部Bm p和Bu u都计入Vdot。目标为去共同角度后、包含目标平衡点的紧致不变子水平连通分支，而不是让全部训练轨迹能量下降。

\[
\Omega_\rho=\operatorname{cc}_0\{z\in\mathcal D:V(z)\le\rho\},\qquad
m(z_0)=1-V(z_0)/\rho.
\]

必须验证正定性、有效域、前向不变性及严格下降或LaSalle条件；m>0仍需确认属于同一分支。域外是未获证，不是失稳。若初始化有误差，检查整个误差集合，不只检查中心点。不能靠增设一个虚拟能量变量抵消所有Hdot。[R8]

先得到ROM内界与高阶事件兼容性。要向原高阶系统传递严格保证，还需有效的降阶/初始化误差界，不能用平均RMSE替代。没有V不抹去预测成果；但没有V和区域验证不能声称完成直接判稳。

### 模态

固定有价值端点后，报告完整Jacobian在物理输出上的频率、阻尼和振型匹配；保持已有单对匹配标准，不要求固定数量。无对应如实记录，不因此开启连续修参数链。默认不以特征值训练或挑模型；小扰动轨迹作为泛化数据可用，但明确新增监督与独立验证的边界。

## 12. 能力成绩单与结束条件

必须同时展示N与S的1/2/5/8秒mean/pooled/tail、物理单位误差、共同频率、p、所有严重前缀、原始/100 ms可覆盖分母、漏检/假失步/未判定/数值失败及触发时刻。不能只报稳定集RMSE，不能用更小的分母伪造检出率。

速度在相同硬件、容差与精度条件下计初始化+积分；100 ms观察延迟另列。比较单事件和批处理，不把GPU训练加速当作部署加速。状态维数、神经参数、最终表达式节点、展开RHS和全部搜索成本同时报告。

结束时分别给出：

1. **预测成果**：是否优于有明确身份的参照，改善/损害在哪里，能否从一次初始化运行；
2. **公式成果**：是否完成保结构压缩，哪些函数实际被选择，导数和自主预测是否一致；
3. **结构解释**：哪些只是预设模板，哪些是数据选择，哪些经独立物理验证；
4. **稳定性/模态**：证书或候选的范围，模态的部分对应或缺失。

只有大模型准而公式失败，记为“预测有价值，公式发现未完成”；只有结构恒等式正确但轨迹差，记为“实现正确，动态等效未实现”。不拿一个平均分把错误判稳抵消，不把固定改善百分比当每轮唯一目的。

## 13. 独立执行与工程接口

推荐独立项目根目录 `TASK4/`。只读挂载KIKI原数据、分割和参照；派生缓存、训练、模型、配置和报告全写入TASK4。不要自动修改TASK2的AGENTS、loop、默认模型或current_state；需要代码复用时记录来源版本，不从旧脚本继承硬编码33/40维或7模板限制。

## 14. 主要风险与预设回应

| 风险 | 预设回应 |
|---|---|
| 更灵活结构反而扩大欠约束 | 必须报告P/A/U、跨种子物理分歧和端口占用；不声称唯一机制 |
| 预测锚定逼q记住不易闭合的未来摘要 | 权重退火、主ODE损失优先；A臂检验是否反而损害预测 |
| 状态相关J只满足反对称、不满足Poisson | 准确声明功率结构；需要严格Poisson时另用有保证子族 |
| H拟合好但梯度不好，压缩后发散 | 梯度/向量场联合蒸馏，完整自主真值精调，不交付只拟合H值的公式 |
| 端口吞掉全部动态 | 固定稀疏接入、每机有限rank、作用与复杂度记录；同结构调整而不是任意全维残差 |
| 训练更慢、50维未必更快 | GPU/批处理用于探索，最终单事件同精度计时；状态和公式一起压缩 |
| 数据并未激发关键方向 | 两个合格模型的分歧驱动有限TRAIN采集，不强制补齐13个模态 |
| 固定数据下仍没有准确模型 | 区分P/A/U各自训练曲线、初态诊断与结构偏差；不宣布100 ms或整个物理路线无效 |
