## 当前参考实现的具体选择

- m3物理量及单位来自提供的源码；h/κ/ℓ/端口为两层共享tanh函数。
- J选择本机4个非角状态的交换对，并提供等效边的状态相关交换；额外边耗散为非角状态差方向。不是所有合法方向都自动搜索过。
- 用原点值/梯度相减中心化能量；只有动能依赖pi，角差能量按端点反转对称化。
- 初始记忆交换小幅非零以保留梯度，物理基线可由strength=0复现。端口p初值含−gain×omega。
- 当前训练中的正则是小幅参数正则，不等同于最终结构稀疏化；真正公式压缩必须另外完成。
- 当前完整TRAIN监控是未核验的训练信号，不能替代冻结两步长评价；其JSON显式标记numerically_verified=false。
- `--resume`以配置steps为本阶段总步数，要求原配置（除已验证等价执行选项device/checkpoint_steps/trace_field）完全一致；更换课程或新一轮适配用 `--warm-start`，新建优化器、重新登记，不能称为旧实验精确续跑。保存时发生的运行时异常要由代理说明。
- 新增严格`autonomous_only`最终D选项，删除全部滑窗辅助/预测头/教师作用，只保留真实自主主损失和结构正则；head存档但冻结且不导出。独立NumPy交付包可打印全部17位系数并从11点历史运行；这两项新接口已过合成QA，真实S终点及交付仍待完成，不把文件存在当科研成果。

这些实现选择是打包时新增的工程起点，不是来源文件已经验证的最佳设置。修改实现而不改变核心方案属于正常自主工作。若认为核心方案有问题并准备换新方向，则按AGENTS暂停审批。
