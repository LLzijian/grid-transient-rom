# 什么时候继续，什么时候问

| 事件 | 处理 |
|---|---|
| 训练仍在改进，按已登记课程进入下一预算阶段 | 自主继续 |
| 一个臂失败，其他规划内臂有效 | 隔离失败，继续 |
| 调学习率、分块尺度、有限剪枝/去偏、修接口bug | 协议内自主；超原单轮设置则前瞻修改协议，不改历史 |
| 已实现模块仍缺压缩/评价代码 | 正常实施TASK4，不是改向 |
| 判断预测锚定无用，准备取消它作为主算法 | 提交方向修改并暂停 |
| 判断能量结构限制太大，想以U黑盒为主路线 | 提交方向修改并暂停 |
| N准但压缩失败，想永久只交付N | 提交方向修改并暂停；N结果仍保留 |
| 新增全局状态、增加机器内部阶次作为新的补救主方案 | 提交方向修改并暂停 |
| 变为200/500 ms、加部署电压/功率传感器 | 必须审批，不能称同信息改进 |
| FOM主动采样、超独立预算、TEST访问 | 单独明确授权；不能以规划提到过代替许可 |
| 数据路径拼写/目录位置不同 | 只读核对后更新TASK4映射，不必科学改向审批 |
| 源数据版本/分割实质改变 | 暂停受影响实验并解释，不偷偷重切分 |

用户的“认可”指对具体方向修改的明确回复。其他话题、沉默、一般鼓励、已有旧路线许可不算对新方向认可。
