# 给执行代理的启动入口

先把TASK4与已有kiki放在同一父目录；在TASK4根目录打开代理工作区。

下方启动文本采用**独立60000累计进程墙钟秒、8GiB、一个重任务**作为建议上限。它不是当前对话已经开训或自动授权的记录。你把下段明确发给执行代理后，它才能登记授权。需要其他上限，修改文本中的数字后再发送。

## 可以直接发送的启动文本

```text
请在当前TASK4项目中实际开展研究，不要只交一份计划。
先完整阅读AGENTS.md、TASK4.md、docs/engineering_loop.md、docs/current_state.md和docs/implementation_status.md。
TASK4与kiki是并列文件夹，只读../kiki中的合法TRAIN/validation、必要基线和源码；不能修改kiki、不能读取任何TEST载荷。
本次明确授权在已认可的TASK4大规划内自主实现、设计并执行实验。独立TASK4预算累计60000进程墙钟秒，包含实现验证、失败重试、训练、监控、压缩和评价；最多1个重任务、内存8GiB。阶段未用额度归还父池，不继承TASK2账本，不通过换loop编号清零成本。
先核验实际数据路径与环境，按测时和规划补齐必要实现，不把合成烟测当科研结果。正式研究使用当前项目自己的代码与输出目录。
在大规划内自行设计和推进：有可信进展就接受或保留，无进展就回退活动代码/模型但保留报告及失败证据，然后继续下一项规划内工作。不必逐轮征求我对超参数或常规实现的同意。
但当你认为当前核心方案存在问题、准备给出新的方向并改变路线时，必须保存并暂停，提交简明修改单询问我。得到我对该具体方向的明确认可后才继续，不能自行认可或先跑再问。
不默认批准新FOM采集、TEST、额外预算或付费服务。优先高精度自主暂态，结构支持稳定域分析，模态是附加收益。首轮不要追求固定匹配数量或每次必须改善某个百分比。
按状态工具记录授权，建立前瞻实验协议和代码快照，开始执行；健康长任务外层检查约3–5分钟一次，预算或安全边界到达就保存退出。不要承诺宿主/会话关闭后仍会后台运行。
```

## 新方向认可后恢复

只需针对代理提交的具体提案回复，例如：

```text
认可DIRECTION_001中的新方向及明确列出的修改，其他约束和原累计预算不变。请记录本次认可，更新相应路线版本，然后继续执行。
```

如果不同意，说明希望保留的主线。代理应保持暂停，而不是自动尝试它自己的备选方向。
