## 验证与边界

本次快照不是原子快照。盘点期间全部 4,408 个文件的大小和修改时间未观察到变化；其中实际读取的 1,599 个文本文件另做了前后 SHA256 比较，未发现变化。
未读二进制文件没有取得前后内容一致的哈希保证。覆盖目录中没有遇到不可访问项或被跳过的链接；这不代表私有目录内的旧受限子树可访问。

当前研究登记记载 fit297 已闭合；系统中仍有 Python 进程。由于进程命令行查询被系统拒绝，本次没有确认它们与仓库的关系，也不据登记推断当前没有作业。
本批仅在新工具、测试和此产物目录中写入，未运行训练、预测或高阶数据生成，未解析原始 val/test 或科学数组。

重新盘点需使用新目录，工具拒绝覆盖已有快照：

```powershell
./.venv-gpu/Scripts/python.exe -X utf8 -B tools/repository_inventory.py --root . --output results/repository_organization/<新批次>
```

后续再运行时应排除已有整理产物或另行标注，以免把维护产物计作原始研究材料。
