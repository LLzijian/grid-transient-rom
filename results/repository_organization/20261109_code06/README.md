## 验证范围

[合成单测](../../../tests/test_shared_numerics.py)只核对数值函数：向前／向后、向量与批量输入和旧表达式逐位一致；线性解析解验证四阶误差趋势；非法步长、非有限值和错误形状被拒绝。没有加载旧模型、数据集或运行原实验。

代码索引中的入口与共享实现类别来自AST及静态引用，实际运行情况未核验。旧源的动态消费者不能由静态扫描穷尽；所有未解除依赖与待判定项继续保留。[迁移回执](migration.json)含原路径、字节、SHA256、原版本阅读方式及回退条件；最新累计路径同时接续此前416份报告原件。
