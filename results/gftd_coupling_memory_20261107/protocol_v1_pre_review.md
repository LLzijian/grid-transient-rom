## 问题与最小方法

检验s=0、已知边形状及其余共享参数时，一个未知共享尺度c能否与逐事件记忆初态区分。不扩展通用fit，也不修复无关接口；现弱投影类docstring的D符号与代码不一致，资格以本页推导及实际正D方程为准并在实现审查记录。不是图发现，不拟合节点指数核，不将真参数初始化出的隐轨迹当独立观测。单Run包含先后两门：A真值辅助端口/代数资格；A通过后B合法11点线性估计。二者分表、隔离输入；A失败则B不释放，保留失败分母，不必为相同数学问题拆成另一科学Run。

已知方程M omega_dot=-c F(theta)-D omega+G S_p p-r，p_dot=-G'omega-R_p S_p p，r_dot=kappa omega-lambda r，theta_dot=omega。F=∇U_ref，边参考形状固定；a=0且s=0使其完全解耦。唯一待估共享参数c，逐事件r_begin是干扰参数，不固定为真值。

记窗口[0,T]、T=.1，A_p=R_p S_p，则

    p(t)=exp(A_p*(T-t))*p_end + ∫_t^T exp(A_p*(u-t))*G'omega(u)du
    r(t)=exp(-lambda*t)*rho + r_f(t)
    r_f(t)=kappa∫_0^t exp[-lambda*(t-u)]omega(u)du，rho=r_begin。

p和r_f只依赖合法omega及真p_end、固定常数，与c无关；可同c联合使用而无循环推断。测试函数v(0)=v(T)=0后：

    c ∫F v + rho ∫exp(-lambda*t)v
      = ∫M omega v' - ∫D omega v + ∫G S_p p v - ∫r_f v。

逐节点、逐测试函数堆叠为A*c+Z*rho=b，多事件仅c列共享、rho列各自独立。用SVD正交消去Z，a_perp=(I-P_Z)A，b_perp=(I-P_Z)b；若a_perp非零，c_hat=(a_perp' b_perp)/(a_perp'a_perp)，rho_hat=Z^+(b-A*c_hat)。profile(c)=||b_perp-a_perp*c||²，不做逐c ODE优化。主估计不强制c非负、不截断、不加ridge；负值作为有限估计结果报告，不能偷改成结构零。合法物理c>=0只作科学解释，需有界物理估计另设计。
