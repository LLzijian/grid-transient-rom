# GFTD 修订：独立机械功率、幅值与记忆

本方案冻结 5N 状态及数据无关 Stage 0 资格检查。目标是让调制候选精确包含旧 RMemoryROM，并由同一储能给出全部梯度和功率账。Stage 0 不运行科学训练，不读取真实事件数据；结论限于数学与接口资格。

设计角色回执：configured_model = `gpt-6-astra`；server_resolved_model = null。配置名不作为服务端模型解析证据。root 已记录恢复授权；本文件不扩张数据权限。

## 1. 冻结方程

接口状态顺序为 `(theta, omega, p, a, r)`，每块 N 维。theta 为展开绝对角，父偏差坐标通过 theta=delta+delta_star 映射；内部动量为 pi=M omega，不把 omega 直接当动量。

令 M 正定对角，S_p、K_a 正定，kappa>0；D_w、R_p、R_a 及 sym(Q) 半正定。父模型 G 为对角；一般矩阵推广时机械功率反作用须使用 G 的转置。

```text
H = omega' M omega/2 + p' S_p p/2 + r' r/(2 kappa)
    + a' K_a a/2 + U(theta,a)
theta_dot = omega
M omega_dot = -U_theta - D_w omega + G S_p p - r
p_dot = -G' omega - R_p S_p p
a_dot = -R_a (K_a a + U_a)
r_dot = kappa omega - Q r
```

相应精确连续时间功率恒等式：

```text
H_dot = -omega' D_w omega - (S_p p)' R_p (S_p p)
        -(K_a a+U_a)' R_a (K_a a+U_a)
        -r' sym(Q) r/kappa
```

幅值与记忆分离使调制开关不改变 `-r`、`kappa omega` 两个加性记忆端口。储能耗散不自动给出目标平衡的吸引域；后者需要另外检查局部曲率及区域条件。

设 B 为 N×E 节点—边关联矩阵（父 E×N 关联矩阵的转置），eta=Bᵀ delta_star，phi=Bᵀ theta，
`V_e = cos(eta_e)-cos(phi_e)-sin(eta_e)*(phi_e-eta_e)`。
取 `U=sum_e k_e Phi_e(a) V_e`，`Phi_e=(1-s)+s exp(h_e(a))`，0<=s<=1；h 为光滑的既有节点局域幅值参数化。所有梯度使用同一未截断指数；浮点越界明确失败，不截断或替换梯度。s=0 时必须精确返回父 U，U_a=0。Stage 0 的合成非零调制检查可固定线性 h，无需学习。

## 2. 父映射与合法输入

代码来源为 `experiments/r_memory_model_20261025.py:RMemoryROM`。映射保留其有效质量、边、目标相角、耦合、阻尼、G、S_p、R_p、kappa、lambda 及初始化器；使用 s=0、a=0、Q=lambda I。父状态 `(delta,omega,p,r)` 映为 `(delta+delta_star,omega,p,0,r)`，构成不变子空间。父内部储能通过 `(delta,M omega,p,r)` 调用，避免坐标误比。其他父 Q 变体必须传入实际同一个 Q，不能换成 lambda I 后称精确嵌入。

初始化只接收 11 点/100 ms 的 theta、omega（父接口用 theta-delta_star），末点真实 p0 和冻结常数。兼容旧 `[11,30]` 接口时，前 10 行 p 必须被忽略；它们不是部署输入。父模式下原初始化器生成 r0，a0=0，p0 原样进入独立 p 状态。非零调制模式的隐状态初始化尚须 Stage I 设计，不能用隐藏 a/r 真值完成部署初始化。

## 3. COI 算子条件

令 b=M1/(1' M1)，P=I-1b'。相角和速度相对坐标用 P，力用 P'；P1=0、b'P=0、P'M=MP。对零和隐力子空间，`1' Q P'=0` 保证 Q 不把零和隐力送入总隐力。

全系统共同/相对动力学解耦还要求完整状态投影 Pi 的两个交叉块 `Pi A(I-Pi)`、`(I-Pi)A Pi` 均为零；非线性系统须对声称区域内完整 Jacobian 成立，并检查初始化。单独投影 r 或 Q 不足。本轮不删除父共同状态，COI 仅报告。

4. **报告字段**：每项输入、最大绝对/相对残差、通过状态、失败原因、代码版本、修复次数及实际耗时。缺失为 null。代码决定、模型决定、科学决定分别写；资格通过不晋升模型，不宣称结构恢复。

## 5. Stage I：下一项待设计问题

下一问题是：在合法 100 ms 观测中，幅值 a 与记忆 r 的影响能否区分，如何得到可自主推进的初态？本文件不释放 Stage I，不提出恢复排行榜。

优先设计零参数拟合的局部敏感度探针：固定已知方程与尺度，在人工状态附近计算 `(a0,r0)` 到 11 点 delta/omega 与末点 p 的观测 Jacobian；报告奇异值谱及近零方向的前向扰动检验，比较 s=0 与非零 s。s=0 时 a 完全不可观是解析负校准。有限窗满秩不等于全局可辨识，也不证明未知参数与隐状态可以同时恢复。
