# 闭合结构发现：预测标准与机制证据

2026-10-21，受控合成研究。**当前骨架和一次历史初始化可以在不新增边储能的情况下达到既定平均预测标准。** 这为后续结构发现提供了必须区分的两个问题：模型能否预测，以及额外机制是否为这种预测所需。

三个结构使用相同的40状态和固定物理图、30维观测及100ms一次GRU初始化。正弦差与余弦和各增加一个共享系数的边储能项；空项删除整个新增H，保留q骨架、交换/耗散/端口和六个q0历史系数。新空项从共同未拟合来源分别联合训练512次；两个既有结构冻结复用，没有重训或重评。

每种子16train、未来0.5s；16既有开发合成val、未来1s。固定train尺度下逐事件归一化MSE再平均。九个端点均通过平均MSE≤0.01及双步长差≤1e-3；新空项数值差≤9.633e-11。每方案超过0.01的val事件数分别为0/2/1，全部事件保留；平均通过不等于逐事件通过。三种子同时改变生成与训练随机流，不作同数据优化重复或未登记的显著性推断。

新增H不是这些观测、激励、时域与512次联合适配流程下达到平均门槛的必要组成；这不表示三个结构性能相同。空项相对正弦的val误差变化为+14.495%、−0.454%、+6.653%。原物理边、q及初始化适配均保留，结果不否定一般边作用、隐藏记忆或teacher项；也不证明未知公式恢复、全局不可辨识或物理必要性。512端点仍在改善，不声称各族优化收敛。

下一科学决策应检验哪些观测、激励或时域能区分这些可行解释；任何具体试验都须新的Astra6方案与有限协议。本次是开发合成证据，原项目val/test关闭、TASK4暂停，默认模型、原结构发现门槛、真实模型采用标准与P4资格不变。
