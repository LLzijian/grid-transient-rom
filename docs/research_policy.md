# 研究证据、档案、预算与发布

此处定义证据规则；工作流见 [engineering_loop](engineering_loop.md)。
程序只检查记录资格，不证明物理、统计、文献新颖性或证据真实性。

## 1. 不同层次的判断

| 层次 | 问题 | 不足时允许的结论 |
|---|---|---|
| 证据有效性 | 信息、数据、分母、数值、实现、身份是否正确？ | technical_invalid / unknown |
| 优化健康 | 是否有非有限值、异常步幅、崩溃或明显数值问题？ | unhealthy / unknown |
| 优化充分性 | 对此实例与比较机会，欠优化是否仍是主要竞争解释？ | insufficient / unknown |
| 机制探针 | 实际实现是否实现目标功能；观测能否区分它？ | failed / unidentifiable |
| 效应与确认 | 多大效应、哪些事件、何种不确定性、在哪个范围重复？ | 观察、权衡或未决 |

健康不能替代充分；探针通过不能替代可辨识；参数非零不能替代因果作用。
强经验结论和模型晋升要求明确的优化健康判断；unknown 或缺失不算通过。
确实不适用时可用 not_applicable，并以已索引的
`inference.optimizer_health_not_applicable_reference` 说明依据。预算内观察和数学反例
沿用各自条件，不因此新增充分优化或重复训练要求。
非负约束下的精确零边、饱和活动集可以是正确最优解。使用可行下降方向、投影梯度、
KKT 残差或约束子问题诊断；不要求所有参数“未触边”。
证书未获、激励不足和代码错误分别记录。L2 证书与精确可辨识证明按具体主张取证，不作为首个预测候选的开工门。

## 2. 主张必须对应证据

### 观察与范围内效应

一次有效且匹配的比较可报告“在登记预算与条件下观察到收益/退化/权衡”。
这不需要虚称已经找到全局最优，但必须披露优化机会和选择过程。
只有充分适配、能够区分竞争解释且有范围相符的确认，才申请更强的机制性主张。

### 阴性、等效性与否证

- 没有清晰收益、p>0.05、两个 seed 同号，均不单独证明无效。
- 性能实践等效须先定义实际意义界值 δ>0、指标方向、估计对象和不确定性方法；
  在有效且匹配的比较、合理优化和相应确认下，区间完全落入 [−δ,δ] 才能支持该
  范围内的等效判断。区间宽则继续未决，不能因为均值接近零而宣布等效。
- “没有实际意义的正收益”也可以是单侧命题，但必须单独登记检验；本包检查器仅实现
  上述更保守的双侧实践等效记录门，不自动计算统计检验。
- 性能等效不表示物理机制不存在、不必要或参数为零。mechanism_null_within_scope
  只用于明确预登记的功能性预测，须有对应探针、范围和独立审查，不能由 RMSE 自动生成。
- 精确反例/定理可否定一个明确全称命题，不要求重复训练；需保存命题、假设、
  推导与独立复核。数学否证的范围不能扩展为所有相关模型族。
- 停止投入或暂存是资源/优先级决定，不自动改变真伪判断；保留重开所需新证据。

### 确认独立于晋升

首轮正、负、混合结果都可触发确认。确认的目的可以是排除随机性、判断实际等效、
区分机制或界定失败范围；不能仅对首轮赢家重复。
种子重复只量化优化随机性；同一数据上的事件重采样不是全新系统。
记录冻结时点、历史选择暴露、数据/条件重叠、独立单位和多重/自适应选择处理。
不设全局“2 seeds 即充分”。确认计划由估计精度、效应尺度和可用独立单位决定。
旧训练/报告数据反复使用须披露；本规则不打开 val/test 或新增 FOM。

## 3. 双档案、四指针和三个决定

保留现有双档案：受保护的可用模型、科学候选/证据档案。
可用只表示原研究合同下接受，不自动可部署或获得高阶安全保证。
候选记录 artifact/hash、source commit、父候选/架构、信息暴露、评价合同、
逐事件错误集合、数值未决、复杂度及真实成本。缺失填 null，不填 0。
同合同才比较非支配关系；错误数相同但身份不同可有互补价值；不合成任意总分。

main code、working_candidate、incumbent、protected anchors 相互独立。
模型未晋升不重置 working_candidate；下一起点由科学理由和谱系决定。

| 决定 | 选项 | 要回答的问题 |
|---|---|---|
| 代码 | merge / retain_branch / revert_active / no_change | 实现是否正确、可维护、可复用？ |
| 模型 | promote_incumbent / add_frontier / retain_evidence / ineligible | 满足哪一评价合同、代价和事件条件？ |
| 科学 | continue / supported_within_scope / mechanism_null_within_scope / falsified_within_scope / unresolved / abandon | 哪个命题得到何种证据？ |

abandon 仅表示不继续投入，必须附仍未解决的科学状态。
晋升需冻结候选、原门槛、关键事件身份与数值资格、范围相符确认和独立审查。
探索性 frontier 保留不等于晋升；平均收益不能抵消未获许可的关键事件退化。
三决定由 root 明确作出；机器 eligibility 只能提示是否具备提交审查的记录。

## 4. 数据、权限与暂停

沿用 [kiki](../kiki.md) 数据合同：原始 val/test 关闭、旧已消费 test 退出选择、
新 FOM=0、TASK4 暂停、default none。新 Run 前瞻冻结版本化部署合同及输入白名单。活动合同 motion_only_v1 与旧信息增强参照 known_p0_reference 分开列示，只有同信息条件可作匹配算法比较。训练辅助监督限于获准且已保存的 train fit297 字段，部署与评分信息按相应协议隔离。旧协议及其数据权限保留原身份。
私有数据、轨迹、checkpoint、Adam/RNG 和密钥按其数据或模型身份保全，不随本包上传。
存储迁移和旧产物精简按第7节执行，不把换位置当作获得新数据权限。
用户显式暂停科学运行时，须等用户明确恢复后才能登记和执行新科学 Run；已授权的整理、设计与审查可继续。
新模型名、框架安装、Git 同步或示例状态不能代替恢复授权。
在用户恢复后，既定方向内正常推进无需逐轮再次请示；权限边界变化另行处理。

## 5. 工作量、适配与成本

用户已取消进程数量、单进程时长、进程秒和父总小时额度；不借调度规则恢复这些配额。
每个 Run 仍事先登记有限比较、适配窗口、停止/转向条件及成本记录。
给新机制和对照合理适配机会，不机械认为相同 updates 就等价；同时报告固定计算预算下
表现与适配诊断，避免把无限调优后的最好值和未经适配的基线比较。

追加工作必须写：哪种竞争解释仍在、什么结果会改变判断、为什么此工作比替代方案更有价值。
不能无限以“也许欠优化”续跑。若可用预算不能消除欠优化解释，则正确状态是未决或暂存。
既有 formal / QA / repair / replay 类别、上限、已关闭余额保持原记录，不跨阶段转移。
更换 ID、seed、Adam 或父候选不能抹去同谱系已经进行的适配与选择。
实际 wall/CPU/GPU 记录来源和范围；未知成本写 unknown。预算耗尽不等于科学完成。

## 6. 归档、Git 与状态

算法方案放 `designs/`，旧设计归 `designs/history/`；新 Run 协议随 Campaign 放 `campaigns/`。
`reports/` 保存结果、分析、审查和支撑实验的冻结来源。运行中的路径与哈希绑定保留到明确阶段边界，
设计入口可以指向字节一致的副本；冻结期间双方均不编辑，后续修订另记版本与来源。

研究执行改变设计、代码或结果后，按既有授权选择性提交并普通推送；接受、失败、
拒绝和未决同样归档。只读检查无新材料不做空提交；本包安装工具不操作 Git。
耐久记录含协议/修订、必要源码配置、关键正负证据、逐事件摘要、三个决定、
命令环境、来源哈希及推送核验。小体积证据入库，大型/私有产物按原存储保全并记哈希。
禁止整树暂存无关修改、force push、reset --hard 或 git clean 清除未归档研究。
先存证据，再撤活动代码。推送失败保留本地提交并记录阻碍，恢复先对账，不重复启动未知 Job。

执行状态沿用 RUNNING / COMPLETED / BLOCKED / PAUSED_BY_USER / INTERRUPTED_RUNTIME。
Campaign 状态沿用 active / supported_within_scope / falsified_within_scope / unresolved /
paused_review，与执行状态和 Run 科学结论分别记录；新规则不追溯改写历史状态。
预算使用 open/closed/exhausted 等独立字段。
current_state 约一页，只写真实状态、指针、证据和下一授权动作。
历史报告不回写；更正追加日期、理由、旧/新解释及范围。包内快照是历史输入，不是 live registry。

## 7. 本地存储与闭合实验精简（2026-11-08用户授权）

`private_data/`存放数据集、固定划分与生成来源；`artifacts/<实验名>/`存放本地实验大文件、
检查点、原始预测、缓存及相应执行回执；小体积协议与结论继续放`reports/`、`results/`。
可重建测试文件用`.tmp/`，恢复备份用`local_backups/`；后两类与artifacts默认不上传。
当前已冻结的旧路径依赖暂时原地保留，待阶段边界验证兼容后迁移，新Run优先使用新位置。

迁移保留旧→新路径、文件大小与SHA256；不改写旧协议或身份哈希以消除路径冲突。
当前依赖、受保护模型、唯一输入与支撑正负结论的决定性证据必须保留。
闭合后可按逐项清单删除无恢复用途、无独立证据职责的中间状态和可重建测试产物；
重建不得要求重开val/test或新增FOM。无法核清的材料继续保留。
相同冻结文件可经字节哈希和同卷验证后共享只读硬链接，保留所有引用路径和内容；
修改共享文件会影响全部链接，故不得将这种文件作为可覆盖的输出。恢复写入须先生成独立副本。
清理记录分别报告逻辑迁移量、删除量与物理空间回收，不把同卷迁移计作释放空间。
