## 3. 保留的上层设计，以及允许修正的闭合假设

首轮状态仍为每机 \(z_i=(\delta_i,\omega_i,p_i,q_i)\)，\(p_i=P_{m,i}-P_{m,i}^*\)，十机共40维；分析仅去共同角度，保留39维及完整共同频率。内部允许 \(\pi_i=M_i\omega_i\)，但沿用已核对的单位与链式法则，不任意解释为真实角动量。

\[
q_i(0)=E_\phi(\mathcal H_i,\mathcal A_i(\mathcal H);\mu_i),\qquad
\dot z= f_\theta(z).
\]

固定100 ms、11点角度/转速历史；共享小GRU、各机不同状态；第一阶段真实 \(p_0\) 已知。预测从切除后100 ms开始，之后只积分ODE，不反复编码，不读取未来电压、功率、故障元数据。邻域作用只由当前模型状态和固定可用物理信息计算。

| 保留的约束 | 不应误当作定律的假设 |
|---|---|
| 经核对的运动学、惯性、单位、工作点与角度平移/机器重编号一致性 | 原始M3的一阶 \(\dot p=-Ap-B\omega\) 并非机械侧唯一形式 |
| 声明为内部交换的成对作用；声明为耗散的非负耗散；显式供能账 | 当前七组支持、13参数乘积绑定、单标量指数型记忆不是唯一能量实现 |
| 共享机器级规律，允许已知机器参数依赖 | 共享规律不等于所有时间常数相同；\(q_i\)不预先命名成纯电磁状态 |
| 显式、自治、低复杂度，部署信息不增加 | 当前每机一个q是起点，不是严格最小或充分状态的结论 |

结构候选继续采用：
\[
\dot x=(J-R)\nabla\mathcal H+B u(x),\qquad J^T=-J,\ R\succeq0,
\]
\[
\mathcal H=\tfrac12\pi^TM^{-1}\pi+\sum_i h_N(p_i,q_i;\mu_i)
+\sum_{(i,j)}h_E(\eta_{ij},p_i,q_i,p_j,q_j;\mu_i,\mu_j).
\]

首阶段沿用常数J/R/B与既有运动学块；非动能储能不含π以保持现有运动学保证。此后扩展须继续满足这些硬约束，但不永久锁死当前函数族。节点/边/端口按模板组选择，储能求导及交换成对生成，不逐行剪枝破坏关系。[R1,R2]

\(u(x)\)是当前状态的低复杂度非保守作用，不是未来真值，也不得成为全维任意残差网络。全部端口纳入功率账和稳定域验证；不强制所有发电机修正零和。区分真实物理恒等式与有效参数：不得把经验 \(j_iA_i\) 的变化写成重新发现惯性或原始机械功率定律。

### M臂的具体训练办法

多重打靶是把长轨迹拆成短段共同拟合，同时要求段与段由同一ODE衔接；不是让模型一直依赖真实轨迹。[R5] 以下合并课程与GRU接口是本项目的新实现方案，不是文献已经验证的电网结果。下式的Z是仅训练期使用的段起点，S_z是由TRAIN固定的状态尺度，不能随候选自由缩小以掩盖连续性误差。

\[
Z_{e,0}=z_{e,0},\qquad
L_{\mathrm{MS}}=\sum_k L_{\mathrm{segment},e,k}
+\beta\sum_k\|S_z^{-1}[Z_{e,k+1}-\Phi_\theta(\Delta_k,Z_{e,k})]\|^2.
\]

1. 先用约0.5 s短段，逐步合并到1、2 s及完整目标区间。段起点物理分量由TRAIN观测初始化；作为辅助变量时仍受物理观测拟合约束，不能自由漂移解释误差。隐藏段状态可优化，但不称为真实隐藏状态。
2. 只有TRAIN可以使用这些辅助段状态；第一段始终由正式100 ms编码器初始化。每段使用同一ODE，连续性约束覆盖完整降阶状态，不能只约束输出而允许q跳变。
3. 用预登记的有限罚系数课程或增广拉格朗日实现连续性；同时记录段间不连续量和真正的单次初始化预测，不只看分段损失。
4. 最后删除全部中途段状态与重置，回到原 \(L_{\mathrm{deploy}}\)，从唯一 \(z_0\) 自主积分。预先为这一步保留至少三分之一训练预算；预算不足以完成时写“训练策略未完成”，不能交分段成绩冒充预测。
5. 所有开发/TEST评价从头到尾只调用一次GRU。部署文件不包含任何逐事件辅助初态、未来观测或分段校正。仅真实可用前缀参与损失，短失稳事件不补到课程长度。

O/M两臂使用相同原始事件、观测信息、物理目标及总资源上限，报告共同成本点和最终单次初始化成绩；中间训练目标不同是算法比较的一部分。若预算无法支持四臂，先做S-O/S-M，再登记匹配的F对照；缺失的因子效应保持未决，不用历史端点冒充匹配对照。

### 怎样判断，而不是训练到某个百分比通过

在固定节点查看完整TRAIN同部署目标、严重前缀、块级梯度/更新量和裁剪比例。12事件面板只作廉价监控。提前登记学习率适配范围、可执行里程碑、停止/扩展规则和检查点选择；依据完整TRAIN或内层组，不靠反复看开发结果调参。

| 观察 | 下一决策 |
|---|---|
| S-M较S-O改善，S/F差距收窄 | 保留优化方法，优先完成结构候选的精度确认 |
| F在合理适配后仍明显好于S | 检查具体绑定/结构模板；不能直接宣布能量规律不合适 |
| 两者都难拟合TRAIN | 执行第6节一个初态或表达诊断，随后返回自主训练 |
| TRAIN好、开发组差 | 检查覆盖/共享异质性与泛化，不以扩大训练步数替代分析 |
| 预算到限仍改善 | 记录优化受限、保留端点；新的有限阶段另登记，不重判旧轮 |

本阶段交付是完整的预测能力与优化证据，不以稳定域或匹配模态数作为结束前提。

## 6. 只有预测证据指向缺口时，才调整闭合设计

不新增一长串冻结系数诊断。每次只选下列一个能改变下一自主实验的假设：

| 需要区分的问题 | 最小有用实验 | 解释边界 |
|---|---|---|
| GRU初始化还是ODE本身限制？ | 同一ODE与维数，在TRAIN子集中从GRU初值出发，用后续真实轨迹优化q0，并比较完整自主目标 | 明确使用未来的离线乐观诊断，不是部署算法或泛化；无收益也可能是该诊断未优化好 |
| 共享时间尺度/参数关系过窄？ | 同状态下增加一种基于已知机器参数的共享异质性，或一族成对节点/边结构，再联合训练 | 不同时变维数、输入与端口；F优于S不证明不存在其他能量坐标 |
| 一个局部内部方向不足？ | 在保留局部组织和共享规则下，比较一次额外局部状态或一个小型内部动态模块 | 只在前述适配后触发；不重回全局r逐级扫描，不把新状态预先命名成某个器件 |

M3的 \(\dot p=-Ap-B\omega\) 继续作为初始化/对照，不永久锁死。p与q的新增动力学仍来自受约束模板：优先检验耦合、已知异质性及有效时标，必要时才增加低阶非线性。状态相关反对称J仅保证零供能，声称Poisson时还须核对Jacobi；首选不破坏已有运动学的最小扩展。

结构组由多步自主误差提出并联合适配，按其对预测的贡献剪枝；不在大函数库里逐行任意搜索，也不由人工逐项规定励磁/负荷/调速器关系。全部新结构、独立参数及展开RHS成本显式导出。

## 8. 稳定域：结构从开头设计，证书对最终方程建立

结构化预测候选形成后，固定部署ODE及其全部端口，寻找低复杂度 \(V=\mathcal H+\) 必要的中心化修正。在仅去共同角度后的状态z上定义：
\[
\Omega_\rho=\operatorname{cc}_0\{z\in\mathcal D:V(z)\le\rho\},\qquad
m(z_0)=1-\frac{V(z_0)}{\rho}.
\]

先检查目标平衡点及局部曲率，建立一个可检验的局部区域，再利用角差函数界或适合当前模板的条件扩大它；不先建设通用高维认证框架。稀疏H本身若不够，允许少量证明用交叉项，不要求每个储能子项分别正定。

只有该分支紧致、位于声明有效域内、V相对目标平衡点正定、前向不变，并满足严格下降或“非正导数＋最大不变集仅为目标平衡点”的LaSalle条件，才称为**ROM吸引域内估计**。[R4] 全部实际端口必须参加 \(\nabla V^Tf\)；认证时不得关闭它们或补一个虚拟能量箱。

采样无反例只能支持候选判据。\(m>0\)还需确认初态属于相应连通分支；\(m\le0\)表示未获证，不自动失稳。\(\rho\)不是自动成立的真实临界能量，不能直接换算成临界切除时间。存在初始化误差时报告其敏感性；更强声明须把误差集合纳入判定。

随后在独立高阶真实事件上报告稳定覆盖、失稳误纳入和未获证比例。ROM证书与高阶事件吻合是兼容性证据，严格传递还需有效的降阶/初始化误差界，不能用平均RMSE代替。区域不宜只追数学体积，还要看是否覆盖有效初态。

若为扩大区域需要再调整动力学，另立有限的联合实验并保留L1精度约束；不以显著牺牲真实暂态的代价制造漂亮势阱。L2暂未建立时交付L1部分成果并明确缺口，不宣称整体结构判稳目标已完成。

## 9. 模态：可以部分对应，不再反向绑架预测模型

只在固定的有价值预测端点上计算完整耦合Jacobian，去共同角度、保留共同频率。继续沿用既有一对一频率/阻尼/物理输出振型匹配定义；报告全部目标、连续误差、已匹配和未匹配项。

**取消未来任务中“至少匹配若干/多数模态”的完成条件，不降低原有单对匹配标准，不追改旧0/13或1/13结论。**得到少量对应即可作为附加结果；没有对应就说明当前模型不支持该项解释，不能伪造机制，也不自动再开参数修补分支。

不默认加入高阶特征值/振型损失，不按匹配数挑选预测端点。对已匹配项可做一组独立小扰动响应核对；不同幅值响应作为预测验证有价值，但不是凑模态。以后确有独立研究必要时，模态监督另立扩展任务，并标明训练所用信息，不能悄悄回到三目标同等强制。

## 11. 确认与交付边界

沿用原合法TRAIN；0075/0077未合格边界数据不自动合并。所有拟合、归一化、结构选择及优化适配限于TRAIN/内层TRAIN；开发集反复使用属于开发证据。旧已消费TEST永久退出选择；新TEST在模型、初始化器、预测判据及拟声明的稳定域规则冻结后，获得授权才一次性使用。不能先用它挑L1模型，再继续用同一TEST调稳定域。

最终保留1–2个互补候选，优先争取同一结构化ODE同时交付高精度预测与有效区域内界。交付：100 ms共享初始化器；完整显式方程、数值系数、单位与支持；结构版H/J/R/全部端口；逐事件精度/判稳/数值/计算成本；V与区域证据（若得到）；部分模态表（无对应也如实报告）。

L1可独立形成经过确认的成果；F可作为普通稀疏预测成果和对照，但不因此完成结构化L2。主结构判稳目标的完成需要L1与其明确声明范围内的L2证据；L3不是必须补齐的缺口。科学假设未奏效、预算耗尽和任务完成分别记录，不用改变结论措辞制造成功。

**首个执行入口：核对0101端点与授权 → 同起点S/F×优化方法对照 → 完整自主预测评价 → 按证据选择优化确认或一次闭合扩展 → 在有效结构候选上建立稳定域；模态最后附带检查，不倒置主次。**
