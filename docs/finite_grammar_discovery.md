# 有限语法结构选择工具

新增工具将生产语法生成的六种边闭合形式，与一次100ms初始化下的自主联合训练连接起来。短期train轨迹用于连续参数拟合，较长train轨迹用于结构排名；无效事件不删除，数值误差区间重叠的候选保留明确的排序歧义。所有最终结构冻结后才生成独立合成val。

分级更新为六项到32次、两项继续到128次、一项继续到512次；三个种子的完整合同共2304次更新。模型、Adam和NumPy/CPU/CUDA随机状态从实际checkpoint接续，计划工作量与已完成工作量分列。CUDA检查7项通过，其中32→34次恢复后的参数、优化器、随机流和输出与连续训练精确一致。

当前完整研究**未获成本准入**：唯一测量在100秒内部上限处停止，尚未覆盖全流程；三个正式种子均未启动。准入要求完整T≤576秒，再加25%余量和180秒支持，总计不超过900秒。当前没有完整T估计、未知形式恢复结果或新的模型默认设置。后续训练须另行满足完整成本与来源门禁。

入口为[专用模块](../experiments/finite_grammar_discovery_20261021.py)，检查见[测试](../tests/test_finite_grammar_discovery_20261021.py)，实际资格、失败和费用见[证据](../results/finite_grammar_discovery_20261021/capability_profile.json)。[冻结协议与来源](https://github.com/LLzijian/grid-transient-rom/tree/f41cb671a48d102705362fe84f6f2e16e00cbc2a/reports)明确预算、池、真值抽取及关闭规则。登记的Windows/CUDA、float64、固定步长和本地来源资产是复现条件；原始数据、Adam状态和完整原生回执保留本地，关键路径及哈希已归档。原项目val/test关闭、TASK4暂停，所有模型采用门槛保持。
