# 一级算法设计：先确定学习问题，再决定模块

本文件定义通用设计方法；当前架构实例见 [current_design](current_design.md)，部署与数据合同见 [kiki](../kiki.md)。
改变状态、闭合族、结构推断原则或主要训练目标前，先形成 [架构简报](../templates/architecture_brief.md)。
具体方案保存在 [designs/](../designs/README.md)，旧版本归 `designs/history/`，由当前入口和 Campaign 引用。
同一假说内调参、修复或消融引用现有简报，不另造架构层级；设计材料本身不授予运行权限。

## 1. 一级结构必须给出的五个对象

| 对象 | 必须说清什么 | 常见误判 |
|---|---|---|
| 信息与状态 | 合法观测 H₀、待预测 y、状态 z、因果初始化 Iφ | 用更多训练标签掩盖部署不可观 |
| 假说空间 | 结构 S、参数 θ、已知约束、允许的等价变换 | 把手工固定的图或维数称为发现 |
| 学习原则 | 如何由轨迹推断 S、θ、φ；为何目标与主张一致 | 只有前向 ODE，缺少结构推断原则 |
| 可辨识性 | 哪些激励、时域和坐标下可恢复；何时只得等价类 | 用预测拟合替代参数或结构唯一性 |
| 判别预测 | 相对简单基线新增什么可观察预测，什么结果能推翻它 | 每个版本只问总 risk 能否下降 |

可用统一记号表达：z₀=Iφ(H₀)，ż=f(S,θ;z)，ŷₜ=OΦₜ(z₀)。
先区分给定量、算法选择量与待估计量，再写连贯的估计问题。
每个损失、约束和复杂度准则须有明确的物理或统计职责，任意加权和本身不构成解释。
若 S 完全人工固定、只拟合 θ，称“结构约束辨识”；若在候选库内选择结构，
明确候选库先验与选择范围，不称发现任意物理定律。

## 2. 从第一性原理出发的设计顺序

1. **可观测信息。** 在合法历史窗内能区分哪些模式？如何分别识别初始化误差与动力学误差？
2. **物理平衡。** 写出已知定律、端口和单位，将未观测作用列为明确的闭合对象。
3. **最小充分表示。** 检查共同与差分模式、坐标自由度和记忆需求；用证据说明新增状态的必要性。
4. **最小假说族。** 让竞争结构给出不同的可观察预测，避免多个模块互相补偿而无法归因。
5. **推断原则。** 比较解析、线性、弱形式估计与联合非线性拟合的可辨识性、噪声和偏差；
   明确初态估计、结构选择、参数估计的耦合，不把优化便利当物理定律。
6. **证据设计。** 先定义可推翻主张的结果，再选择实现、适配、辨别与确认所需的最小工作。

结构保证须注明假设、区域和适用对象。同一储能的梯度、全部端口、实际方程和初始化必须一致；
中心化与坐标变换须保持参考平衡及动力学含义。开放系统优先给出端口的作用方向、单位、共同参考、可观测标签和功率收支，再选自由函数。机械、内部耦合与环境允许共享有职责的状态，各模块的同类自由项须有可区分的依据。已证被动的模块可以采用耗散结构。

区分代数消元和动力学消元。前者须核对代数方程与适用条件，后者可能产生历史依赖，需说明是否保留显式状态或有效记忆。短历史初始化应说明合法输入、需估计状态、必要激励与等价类，并用同一方程检验启动误差如何影响未来。精确可辨识性可在候选建立后按主张需要检验。

有效图、隐状态和模型储能按已证明含义命名，
不直接等同于线路、器件状态或 SI 能量。真实系统中的驱动、非被动控制和未建模端口须进入解释。

## 3. 架构简报的评议与采用

Scientist 给出一个主方案、最强竞争解释和最简单基线；只有本质不同的方案才展开。
简报包含学习问题、数学模型与估计原则、已知和学习对象、等价类、关键推导、
最近邻研究差异、判别实验、失败条件、有限工作量和可能的论文主张。

独立 Reviewer 挑战冻结版本：效果是否来自容量、初始化、损失或适配机会？
合法观测能否区分该结构？简单模型是否已经具有拟议能力？
数学保证是否对应实际方程和适用域？已知极限是否连同全部方程、初始化和轨迹一致？

root 记录采用、先做便宜辨别、修订或暂存的理由，保存真实模型调用回执。
不用代理多数票或术语替代推导。审查不可用时，重大采用及强主张保持暂定，
可继续已授权准备；进入新科学 Run 仍按 [engineering_loop](engineering_loop.md) 执行。

## 4. 主张台账与证据链

每项核心主张记录四列：主张；最强已有证据；最强反例或混淆；仍缺的决定性证据。
论证围绕重要问题、明确缺口、独特推断原则、支撑证据与意义组织。
结构恒等式、预测收益、机制识别与稳定性证书分别给证据，不互相替代。

完整证据链是：部分观测下的结构歧义 → 明确推断或选择原则 → 可证明性质或可辨识边界 →
与简单基线的匹配比较 → 与主张范围相符的确认。理论、人工资格与真实系统各承担明确职责。
现有 train 上重复种子衡量优化随机性，不充当外部分布验证；后续新系统或新工况遵守数据授权。
主张随证据收缩或重组，不因单个 Run 未晋升就否定整个 Campaign，也不把工程改进直接称为方法贡献。
五轴判断、确认和晋升条件见 [research_policy](research_policy.md)。
