# 一级算法设计：先确定学习问题，再决定模块

本文件约束设计过程，不指定下一实验结果，也不授权恢复暂停的科学运行。
每次改变状态、闭合族、结构推断原则或主要训练目标，更新一份架构简报；
调学习率、修实现或同一假说内的消融不必再写一份宏大提案。

## 1. 一级结构必须给出的五个对象

| 对象 | 必须说清什么 | 常见误判 |
|---|---|---|
| 信息与状态 | 合法观测 H₀、待预测 y、状态 z、因果初始化 Iφ | 用更多训练标签掩盖部署不可观 |
| 假说空间 | 结构 S、参数 θ、已知约束、允许的等价变换 | 把手工固定的图或维数称为发现 |
| 学习原则 | 如何由轨迹推断 S、θ、φ；为何该目标与主张一致 | 只有前向 ODE，缺少结构发现算法 |
| 可辨识性 | 结构在哪些激励、时域和坐标下可恢复；何时只得等价类 | 用预测拟合替代参数/结构唯一性 |
| 判别预测 | 相对简单基线新增了哪条可观察预测及反例 | 每个版本只问总 risk 能否下降 |

可用统一记号描述问题：z₀=Iφ(H₀)，ż=f(S,θ;z)，ŷₜ=OΦₜ(z₀)。
先明确哪些变量是给定的、哪些由算法选择；再写一个连贯的估计问题。
损失、约束、模型复杂度或证据准则各有物理/统计职责，不能把任意加权和当解释。
若 S 完全人工固定、只拟合 θ，应称“结构约束辨识”；若选择了候选库中的结构，
则声明候选库先验与选择范围，不能称发现任意物理定律。

## 2. 从第一性原理出发的设计顺序

1. **可观测信息。** 哪些模式在 100 ms 窗中可区分？初始化敏感性与动力学误差分别如何识别？
2. **物理平衡。** 写已知输出的平衡式、端口和单位；将未观测作用作为明确的闭合对象。
3. **最小充分表示。** 先查共同/差分模态、规范自由度和记忆阶数；给增维的必要性证据。
4. **最小假说族。** 每次只竞争能够改变不同可观察预测的结构，不先堆多个互相补偿模块。
5. **推断原则。** 比较解析/线性/弱式估计与联合非线性拟合的可辨识性、噪声与偏差；
   初值估计、结构选择、参数估计的耦合必须显式，不能把优化便利当物理定律。
6. **证据设计。** 先定义可推翻主张的结果，再选择实现、适配和确认所需最小实验。

已证明恒等式与“在此 ROM 假设下成立”分开；真实系统可能存在驱动、非被动控制器和未建模端口。
若需要让步，写出让步位置及影响；不能把一切失配都塞进高容量残差网络。

## 3. 架构简报的评议

Scientist 给一个主方案、最强竞争解释和最简单基线；只有本质不同的方案值得展开。
不要求固定数量的平行创意。简报包含：问题、数学模型/估计问题、已知/学习对象、
等价类、关键推导、最近邻研究差异、判别实验、失败条件、成本和可能的论文主张。

独立 Reviewer 先尝试以下反驳：同样效果是否来自容量/初始化/损失或训练机会？
数据是否根本不能分辨该结构？结构恒等式是否允许改变目标失配？
简化模型是否已包含拟议能力？证书是否只在假设未满足的域成立？

root 作带理由的选择：采用 / 做便宜辨别 / 修订 / 暂存。不能用多代理多数票或
漂亮术语替代推导。证据不足可停在辨别阶段，不必须立即训练新模型。

## 4. 对当前项目的具体启动问题（草案，未采用）

当前力记忆族的一个可检验结构问题是：已有空间重分配是否根本无法改变目标共同模态？
若 Q 满足 1ᵀQ=λ1ᵀ，且 ṙ=κω−Qr，则精确有

    d(1ᵀr)/dt = κ 1ᵀω − λ 1ᵀr.

任何左零和的附加输运都保留此式。因此，该族内改边权或增加零和输运不提供新的
共同记忆动力学自由度。此式约束总隐力 1ᵀr，其驱动是未加权 1ᵀω，
不等于惯量加权 COI 频率的独立一阶闭合。它仍可能经其他状态耦合间接改善预测；不能仅凭恒等式宣称
当前瓶颈已定位。该推导也不自动覆盖非零和耦合、非均匀尺度或 p–r 交换。

下一份架构简报应先区分三个解释：共同模态闭合不足、初始化/可观测性不足、优化不足。
使用已授权旧数据的分析或已有人工资格算例可提出判别计划；当前暂停期间不新跑科学实验。
若区分不开，报告“本证据下尚不能区分 / 可辨识性未决”；只有等价构造、秩条件或
理论论证支持时才称该范围内不可辨识。先改善判别设计，不直接加一个共同模态状态。
若确认是结构自由度缺失，再导出最小扩展及其功率账、嵌入极限和可识别参数组合。
弱式投影、模态分解或小规模参数辨识都是候选工具，尚无本包新实验支持其收益。

## 5. 面向 ICML / NeurIPS 的主张台账

每项核心主张仅用四列：主张；最强已有证据；最强反例/混淆；仍缺的决定性证据。
投稿导向是原创性、技术可靠性、意义和清楚定位，不是要求大网络、多模块或无条件 SOTA。
不能把“符合会议倾向”作为更改物理假设或隐藏负结果的理由。

本项目应争取的完整论证链是：部分观测下的结构歧义 → 明确推断/选择原则 →
可证明性质或可辨识边界 → 与公平简单基线的匹配比较 → 超出单一调参场景的证据。
后续跨系统/新工况证据须另行处理数据授权；现有 train 重复 seed 不能充当外部分布验证。
若贡献只剩单系统参数微调，停止“已具备顶会方法贡献”的叙事，保留其工程价值与真实结果。
