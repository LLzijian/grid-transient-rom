# 科学闭环：设计、适配、辨别与确认

保持 Campaign → Run → Job：Campaign 管理有范围的假说与竞争解释，Run 回答其中一个辨别问题，
Job 是冻结输入下的执行单位。算法实例、trial、checkpoint 用 ID 和父引用记录，不另造管理层。
证据规则见 [research_policy](research_policy.md)；当前架构与运行事实分别见
[current_design](current_design.md)、[current_state](current_state.md)。

## 1. 从真实状态与授权开始

核对授权、执行状态、来源 commit、未完成作业与归档、架构，以及 `main code`、
`working_candidate`、`incumbent`、`protected anchors` 四个独立指针。
用户明确暂停时，只完成已授权整理、设计和代码审查；不恢复科学运行。
未释放的 Run 不启动，状态未知先对账，不重放身份或结果尚不确定的 Job，不把历史快照当实时状态。
范围内持续授权按有限协议执行；新目标、部署信息、数据或付费资源按 [kiki](../kiki.md) 的边界处理。

## 2. 架构简报与 Campaign

涉及状态、闭合族、推断原则或主要目标改变，先走 [一级算法设计](architecture_design.md)，
形成 [架构简报](../templates/architecture_brief.md)。Scientist 从第一性原理提出学习问题、
最小结构和竞争解释，Reviewer 挑战冻结版本，root 保存真实模型回执与采纳理由。
小型实现修改引用既有简报，不重复宏观论证。

Campaign 维护假说与范围、架构引用、竞争解释、Run 树、历史信息暴露、已有证据和下一辨别问题。
一个 Run 未晋升不等于 Campaign 失败。历史补录明确标为 retrospective，不补造预登记；
换 ID 不抹去选择历史、已用适配机会或已关闭余额。

## 3. 完整模型的训练、评价与解释

主循环在冻结合同下做有限的完整训练、原分母评价和结果解释。先完成因果初始化、共享动力学和同信息对照，保留可用候选或有明确失败定位的完整尝试。按优先级分析净作用、分项误差与必要结构，删组比较同步重拟合方程与初始化器。设计、合理适配、种子与检查点可在同一 Run 记录父子谱系。

诊断须有可改变的本轮决定和有限停止点。接口与基本数值资格通过后，在明确释放的范围内开展首个预测候选，L2 证书和精确可辨识证明按后续主张需要安排。

### Run 类型由问题决定

| 类型 | 主要职责 | 什么结果改变判断 |
|---|---|---|
| `probe` | 检查实现、数学性质和机制可检验性 | 恒等式或已知极限错误、探针失灵、信息不足 |
| `adaptation` | 检查合理优化与初始化能否改变判断 | 欠优化解释变强或变弱，定位具体瓶颈 |
| `discrimination` | 匹配容量、初始化和合理适配机会，区分竞争解释 | 不同机制的可观察预测分离 |
| `confirmation` | 检查正、负、混合结果的重复性与效应精度 | 主张范围、不确定性或等效判断改变 |

这些是目的，不是固定流水线，也不要求每个方向各跑一次。一个 Run 可含多个 Job 或 trial；
科学比较身份与真实进程身份分开。解析反例和廉价探针可直接回答相应问题。
每个新科学 Run 前，实际调用 Scientist（`gpt-6-astra`），保存简报、来源及 root 采用记录。
工程工作依附其解锁的科学问题，不计作独立物理发现。

## 4. 运行前协议与冻结执行

1. **协议。** 按 [模板](../templates/run_protocol.md) 记录问题、父候选与架构、只改变什么、
   合法输入与历史暴露、匹配对照、主要估计对象、关键事件守卫、数值资格、证据产物与确认设计。
   记录长度随问题而定，强主张须补齐对应统计或证明材料。
   后续 IEEE39 训练登记完整 `train` 的事件身份、批次覆盖与原始 `val` 的验证时点、选点规则及分母。
   新协议随 Campaign 放 `campaigns/`，具体算法方案放 `designs/`，结果和分析放 `reports/`；旧冻结协议保留原身份。
2. **有限计划。** 预先定义比较、初始工作窗口、适配触发条件和上限、停止、转向、重开条件及成本。
   给机制和对照合理适配机会，不将相同步数当作充分公平，也不以首轮必须胜出作为统一后续门槛。
   每次追加适配针对具体竞争解释，保留已用机会，关闭余额不转移。
3. **实现。** Modeler 做最小改变，核查因果输入、坐标、单位、功率、已知极限与适用域。
   Experimenter 用冻结源码与配置执行，保留数据身份、初始化、RNG、优化器、数值和逐事件结果。
   按 [runtime](../agents/runtime.md) 遵守单写者、资源互斥与未知 Job 对账；工具的资格检查不替代真实执行回执。

对于结构发现，协议先冻结候选库、已知约束、输入和参考尺度。用未经删组的父候选建立可复现对照，再比较保留与删除后的充分重拟合。已知真值时报告恢复误差，未知真值时报告可区分的作用、预测差与等价类。把重新拟合迁移、有限适配和冻结参数直接迁移写成不同的研究问题。

## 5. 五轴独立解释与下一动作

分别判断证据有效性、优化健康、优化充分性、机制可检验性、效应与确认范围。
无 NaN、低裁剪和达到步数都不证明充分优化；非负约束下零边或饱和活动集可能是合法最优解，
用可行下降方向、投影梯度、KKT 残差或约束子问题判断，不要求参数全部远离边界。

| 观察 | 合理下一动作 | 禁止跳跃 |
|---|---|---|
| 实现、功率或数值证据无效 | 有界修复或结束无效 trial | 宣布算法族被否证 |
| 梯度健康但充分性未知 | 针对具体欠优化解释适配或暂存 | 把健康当充分 |
| 探针不区分机制或信息不足 | 辨别试验、等价类或可辨识性分析 | 认为延长训练必然解决 |
| 单次有效匹配比较有正收益 | 报告登记条件下效应，按主张规划确认 | 直接声称稳健机制识别或自动晋升 |
| 单次无收益或混合结果 | 据充分性、探针与区间精度选适配、辨别、确认或暂存 | 自动否定或无条件追加训练 |
| 有效匹配、合理适配与相符确认下，区间支持实践等效 | 限定实例与协议作等效判断 | 推出物理机制不存在 |
| 精确数学反例且经独立复核 | 否定对应全称命题 | 扩大到未覆盖模型族或机械要求重复训练 |

实践等效须预登记实际意义界值 δ>0、指标方向、估计对象和不确定性方法，
整个区间落入 [−δ,δ] 才支持该范围内判断；区间过宽保持未决。
确认需求独立于模型晋升，正、负、混合结果均可值得确认。
种子重复衡量优化随机性。重复使用已暴露的 `train` 和 `val` 须披露，独立确认和 `test` 另按授权规则执行。
结果后改变问题、目标或判据，保留旧解释并作前瞻修订，不追溯改写“通过”。

## 6. 防止无止境适配与过早淘汰

连续两个 Run 只有参数微调或工程修复、未减少重要不确定性时，触发内部结构复盘。
root 检查是否仍有可区分预测、是否重复已有证据、是否存在更便宜的替代试验，
决定按有限协议继续或暂存，并记录重开所需证据。固定次数只触发复盘，
不自动否定路线，也不自动要求用户再次批准范围内工作。

不能通过改名、换种子或重启优化器重置机会。重复修复应定位共同根因；
若有限工作不能排除欠优化解释，科学状态是未决或暂存，停止投入不等于否证。
进程与时长配额沿用用户已取消的口径，有限科学工作量和实际成本记录仍须保留。

## 7. 闭合、归档与历史兼容

新 Run 的协议放 `campaigns/`，入口按 `experiments/<run_id>/` 收拢，复用实现放 `src/kiki/`；
正式闭合报告与必要审查放 `reports/<run_id>/`，小体积摘要与回执放 `results/<run_id>/`，
本地产物按 `artifacts/<run_id>/<job_id>/` 保存；只创建实际需要的文件。旧冻结路径依赖不回写。
闭合、新审查、更正或采用变化时，直接核对原始结论与证据，更新 Campaign 对应问题的正文，
删除已过时的当前判断，简记变化与来源，并刷新 Run 导航。定期复核只查漏；无认识变化不另写周报。
尚未综合的新材料明确列为待处理，不以修改时间自动判定最新。命令输出和一般进度保存到执行记录。

每轮独立给出**代码、模型、科学**三个决定，更新 Campaign 的竞争解释与主张台账。
按 [闭合模板](../templates/run_closure.md) 保存正负结果与工作候选，保护已接受锚点；
按 [research_policy](research_policy.md) 选择性提交、普通推送并核验原字节回执。
科学、执行、预算状态分别收尾，归档未确认先对账再进入下一 Run。
已授权且未暂停的范围内，root 按协议自主继续。

旧 `NOT_RETAINED` 保留不晋升含义，不升级为否证；旧关闭余额不自动转给新 Run。
旧 runner 与冻结结果保留原口径：`optimization_unresolved=False` 只对应旧定义下未触发健康报警，
`optimization_adequacy` 仍为 unknown，除非有额外可审查证据。
能力 L1/L2/L3 与五轴判断分开，COMPLETED 和预算耗尽均不表示科学命题已获确认。
