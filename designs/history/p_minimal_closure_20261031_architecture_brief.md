## 2. 一个主方案：一个规范化内部交换状态q

### 已知结构、闭合假说与学习对象

沿当前有效模型坐标，保留δ、ω、p、r及原U、M、D、G、S、κ、Q。δ的运动学关系、既有模型中互易端口的功率抵消是沿用结构；它们不独立认证为高阶系统SI能量。p与r的闭合仍是模型假说。

唯一新增假说是每机一个规范化q，通过反对称交换与p耦合，q自身线性耗散。不添加任意事件驱动、参考偏置或状态门。若将来采用，跨事件共享参数为g,a,b,c；M/S及其余已冻结量沿选定父实例。当前不拟合其中任何量，也不决定改动哪些父参数。

以对角阵G=diag(g)、A_p=diag(a)、B=diag(b)、C=diag(c)、S>0表示：

```
δdot = ω
M ωdot = −∇U(δ) − Dω + G S p − r
pdot = −Gω − A_p p + B q
rdot = κω − Q(δ)r
qdot = −B S p − C q
```

g>0、a>=0、b>=0、c>=0。q是为模型定义的有效内部坐标，不命名为阀位、真实功率或某个器件状态。b>=0只固定q的符号规范；不能由b非零推断某真实器件作用。

这会把每机状态由4个增至5个，完整实现为50维（共同角度规范另行处理）；“最小”只指相对当前一阶p闭合增加一个内部动态坐标，不是已证明全系统最小阶数。只在本候选通过来源/初始化辨别后才讨论实际架构采用，当前40维代码不改。

### 完整功率账与嵌套极限

定义模型储能

`H = U(δ) + 0.5*ωᵀMω + 0.5*pᵀSp + (rᵀr)/(2κ) + 0.5*qᵀq`。

在M、S、κ常量、κ>0、D对称半正定、S/A_p为可交换对角阵、sym(Q)>=0的假设下，直接有

`Hdot = −ωᵀDω − pᵀS A_p p − (rᵀsym(Q)r)/κ − qᵀCq`。

GSp与−Gω、−r与κω、Bq与−BSp分别相消；Q的反对称部分不供能。若实际父Q不满足所需耗散条件，应把其原账项保留而不能套用半负定结论。U的非凸性、目标平衡、正定区域与LaSalle条件另行判断；Hdot<=0不自动给高阶稳定性证书或全局吸引域。

b=0时p方程和原四状态方程严格回到父形式，q与预测完全解耦；取q=0即可精确嵌入父模型。c可为0；不能靠b下界强迫增加阶数。用此有限耦合极限嵌套，不靠c→∞的奇异极限冒充精确原模型。

如为来源比较临时写`pdot=...+u`，必须把`pᵀS u`列为外供能项。u不得以未知残差之名从功率账消失；若实际来源必须保留独立输入，则当前自治候选的对应假设需要修订或暂存，不能悄悄让u依赖事件/未来真值。

## 3. 新增的可反驳预测、可辨识组合与边界

对单机常系数候选消去q，有

`p''+(a+c)p'+(ac+b²S)p = −g*ω'−c*g*ω`。

故若写为`p''+c1*p'+c0*p = −b1*ω'−b0*ω`，本候选要求：

`b1=g>0, c=b0/b1>=0, a=c1−c>=0, k=c0−a*c=b²S>=0`。

这四项约束是新增可检验内容。一般二阶拟合不必满足它们；违反任一项可否定“这些系数由本被动交换候选实现”的具体命题，而不是否定所有二阶闭合。零初态输入输出传递为`p(s)/(−ω(s))=g(s+c)/(s²+(a+c)s+ac+b²S)`；非零q初值另有齐次响应，不能在辨识中忽略。

一阶父模型对应k=0并发生极零抵消；此时c与未耦合q不可由p/ω识别，不应把不唯一c当数值失败。k>0时在充分激励且无退化/采样混叠条件下，可由可识别四系数恢复g,a,c,k；S冻结才可取b=sqrt(k/S)。若S也自由，则b和q的尺度可互相补偿，只能识别组合；本方案固定q储能系数为1消除一个坐标规范，但仍不获得真实器件状态含义。

任意隐藏输入`u=p'+gω+ap`总能使一阶方程成立，这是恒等重写，无区分力。新增状态必须让u满足独立的有限阶动力学和系数约束，才构成机制假说。候选也不排除静态非线性可能用更少状态解释数据；当前来源阶段若明确发现直接状态依赖/限幅，就不能先忽略它来宣称q必要。

**下一Run拟排除的具体混淆**是“tm的输入通路本就含独立时变参考、直接代数输入或额外动态，而我们误把它当单一ω驱动的一阶状态”。来源方程可确认这些通路是否结构上存在、被配置关闭还是unknown；不读取轨迹时不能判断限幅是否实际激活，也不能据控制器名直接认定父残差由它造成。

## 4. 合法初始化：必须联合考虑q与原隐力r

合法信息固定为`H0={δ_j,ω_j,j=0..10; p_10;冻结常数}`。不允许历史p、p'、q、未来ω或事件身份进入部署初始化；元数据只用于离线来源审查。

拟议初始化原则是：在同一完整候选方程下，以合法历史观测确定隐状态等价类，再选择能给出唯一预测的代表。不能单独从`q=(p'+gω+ap)/b`求q₀，因为这里的p'与历史p不在部署输入中。也不能将r固定为真值后声称q可辨识。

先做局部线性数学判别。设完整候选在指定参考状态的线性化为A_full，C_h观测δ/ω，C_p观测末点p，以t0状态为未知量：

`O_h = stack(C_h*exp(−k*0.01*A_full), k=0..10; C_p)`。

离散观测存在唯一完整状态是充分条件，但不是必要条件。准确的问题是：`ker(O_h)`中的方向是否会改变未来目标输出(δ,ω,p)。若这些方向都在未来输出不可观子空间，初值可不唯一而预测仍唯一；若某v满足O_h v=0而未来输出非零，则有该局部模型的合法信息歧义。保存v、两初态与推导，不以正则化选择一个v就宣称歧义被消除。

b=0时q不可观但不影响预测，必须通过这一正确极限；b趋近0时q坐标条件数变差不自动等于输出预测病态。还应区分连续观测的结构可观性与11点采样可观性；高频混叠/退化极点可能只出现在后者。数值满秩不证明100 ms具有足够实际信息，须同时报告尺度定义与输出敏感性，不能把坐标尺度任意放大当信息改善。
