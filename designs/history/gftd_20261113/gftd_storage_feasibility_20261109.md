# GFTD 储能可行性：有界调制与合法初始化的分工

**原指数调制允许储能沿幅值方向趋于负无穷，并存在精确的有限时间逃逸反例。最小修订是在同一储能中将 exp(h) 改为 exp(tanh h)，同步采用全部新梯度。该修订保留5N状态、静态父极限和原核在零点的二阶展开，并使当前自治方程满足全局线性增长，从结构上排除有限时间状态逃逸。合法初始化仍决定预测和局部稳定证书的可用范围。**

## 1. 科学问题与已有证据

问题是：100 ms合法观测给出的隐状态，能否在共享自治方程下形成可分析、可延拓的有效状态？需要分别处理方程是否允许状态逃逸、初始化是否位于局部有效区域，以及这种选择是否预测真实系统。

上一轮五个调制状态在三参考一致区间内增长，末点存在负`beta*psi`及方向一致的幅值反馈；268的stage2历史归一化观测MSE为0.1444988619，stage1为0.2102624210，前者在0.71–0.91 s出现增长，后者在1 s未取得该增长证据。两者同时改变a与r，不能归因于其中一个变量。证据与边界见[最终科学判读](../reports/gftd_long_horizon_diagnostic_20261109/final_scientific_assessment.md)及[独立审查](../reports/gftd_long_horizon_diagnostic_20261109/final_review.md)。这些事实支持结构与初始化分别辨别，不支持直接采用stage1回退或总体预测收益。

本轮直接比较项目内原指数调制、静态父模型及同一事件两个已保存初态。一手文献中，Roth等的[Stable Port-Hamiltonian Neural Networks](https://proceedings.neurips.cc/paper_files/paper/2025/file/48cf746df45ef6f74f53805136b4b348-Paper-Conference.pdf) §3.1 Theorem 3.1在C²凸H、H(0)=0、梯度为0、原点Hessian正定等条件下得到解有界，并在R正定时得到全局渐近稳定（root核查，访问2026-11-09）。由此对本问题作出的区别是：这里保留展开相角和失稳轨迹表达，当前修订只要求有限时域存在，不强加单一全局吸引平衡；能量耗散恒等式自身不代替该文的储能条件。本轮不提出候选核的文献新颖性主张。

## 2. 同一个学习问题与方程

合法观测为11点theta/omega因果历史、末点真实p0与冻结常数。目标仍是共享自治ODE的theta、omega、p预测。状态为`z=(theta,omega,p,a,r)`；theta为展开绝对角，动量为M omega。结构为有效图、幅值调制门和记忆门；它们是待辨识闭合，不等于物理线路或器件状态。

写`c_e=s_edge,e k_e>=0`、`s_e=s_mod,e`、`h_e=gamma_i a_i+gamma_j a_j`、`phi=B' theta`、`eta=B' theta_star`，其中B为节点—边关联矩阵。储能为

```text
H = omega' M omega/2 + p' S_p p/2
    + a' Lambda_a a/2 + r' Lambda_r r/2
    + sum_e c_e Phi_e(h_e) psi(phi_e;eta_e)
psi(phi;eta) = cos(eta)-cos(phi)-(phi-eta)sin(eta).
```

实际代码坐标下，令`J_r=diag(s_mem*j_omega_mem)`、幅值与记忆耗散分别为`R_a(z),R_r(z)`，则

```text
theta_dot = omega
M omega_dot = -H_theta - D omega + G H_p - J_r H_r
p_dot = -G' omega - R_p H_p
a_dot = -R_a(z) H_a
r_dot = J_r' omega - R_r(z) H_r
H_dot = -omega'D omega - H_p'R_p H_p
        -H_a'R_a H_a - H_r'R_r H_r <= 0.
```

当前G、J_r均对角；此式对应实际代码的Lambda_r记忆坐标，不把它误替换成原说明中的归一化记忆坐标。正质量、正局部储能、非负耗散与反对称端口是明确先验；c、s、gamma等共享闭合参数及初态是学习对象。H按模型储能解释，不称SI能量。

本轮所有共享参数和两个初态冻结，不估计新参数。后续若采用新核，训练与初始化必须都使用同一新核、梯度和自治方程；本轮干预诊断不构成已合法初始化的新模型。幅值坐标的正对角缩放等价类仍存在；h在同步平衡附近对观测的作用仍弱，改核不自动增加可辨识性。此处不同时改状态维数、初始化目标或结构选择规则。

## 3. 原结构的两个精确结论

### 3.1 中心化势与指数调制的无下界方向

对单边，若`sin(eta)!=0`，psi沿`phi→sign(sin eta)*infinity`线性趋于负无穷。对完整图不能逐边任意指定phi：固定a时，应使用

```text
U(theta,a) = bounded_periodic_part(theta,a) - theta' d(a) + constant(a)
d(a) = B [c * Phi(h(a)) * sin(eta)].
```

若`d(a)!=0`，取theta=t d(a)即得U→−infinity；若d(a)=0，各边线性项可抵消，不能只由单边斜率断言完整U无下界。

更直接的幅值结论不需要此网络条件。固定某个相角theta*，在简单图中取一条`c_e s_e psi_e(theta*)<0`、两端gamma均非零的边e=(i,j)。沿

```text
a_i(t)=a_i*+t/gamma_i, a_j(t)=a_j*+t/gamma_j,
其他a保持固定，t→+infinity。
```

该边指数为常数乘exp(2t)，其他关联边至多为常数乘exp(t)，非关联边为常数，局部幅值储能为O(t²)。因此

```text
H(theta*,a(t),其他块固定) = C_negative exp(2t) + O(exp(t)) + O(t²) → −infinity。
```

上一轮五个末点的负`beta*psi`与非零端点gamma，提供这个条件命题的实例见证；核对缓存符号和身份即可，不需沿该方向运行轨迹。这个结论是储能几何性质，不等于这五条真实模型轨迹必然有限时逃逸。

### 3.2 允许参数族中确有有限时间逃逸

下述反例由本轮独立Reviewer提出，Scientist与root分别纸面核验；具体审查身份由宿主回执绑定。N=2，单边k=s=1、eta=pi/6、phi=eta+2pi，gamma两端均为1/2，Lambda_a=I、R_a=I，a1=a2=x，初始x=0；omega=p=r=0，其他物理系数取任意满足正性/耗散假设的有限常数。

因`sin(phi)-sin(eta)=0`，theta恒定且omega=p=r=0保持不变；psi=−pi。于是精确约化为

```text
x_dot = (pi/2) exp(x) - x,
H = x² - pi exp(x),     H_dot = -2 x_dot².
```

对x>=0，`x<=exp(x)`，故`x_dot>=(pi/2-1)exp(x)>0`。因此`exp(-x(t))<=1-(pi/2-1)t`，最大存在时间不超过`1/(pi/2-1)`。这推翻“原允许参数族凭耗散恒等式即可保证所有有限初态全时域存在”的全称命题；它不证明上述五个缓存状态爆破，也不否定原方程在局部区域内稳定。

## 4. 最小修订：在储能中定义有界正调制

唯一候选固定为

```text
Phi_b(h) = (1-s) + s exp(tanh h),    0<=s<=1
Phi_b'(h) = s exp(tanh h) [1-tanh² h].
```

尺度固定为1，不搜索。它是新的光滑模型定义，不能作为与exp(h)等价的数值修正；不截断原指数，不单独改RHS，不忽略原模型异常。`Phi_b(0)=1, Phi_b'(0)=s, Phi_b''(0)=s`，与原核零点二阶展开相同。全实数上`exp(-1)<=Phi_b<=exp(1)`、`|Phi_b'|<=exp(1)`；s=0时Phi=1、幅值耦合梯度为0，静态父极限精确保留。采用外层exp保留严格正下界，避免`1+s tanh(h)`在float64负饱和时相消为0。

新的H_theta和H_a必须分别使用Phi_b与Phi_b'；全部机械、p和记忆端口保持原式，功率恒等式随同一H成立。需要覆盖的实现位置是有效耦合、H及全部梯度；旧`gradients`另行求exp的路径必须一并替换。候选保持实验隔离和独立版本身份，原权重/生产路径不覆盖。若未来拟合，旧字典和缓存中硬编码exp的部分另行更新；本轮不走那些路径。

### 4.1 任意有限初态的有限时域存在性

假设维数固定、所有参数有限、M与局部储能系数严格正、tau严格正，耗散门为当前常数或有界局部Lipschitz函数。对展开相角，`|psi|<=C(1+||theta||)`，而`|sin(phi)-sin(eta)|<=2`。因此H_theta全域有界；`||H_a||<=C(1+||theta||+||a||)`；H_p、H_r及其余端口线性，R_a、R_r全域有界。存在依参数而定的有限C，使

```text
||f(z)|| <= C(1+||z||).
```

当前常数或裁剪sigmoid耗散门均局部Lipschitz（分段光滑即可），故f局部Lipschitz。由积分不等式，任意有限T内`||z(t)||<=(||z0||+1)exp(Ct)-1`；有界闭区间上的解可继续，排除有限时间状态逃逸。结论不需要H全域下界。

这个保证不等于长期轨迹有界、目标平衡吸引域、数值积分一定成功或真实预测准确。theta方向的线性势倾斜一般仍存在。反例的同一不变子空间现在满足`x_dot=(pi/2)exp(tanh x)sech²x-x <= pi*e/2-x`，与一般定理一致。

### 4.2 为什么本轮不换相位势

在`cos(eta)>0`时，`psi_alt=cos(eta)[1-cos(phi-eta)]`非负，保留目标平衡和局部曲率；它改变有限偏角的恢复力，从而改变静态父模型。若只在调制项中换势，也会改变Phi=1附近的a梯度与theta耦合。它是另一项有价值的结构选择，但同时改它与调制核会混淆本轮原因。因此本轮保留原psi，仅用有界Phi回答有限时域存在性问题。

## 5. 合法初始化能保证什么

只换初态不会改变第3节的结构反例；但它可以把使用范围限制在有证书的局部连通分支。若eta来自一致theta_star且相位Hessian
`L_eta=B diag(c cos eta) B'`
在去除共同相角后正定，则在`z*=(theta_star,0,0,0,0)`处，theta/a交叉Hessian为0，两种核的Hessian相同：相位块L_eta，其余块为M、S_p、Lambda_a、Lambda_r。原核和新核均可能具有局部正定储能。还需闭合子水平集、前向不变性、下降与LaSalle条件才能称吸引域内估计。

可见的充分区域是所有有效边沿theta_star到theta的线段保持`|phi_e|<=r<pi/2`。该区域psi>=0，且有二次下界。对有界候选，Phi下界为e^-1，若有效图连通，去共同相角后的相位储能有统一正二次下界；加上四个正二次块，可用位于区域内的紧致子水平连通分支构造局部证书。原指数核可在局部有界a域取得正下界，因而也不能因全域反例就否定局部证书。当前共享参数是否满足这些条件，以及可认证rho，均需另行核验；本文未给真实状态颁发证书。

合法初始化应是“在同一ODE与可行集合中解释历史”：端点theta、omega与p0锚定，只在合法历史允许的a/r及必要历史p未知量中求解；目标为历史误差，动力学可行性是明示约束，不用未来真值或事件标签作选择。若给定观测的动能与p储能已超过某个认证rho，因该区域U及a/r二次项非负，改变隐初态也无法进入这个子水平证书；这只说明该充分证书不可行，不说明物理事件失稳或不存在其他证书。

268两个诊断状态来自原核，原stage1资格信息与1 s参考可以帮助检查“历史更低误差是否足够”的竞争解释，不能替代新核的历史重建。特别是原stage2正式返回仍为`state=null`。本轮禁止因候选延拓成功而把旧状态标为新候选合法初始化通过。
