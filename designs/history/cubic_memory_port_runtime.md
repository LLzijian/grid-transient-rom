# 三次记忆端口计算模块

`experiments/cubic_memory_port_runtime_20261021.py`在既有七项结构上提供两个可选项：节点储能`a*sum(q**4)`和既有动量端口`b*q**3`。a非负，b可以为正或负；q沿用当前隐藏坐标。模型保持十机40状态、100ms一次初始化及原有物理方向。

`build_D(source)`复制七项来源，令a和b从精确零开始。两系数按表达式身份定位，使用closure学习率；零系数仍参与求导。`one_update`使用原训练目标和全部实际参数裁剪，Adam后先检查参数、梯度及矩的有限性，再只将a投影到非负范围，保留Adam矩。b不投影。

新增端口进入动量导数为`b*q**3`，进入转速导数为`b*q**3/M`。`extra_port_power(model,z)`返回`sum(omega*b*q**3)`，单位为模型储能率H-unit/s，不是机械功率MW，也不预设正负或称为耗散。新增储能的q梯度为`4*a*q**3`。

优化图缓存保留两系数的梯度连接；field内复用当前状态的q立方，结束、异常、加载或迁移后清理缓存。导出与恢复检查表达式身份、两个系数副本及有限性；a必须非负，b保留符号。通用符号计算和独立NumPy解释器可用于核对。
