## 一句话结论

在**因果 ZOH-ΔPₘ 部署契约**下(训练可用观测 Pm、部署恒持 Pm_clear),把清除后暂态的
降阶建模做成**模块化符号识别**:**永不删除的 M0 二阶摆基座** + 由数据门控的
**能量相容物理模块**——模块包含即模型选择。模型保留可审计的储能结构,可做**从清除态免积分的
候选能量筛查**(三态:screen-stable / screen-unstable / refused;局部候选搜索不证全局逃逸能
下界 → **非证书,不发正式稳定判决**)。315 语料已被多次读取,故其轨迹/筛查结果**仅回顾/探索性**:
在它上面筛查**无非稳被判稳(0/51,仅 9 个独立组,单侧 95% 精确上界 0.283)**;confirmatory 结论
**不存在**,需全新数据集 build + 修正总门 refit 后由预注册单次释放给出(`configs/test_release_v1.json`,
当前 blocked)。同契约下无能量结构的基线(SINDy-多项式 / PINN / LSTM)既追不上闭环精度,
也不具备可审计能量结构。

## 1. 问题与协议

- **动力学**:切除后多机暂态,COI 坐标(消去公共频率漂移),10 机全分辨率,完全图 45 对机对。
- **因果契约**:允许输入仅 `delta0/omega0/Pm_eq/Pm_clear/mass/incidence` + 时变 `Pm`。
  Pm 观测仅作训练 teacher;部署 ZOH `Pm(t)=Pm_clear`。rollout 用共享 RK4(max 内步 0.01 s),
  主表视界 H100=1 s(**100 个积分区间、101 个含首尾样本**)。
- **难度条件化**:按清除后 1 s 内 truth 峰值 |ω| 分 mild ≤0.5 / moderate 0.5–1.5 /
  severe >1.5(rad/s,近临界)。val 是温和开发集,test 覆盖全难度——**必须分难度读表**,
  不给单一折 mean。
- **纪律/证据等级**:outcome label 只用于审计、绝不用于拟合/选择。冻结纪律本身成立,但历史
  E6b/E6c/E8 各自重开过同一 test 语料 → **315 全部结果定为回顾/探索性**,非一次性确认释放;
  confirmatory 需 `configs/test_release_v1.json`(全新 build、claim-before-read 单次读、**禁
  后验角度/阈值扫描**)。

## 2. 模型族与"模块包含 = 模型选择"

**M0 摆基座(永不删除)**:`m_i ω̇_i = ΔP_i − D_i ω_i − Σ_e B_ie·K_e(sinη_e − sinη0_e)`,D,K ≥ 0。

**能量相容模块(互逆被动端口,驱动信号即回力信号,储能恒等式按构造成立)**:

| 模块族 | 形式 | 备选实例(F1) |
|---|---|---|
| NODE_HIGH_ORDER | 每机一阶滞后 h,存储 ½τhᵀh | τ=0.2 s |
| EDGE_MEMORY | 边速 ν 驱动低秩实极点 z,存储 ½τzᵀz | τ=0.02/0.22/1.62 s |
| RESONANT_MEMORY | 边速驱动阻尼振子(q,p),存储 ½(pᵀp+Ω²qᵀq) | (0.20 Hz,ζ0.49)、(0.80 Hz,ζ0.10) |

(NONLINEAR_POTENTIAL / EDGE_DAMPING 两族被提议但无残差支持,F1 未入选。)

- **提议**:基座冻结后,由**无数值微分的积分残差**(1–80 步窗内 ΔPm 冲量 − m·Δω)
  反投影节点/边通道,source 内 fault-line bootstrap(200 抽)相关打分,support ≥0.8。
  中位残差比 1.018——残差冲量与机械输入冲量同量级;这个归一化比值**不能**解释为
  “基座已解释 98%+”,也不能单独给出已解释动力学比例。
- **联合弱式拟合**:整窗积分成线性系统,RHS = ∫ΔPm − mΔω;等 source→line→event→window
  加权;法方程 Cholesky 非负最小二乘 + ridge 网格;可辨识门 + active refit。
- **整块剪枝(模型选择)**:realized-rank=0 端口自动删;每个剩余模块**整块删除重拟合**,
  source×{1,5,10 s} 单元上点估计与 95% fault-line bootstrap 上界须 ≤2% 退化否则保留。
  分层门是方法关键:0.80 Hz 谐振按 pooled 该删(更"简洁"),但稳定长轨迹 source 退化 39%
  ——分层审计保住它对主要稳定场景的作用。内部剪枝结束后,**整个模块候选**还必须相对
  新拟合 M0 基座让总验证误差改善 ≥2% 且失败率不升,否则整套模块候选拒绝。
- **Pm 模块(数据门控、视界依赖)**:零总功率子空间线性端口 ODE,Hurwitz 且 τ≤2.5 s;
  精确 ZOH(A=B=0)是显式候选;≥2% 验证改进才采纳。见 §5 门控结果。

## 3. 能量结构审计与免积分候选能量筛查

**储能函数** H = 动能 ½Σmω² + 基座势 + 模块存储;相对**清除后 ZOH 平衡 δ\*** 平移
(含 ΔPm^clr 线性势,使 H(δ\*)=0)。ZOH 下恒等式 `Ḣ = ωᵀ(Pm(t)−Pm_clr) − ρ`,ρ≥0 → 部署时
H 沿轨非增(由结构 + 供给恒等式的本地数值审计支持)。注意:**"清除储能 < 最低逃逸能量 ⇒ 轨有界、
判稳" 需验证过的全局下界**;局部搜索只给候选,故只作筛查、不发正式证书。

**本地结构审计(继承的 5 折工件全 PASS)**:储能中心化 0;梯度 ≤3e-10;COI(角度/速度)投影
Hessian 最小特征值 **0.1265 > 0**;离散供给恒等式 ≤5e-9。仅审上述量:**hidden 曲率/全局耗散/
全域吸引域/逃逸能下界均未数值验证**(hidden 只按互逆被动构造论证)。

**三态候选筛查(margin=候选临界能量−清除态储能,免积分,非证书)**:
候选搜索完成且 margin>0 ⇒ **screen-stable**;搜索完成且 margin≤0 ⇒ **screen-unstable**;
搜索未完成 ⇒ **refused(绝不判稳)**。候选临界能量 = 局部搜索**找到**的相邻鞍点与 ±η=±θ_max
角边界能量最小值(θ_max=π/2);局部 SLSQP/root 不证搜索完备、可行点是边界最小值**上界**而非
验证下界 → 正式证书状态**恒为 refused**,直至存在验证全局下界(或 BCU 型构造)。

## 4. 主结果

### 主张① 简化模型准确反映暂态(回顾/探索性,分难度)

被消费的 315 test、264 稳定事件、H100=1 s ZOH;数值未被修正总门后的最终模型复现,故为
**探索性**(见 §5):

| 难度 | n | 角 RMSE(rad) | 速 RMSE(rad/s) |
|---|---|---|---|
| mild ≤0.5 | 69 | **0.013** | **0.069** |
| moderate 0.5–1.5 | 40 | **0.046** | **0.190** |
| severe >1.5(近临界) | 155 | 0.378 | 1.231 |
| ALL stable | 264 | 0.290 | 0.947(被 severe 主导) |

### 主张①b 模块选择的继承开发快照(修正总门前;不能确立跨折稳定性)

| fold | val n | val-stable 中位峰值|ω| | 基座 ωR² | 模块 ωR² | δR² | 保留 |
|---|---|---|---|---|---|---|---|
| F1 | 43 | 0.50 | −0.02 | **0.702** | 0.944 | 全 3 族 |
| F2 | 37 | 0.37 | 0.595 | **0.748** | 0.961 | 全 3 族 |
| F3 | 42 | 0.88 | 0.442 | **0.802** | 0.947 | 全 3 族 |
| F4 | 43 | 1.32 | 0.459 | −0.031 | 0.861 | 全 3 族 |
| F5 | 47 | 2.24 | −3.99 | −2.77 | −0.71 | 全 3 族 |

F1–F3 显示模块一致抬升 ωR²(+0.15~+0.72)。但该表为**修正门(checkpoint 早于"新 refit 基座对比 +
总误差采纳门")前的继承快照**:审计显示 legacy F4 候选在修正总门下**会被拒** → 此表**不能确立
跨折选择稳定**,须在修正门后重算;此处仅作开发期定性动机。

### 主张② 免积分候选筛查:被消费 315 语料上无非稳被判稳(描述性/探索性)

| 量 | π/2 | 0.9π |
|---|---|---|
| 候选搜索完成 | 292 | 292 |
| 稳定 → screen-stable | 61 | 79 |
| 稳定 → refused / screen-unstable | 203 | 185 |
| **无非稳被判稳** | **0/51** | **0/51** |
| 不稳定 → screen-unstable / refused | 41 / 10 | 41 / 10(逐事件不变) |
| **stable coverage** | **0.231** | **0.299** |

- **0/51 是描述性/回顾性**:51 个非稳事件只对应 **9 个独立 source/fault-line 组**,0 组被判稳
  → 单侧 95% 精确(Clopper–Pearson)上界 **0.283** → 证据是"本样本零观测",**非零风险/安全保证**。
- 0/51 在 legacy θ_max 扰动下非 knife-edge(41+10 事件集不变),但这是**探索性重验**;confirmatory
  holdout 上**禁止后验角度/阈值扫描**。margin 非严格随角度单调(292 中 18 个下降)→ 属经验筛查。
- 筛查**不发正式稳定判决**(certified 恒 refused,候选搜索非验证全局下界);操作点 π/2 为预注册
  先验选择,不按 test label 反选。代价:覆盖保守(severe 稳定多判不稳/拒),方向保守。

### 主张③ 模态端点(legacy 数值不保留;修正协议为 validation diagnostic)

- **legacy 频响/阻尼数值(~7.2% / MAE 0.04 等)不保留为声明**:它用了选择期验证事件、门禁前的
  模型,并逐事件取**最低误差匹配对**(0003 回归:best-pair 可把误差压低 ~2×)。
- **修正端点**:冻结的最终剪枝模型在解出的清除后平衡线性化,用质量加权转子速度振型,保留一次
  完整 Hungarian 分配的**全部对**,取事件中位数再跨事件宏平均。该协议在 fresh-holdout 释放前
  只是 **post-selection validation diagnostic**;当前 checkpoint 早于修正总门,**不报修正模态数值**。

### 主张④ Pm 自有方程的 legacy 视界诊断(修正门前,待重跑)

| 视界 | 门结论 | 证据 |
|---|---|---|
| H100=1 s | **拒绝**(−2.1%) | 即使非因果 oracle 仅改善 ~1%;ZOH 充分 |
| H800=8 s | **采纳**(+35.3%) | raw rmse 0.0182→0.0118;追回 ZOH→oracle 差距的 74%;谱含慢极点 **τ≈2.0 s**(与 TGOV 调速器 ~2.1 s 一致);89 非零系数 |

> H800 门评估限于 **n=20 条稳定长时程事件**(近临界事件 8 s 暂态超出降阶域,故排除);H100 门为全 43 val。

### 基线对照(E7,F1 val,同契约 H100)

| 方法 | mild+moderate rmse | severe | pooled 闭环 R²(全 43 val) | 能量结构/判据 |
|---|---|---|---|---|
| M0 backbone | 0.071 | 0.882 | 0.313 | 能量结构(无筛查) |
| **modular** | **0.045** | **0.475** | **0.797** | **本地审计 + 候选筛查** |
| SINDy-多项式 | 发散 | 发散 | −1.4e4 | 无 |
| PINN(残差 MLP) | 0.124 | 0.900 | 0.278 | 无 |
| LSTM | 0.346 | 1.404 | −0.90 | 无 |

机制观察:**PINN 点态导数拟合最好(val 残差 0.122),闭环却比它脚下的纯 M0 还差 1.7×**
→ 点态拟合质量 ≠ 闭环外推质量。该对比是**单折、有界预算的开发/探索性研究**,定性支持结构
约束,但不隔离唯一因果机制;凡能量相容结构(物理模块)既能外推又具可审计储能结构。
(此处为 F1 开发折数值,标 exploratory,非 confirmatory。)

## 5. 诚实边界(须与结果同报)

1. **有效域**:max|ω|₁ₛ ≲1.5 rad/s(中轻扰动)精确;近临界 severe 是降阶模型固有边界,
   误差方向保守(发散/过判失步),不构成"判稳漏报"。
2. **筛查非证书、覆盖有限**:screen-stable 是**启发式正判**,既非充分也非必要,不是完备分类器;
   stable coverage 0.231(0.9π 0.299)。正式稳定证书需**验证的全局逃逸能下界**或 BCU 型构造
   (未实现)。混合复核(margin 拒的近临界转有界轨迹复核)会重引入积分,留作未来工作。
3. **证据等级**:所有 315/开发对比为**探索性**——语料被 E6b/E6c/E8 等重开;每数须分难度读,
   pooled 均值被 severe 主导不是 headline;confirmatory **不存在**,待全新 build + 门内 refit +
   `test_release_v1` 单次释放(禁后验扫描)。安全 0/51 仅为 9 个独立组 → 单侧 95% 上界 0.283:
   **非零风险/安全保证**,亦非对未来扰动的前瞻保证。
4. **模态**:legacy 频响/阻尼数值(best-pair)不保留;修正全对端点为 validation diagnostic,
   须 fresh holdout 确认;振型(MAC)未达成(数据侧)。
5. **基线预算**:NN 为 CPU 有界 epoch(PINN 100/LSTM 50,后者未收敛)、单折;更多 epoch
   只缩数值差距,不改结构性弱点。
