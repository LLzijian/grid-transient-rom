# OSGKD：三端作用的联合辨识架构 v1

本文件完成算法与合同切换的阶段一，供 root 集中采用。OSGKD 是研究工作名；当前没有新模型、训练结果或字段覆盖核验。用户本次授权止于阶段一，附件中的自动进入阶段二指令不执行。旧 GFTD 成果保留，旧待办不作为本架构的依赖，也不恢复其科学执行。

## 1. 学什么，先回答什么

从 100 ms 运动历史初始化同一个共享自治模型，联合估计机械驱动、内部耦合与环境交换。第一目标是完整的可初始化预测候选；随后用删组重拟合判断必要作用。稳定证书与唯一辨识证明服务于解释，不作为首个候选开工门。

已知运动学、惯性与核实的作用映射保留；有效图、耦合系数、机械／环境动态及必要支撑由训练决定。节点、候选边族和字典是先验，不能称为发现。IEEE39 十机首版最多 5N=50 维：`x=(theta,omega,p,a,e)`，每组 N 维；不自动增阶，也不排列所有阶数组合。

## 2. 版本化信息合同

**motion_only_v1（主合同）**：输入 11 点、100 ms 的相角和完整转速，以及事前冻结的系统常数、节点顺序和候选图约定。保留共同转速。只去除全局常数角度规范：窗口使用同一个角度偏置，未来沿同一坐标推进，不逐时减去共同转速。

初始化器 `I_phi(H100)=(p0_hat,a0_hat,e0_hat)`；theta、omega 末点取观测值。小型因果 GRU／估计器只产生起点，不读取真实机械末点、机械历史、未来电压／负荷、故障身份、事件长度或逐事件参考曲线。之后共享 ODE 自主推进，不更新真实历史，不逐事件拟合方程。

**known_p0_reference（信息增强对照）**：额外提供经映射的真实机械末点，明确记录该字段和映射。不能把这种历史模型的成绩并入同信息 C0/C1 排名，其 p0 权限不传给主合同。

训练允许使用 train fit297 内既有获准且实际存在的端口标签与未来轨迹，未来只作监督。fit297=267 稳定+30 失稳；不扩到 train385，不打开原始 val/test，不新增 FOM，TASK4 保持暂停。没有新字段覆盖核验；来源包提及的 0048 等历史报告不等于本轮已测覆盖或新性能。

预测条件是来源核实的固定外部参考／既定控制策略。固定 u_ref 可以进入方程，未知未来调度和控制切换不能藏入潜态；若现有样本不满足该条件，记录适用范围与未覆盖，不能悄悄删事件。

## 3. 作用坐标与固定完整参考

在共同同步参考下 omega 为完整转速偏差。采用广义转矩／作用坐标，M 为核实的惯性矩阵、D 为冻结的已知阻尼；其单位、基准和速度映射由端口 adapter 明确。电功率 Pe 不直接等于 te，旧名 Pm 不直接意味着 SI 功率。未核实的 F 不能静默置 I 或认作定律。

只选一个跨事件固定完整参考 `x*=(theta*,0,0,0,0)`。物理参考须来自事前已知运行条件或内部拟合部分，记录来源、坐标和基准，禁止各事件用未来估平衡。若只能采用有效参考，按有效模型约定标注，不称真实物理平衡。所有静态偏置在同一参考扣除，基准作用满足 `tau_m*=Fc*+tau_env*`；不满足时先核对来源或显式承认有效偏置，不能改成随 a 漂移的参考。

下式 tau_m、Fc、tau_env 均表示相对该参考的作用增量：

`theta_dot=omega`

`M omega_dot=tau_m(p)−Fc(theta,a)−tau_env(theta,a,e)−D omega`

`p_dot=f_m(p,omega,u_ref),  a_dot=f_a(a,omega,Bᵀtheta),  e_dot=f_e(e,a,omega,Bᵀtheta)`。

首版机械输出 `tau_m=F S_p p`，F 必须按已有源方程／测量坐标核对，S_p 为正对角尺度。若 F 是旧拟合有效映射则保留其身份；不得继承“旧机械动力学正确”的假设。p 是经机械标签锚定的有效状态，不预称精确调速器状态。

## 4. 内部耦合与开放功率账

N=10 的无向完全候选图共有45条边；固定方向的关联矩阵 B 只定符号。学习有效边，不使用真实线路标签暗示未知图恢复。令 `phi=Bᵀtheta, phi*=Bᵀtheta*`，节点幅值 a 无量纲，参考 a*=0，固定 gamma_i=1：

`K_ij(a)=c_ij−beta_ij+beta_ij exp(tanh(a_i+a_j)),  0≤beta_ij≤c_ij`。

c=0 同时关闭边及调制，beta=0 是完整静态极限。调制核有界且非负，不意味着新增机械和环境方程继承旧全时存在证明。

为使 `Fc=∂theta Uc` 明确成立，先定义 `V(theta,a)=Σ_edges K_ij(a)[1−cos(phi_ij)]`，再在**同一完整参考**定义

`Uc=V−V*−(∂theta V*)ᵀ(theta−theta*)−(∂a V*)ᵀa`。

于是 `Fc=B[K(a)sin(phi)−K(0)sin(phi*)]`，且 `1ᵀFc=0`。这不是 `BK(a)[sin(phi)−sin(phi*)]`；二者相差 `B[K(a)−K(0)]sin(phi*)`。采用前者是固定参考合同，不是宣称已证明旧误差根因。Uc 可以局部不凸，不据中心化自动宣称正定。

令 `H=omegaᵀM omega/2+Uc`，则实际方程的链式账为

`H_dot=omegaᵀtau_m−omegaᵀtau_env−omegaᵀD omega+(∂a Uc)ᵀa_dot`。

最后一项保留为幅值变化与运动—耦合子系统的交换／供能，不强制 f_a 为旧梯度下降。若再赋予幅值子系统储能或端口哈密顿形式，必须另核对相应反作用及端口配对，不能漏项后称全系统守恒。相对转速乘增量作用是该模型的供能率；实际 SI 功率需绝对速度和基准转换，另作核对。

环境输出不强制零和，不强制所有增量耗散非负。实际负荷消耗为正，并不推出相对参考的环境变化或 omegaᵀtau_env 非负。总负荷不能均分成十台机器标签。

## 5. 首版有限字典与潜态规范

全部系数跨事件共享、节点可异质；不得添加自由时间函数或三个任意残差网络。下列模板定义首版最大库，非列出的交叉项、高次多项式和全连接神经动态均不加入。各相位特征均按固定 phi* 扣值，局部输入均用冻结正尺度归一化。

| 模块 | 首版明确的候选项 |
|---|---|
| 每机 f_m,i | p_i、omega_i、tanh(p_i)、tanh(omega_i/s_omega,i)；u_ref 的已知固定偏差有来源时单列，无未知事件输入 |
| 每机 f_a,i | a_i、omega_i/s_omega,i、tanh(a_i)，以及每条相邻候选边的 sin(phi)-sin(phi*)、cos(phi)-cos(phi*) |
| 环境输出 | `tau_env=S_e e+g_env(theta,a)−g_env(theta*,0)`；每个节点 g_env 库为 tanh(a_i)、tanh(a_i)^2，以及各相邻边 cos(phi)；系数有符号，不作零和投影 |
| 每机 f_e,i | e_i、a_i、omega_i/s_omega,i、tanh(e_i)、tanh(a_i)，以及各相邻边的 sin(phi)-sin(phi*)、cos(phi)-cos(phi*) |

g_env 是有效静态电气库；若来源可靠的导纳／电压映射足以支持更物理的幅值负荷项，须在首轮实现前集中冻结替换式及标签身份，不能在看成绩后扩库。上述库不把 e 定义为已消去静态项后的动态残余，因此不额外扣静态导数；以后若改用残余坐标，必须保留 sin(phi)Delta omega、cos(phi)Delta omega 等链式项且只扣一次。

固定 p 的符号和尺度由机械输出 F S_p 锚定；e 的输出系数固定为正对角 S_e，不再同时学习任意 e 输出缩放；a 无量纲、gamma=1，禁止同时自由缩放 a 与 gamma。S_p、S_e、s_omega 只按内部拟合部分的一次预定规则校准、带正下限并随模型导出；缺环境分项时 S_e 是总电气作用尺度下的模型规范，不是环境真值尺度。校准规则与实际值在首轮 Run 发布前冻结，不能逐事件调尺度。

编码器输出初态可采用每坐标 tanh 后乘预定范围；范围是初始化先验，不是状态轨迹硬盒。未来不 clip 状态救轨迹。线性增长核心及有界非线性是首版选择，正式存在性与数值资格须针对完整新方程，不沿用旧证明标签。

机械输出只依赖有锚定的 p；内部耦合只来自该势梯度；环境只用声明的静态库和 e，不复制机械 p 输出或另加任意正弦保守力。不同状态仍可能补偿，这些职责约束不能证明唯一分解。

## 6. 标签缺项与可支持的分解

adapter 首先核对 tm／原 Pm、te／Pe 的单位、符号、参考、速度映射及事件覆盖。机械标签监督 tau_m，总电气标签监督 `Fc+tau_env`。不通过对 omega 求导制造独立真值；积分运动平衡用来检查同一映射，而非补造缺失标签。

若有来源可靠的内部电势、网络及约化信息，可据明确物理近似增加分项监督；必须区分转子、端电压和内部电势相角。使用网络构造标签就声明利用结构先验，不能称仅凭运动恢复线路。

缺可选环境分项时，固定上述字典和参考，继续学习有效分解与净作用；不给未观测 a 伪真值、不均分总量、不把零和投影叫唯一保守交换。必要运动字段或作用映射无法核实时，先修复合法已有来源；不新增 FOM。每个缺失标签有 mask，覆盖分母单列，不能用“较完整事件”替代原297性能分母。

## 7. 完整推断、同信息比较和判断

内部拟合／检查按故障组预先固定；划分元信息只用于分组，不进入模型。参考、尺度、静态初估只使用内部拟合部分。积分／弱形式只提供初始参数或提案，最终接受用同一完整未来目标：

`L=L_rollout+lambda_port L_ports+lambda_con L_consistency`。

L_rollout 是事件平衡、尺度归一化的自主未来运动误差；L_ports 只含真实存在的测量量，避免同一量重复加权；L_consistency 是一个预先定义的短步状态一致性项。尺度、权重、窗口、检查规则在首次科学运行前固定。无分类头、模态罚项或全局稳定罚项。训练未来始终从 motion_only 估计起点出发，不训练用真 p0、部署才删去。

C0 与 C1 都是完整三端模型、同类型初始化器、同字段、同目标和合理适配机会。C0 令 beta=0，a 仍可服务同一环境库；C1 使用上述有界调制且机械参数可学习。C1 保留完整 C0 合法解，并预定一个非零调制初始化，不能用零梯度拒绝调制。二者分别适配，不称参数完全相同的因果干预；报告参数、预算和成本。

可靠预测后，按组删除并重拟合动力学与编码器，先选一个最有价值的组，不做笛卡尔积。训练分数、正 beta 和非零边不证明真实结构。五轴证据及代码／模型／科学三决定沿用现行规则；default none、受保护模型不变。L2 与 L3 按解释需要开展，不成为每个候选的开工门。
