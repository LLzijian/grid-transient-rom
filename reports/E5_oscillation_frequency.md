# E5 技术报告:振荡频率/阻尼辨识(F1 冻结模型)

> 历史保留标记（2026-09-22）：本报告为早期选择期频率/MAC诊断，旧 modal headline 已不再作为当前主张。
> 后续审计见 [0010](accepted/0010_project_conclusion_audit.md)；匹配协议与当前状态见 [current_state](../docs/current_state.md)。

日期: 2026-09-04 · 状态: **频率辨识 PASS / 振型(MAC)未达成** ·
证据: `results/e05/summary.json` · 43 val 事件,test 未打开

## 1. 方法

- **模型侧**:冻结 F1 模块化模型在 **post-clear ZOH 平衡**处数值线性化
  (`solve_postclear_equilibrium` + 中心差分 Jacobian,mass-quotient + hidden
  坐标),特征分解得到可观测正频极点(obs=转子 ω 投影)。每事件 51 个模态。
- **数据侧**:每 val 事件的真实 ω 衰减窗(≤4 s)上跑 **exact DMD**,
  取 0.05–5 Hz 频带(每事件至多 4 个模态;5 事件无阻尼振荡 → 0 模态)。
- **配对**:Hungarian 指派,按频率 + MAC 匹配 132 对。
- 物理过滤:真实机电振荡模态应为低阻尼 —— 只统计
  **两侧 ζ<0.3 的轻阻尼对**(n=101,占 76%)。

## 2. 结果

| 量 | 值 |
|---|---|
| 轻阻尼对(两侧 ζ<0.3) | **101** |
| 观测频带(emp) | 0.66–2.24 Hz,median **1.27** Hz |
| 模型频带 | 0.54–1.40 Hz,median 1.13 Hz |
| **per-event 最佳频率相对误差** | median **4.0%**,mean 7.7% |
| 事件中 <10% 误差者 | **31/34**(有轻阻尼模态的全部事件) |
| 阻尼比(emp ζ vs 模型 ζ) | 0.062 vs 0.089(模型略过阻尼) |
| \|Δζ\| | median 0.038 |
| **MAC(全部 132 对)** | median 0.39,mean 0.36 |
| **per-event 最佳 MAC** | median **0.19**,≥0.8 的事件 **0/34** |

## 3. 科学解读(重点)

- **频率与阻尼被准确捕获**:模型在切除后平衡处线性化的轻阻尼极点,把
  1 Hz 附近的机电振荡频率预测到单事件中位 ~4% 误差,31/34 个含振荡的
  事件都有 <10% 的匹配。这是论文需求③的直接兑现——**模块化模型不仅拟合
  轨迹,还能外推预测系统振荡特征**。旧项目在此步失败(28% 误差);改善的
  根因是:冻结模型的平衡点是严格 post-clear ZOH 解出的鞍点/平衡,而非
  近似工作点。
- **振型(MAC)未达成是数据侧限制,而非模型坐标缺陷**:
  - DMD 激发强度 median 0.17 vs 模型极点 0.844 —— 4 s 衰减窗内模态
    弱激励、阻尼(ζ~0.06,时间常数 ~3 s)把振幅压到噪声层,短窗 DMD 的
    特征向量(形状)不收敛,而特征根(频率)稳健;
  - 10 机 ω 通道上近简并的区间振荡形状本身病态;旧项目 MAC 0.50 亦非
    强同意。报告如实标注:形状级辨识需更长/更强激励窗或状态观测器。

## 4. 局限与下一步

- DMD 窗 4 s ≈ 主导模态 1.27 Hz 的 ~5 周,尚可给频率;MAC 需要 ~10+ 周。
- E6 五折将给出频率误差的折间稳定性(论文主表的频率外推行)。
- 若论文需形状证据,可改用**状态空间子空间辨识(如 N4SID)** 在更长稳定
  轨迹上估计真实振型,与模型 `modes()` 对比。

## 5. 工程注记

- 51 模态/事件 = 18(角度+速度,COI 商空间)+ 33 hidden(模块记忆)维度;
  观测矩阵只投影 ω 扇区,故 MAC 对 10 维 ω 形状。
- Hungarian 会强制一一配对,把弱阻尼模型极点配给重阻尼 DMD 尾模
  (n=31 错配对);统计按阻尼分层,避免把错配计入频率精度。
