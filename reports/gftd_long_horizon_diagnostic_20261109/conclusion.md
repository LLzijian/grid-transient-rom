# 长时数值辨别：积分误差与幅值增长并存

**本轮固定共享参数与10个保存状态，完成46条新积分：五个调制状态在三参考一致的区间内出现幅值增长，同时具有可减少的离散误差。缩小步长能提高局部数值精度，但不足以解释或消除这些状态的增长。初始化选点与幅值反馈结构成为下一步的主要辨别对象。**

范围为train fit297既有模型的9个事件—模型包，其中268保留两个诊断状态；没有重新拟合、重新初始化或读取真实未来。所有误差都是同一模型的数值解差异，不是真实轨迹预测误差。执行与工作量已闭合；模型保留研究候选，`default=none`。

## 2. 静态长时精度与初始化选点

static_027的三参考各自完成15 s，但共同精度只维持至3.84 s。15 s严格Radau与自适应DOP853的观测RMS差为0.000962267、peak为0.0180231，全状态相对最大差为0.00135818，均未通过相应门槛；四档固定DP8在15 s的误差也不单调。因此，该状态的15 s精度仍未决。成功对照static_000与modulated_296均完成15 s且三参考一致。

modulated_048的三参考完成1.10 s；严格Radau使用21750次RHS，解释了该保存状态此前20000次上限不足的问题。这不替代其余10个旧到限点的资格。

268的stage1状态在1 s三参考一致；stage2状态在0.71–0.91 s出现共同增长。两点的观测状态与p锚点相同，隐幅值和记忆初值同时变化。stage2历史归一化观测MSE更低（0.144499，对照stage1的0.210262），却没有更好的自治延拓表现。这支持下一步把动力学可行性纳入合法初始化选择；本轮未实行stage1回退，原正式输出仍为null。

## 3. 零系数求值修正：保留实现，关闭轨迹分支

实验分支只跳过数学系数严格为零的指数求值，保留所有非零项原有的严格上溢、下溢行为。四个人工用例全部通过，包含“仅零项越界”时恢复有限结果的构造用例。

预先固定的20对真实状态共执行40次RHS：10对正常等价，9对保留活跃指数异常，1对未通过冻结判据。未通过的124失败子步在两版中具有相同错误：储能平方项上溢，耦合、梯度与RHS指数上溢；分类器仅接受指数异常，因此记failed。它是异常分类覆盖不足，不能据此声称候选改变了方程或数值值；原判定保留，不事后改门槛。

本批真实状态没有出现跳过零项后恢复有限计算的案例。按[冻结协议](../../campaigns/gftd_long_horizon_diagnostic_20261109/protocol.md)，单点资格不通过即停止，28条条件轨迹未释放、未执行，余额关闭。代码只保留在实验目录，没有替换生产方程。详见[逐点回执](../../results/gftd_long_horizon_diagnostic_20261109/inactive_zero_skip/point_checks/execution.json)及[独立单点审查](zero_skip_point_review.md)。

## 4. 验证、成本与决定

50项首轮及相邻工程测试、3项分支测试通过；人工等价检查计入后续单点预算。独立首轮复核重算了共同区间、网格误差、增长判据与171个缓存功率恒等式，核验184个引用哈希。测试通过与真实状态资格分别判断。

46条积分均留有回执：19条完成、12条RHS数值异常、4条达到RHS上限、11条求解器停止。实际积分RHS为2,046,228次，采样和人工／真实单点为219次，合计2,046,447次。首轮程序宿主墙钟129.831 s，外层宿主131.652 s，worker累计CPU303.078 s；累计worker耗时不作并行宿主耗时。

20对真实检查的科学结果保存完整；外层计时回执在完成后因错误地向哈希函数传入Path而保存失败。原生工具命令墙钟4.014 s，精确函数墙钟和CPU记null；没有为补计时重复计算。[宿主补充回执](../../results/gftd_long_horizon_diagnostic_20261109/inactive_zero_skip/point_checks_host_receipt.json)保留错误与范围。78份原始产物共98,326,340字节留在本地，见[哈希清单](../../results/gftd_long_horizon_diagnostic_20261109/raw_artifacts_manifest.json)。
