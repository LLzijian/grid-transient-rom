# 早期论文：成稿、图表、数字核对与证据修订

**这组档案保存了早期论文从成稿、出图、数字核对到证据口径修订的过程。写作和排版完成曾有明确记录；后续审计又修订了能量证书、test 用途及模态评价的解释。阅读时先确认后续验收，再查看原稿如何组织材料。**

范围：2026-09-04 至 09-06 的写作与维护记录，以及 09-22 的历史标记。
本页于 2026-11-08 追溯整理；不修改 `paper/` 中的正文、PDF、图或文献，也不重新作投稿验收。
研究结果的当前历史解释见[初代模型综述](../early_e_series/README.md)；今天的工作入口见[当前状态](../../../docs/current_state.md)。
