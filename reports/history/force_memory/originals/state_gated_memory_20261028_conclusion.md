## 门确实产生作用，但不是结构识别证据

仅按已登记的C0/C96同轨迹、同参数机制统计：C96稳定/失稳事件的边间门范围时间均值再事件均值约.018877/.932832；与同C状态参数下B匹配算子的标准化力变化率绝对均值约.015546/3.87517，单位为每秒rstar尺度。它说明失稳轨迹上的局部门并非静默，未说明其物理含义正确或能够恢复真实线路。原统计中的事件最大值再组内均值不是全组最大值。

A/B/C端点均非零图，边权总量分别17.722406/22.126393/22.305192，正权数39/40/37；B没有全零控制退化。各组最后48次更新clip及大参数跳变计数均0，原规则未标优化未决；这也不等于证明全局优化充分或模型族能力上限。余弦门在π后可再次开启，不能解释为真实拓扑重新接通。所有实事件恢复同一postfault系统，本轮只检验有效隐力传播，未验证真实39母线线路切换识别。
