# R-memory recovery 结论（2026-10-28）

本次恢复评价完成了 A/25101/step1152 的冻结评价，未进行优化更新。风险按原定义计算：每个稳定样本先求实际时间范围内的归一化点误差均值，再以0.8倍样本均值加0.2倍最差10%样本均值（数量向上取整）汇总；它不是RMSE。物理单位及尺度沿用源证据。

来源曾参与全部train385的训练。本轮fit297与不追加更新的train88均为train发展证据，不是未见数据的确认。原val/test关闭。R0方案见[r_memory_recovery_20261028_protocol](r_memory_recovery_20261028_protocol.md)，可核对数值、范围、源文件路径与SHA的汇总见[recovery_evaluation_20261028_summary](../results/r_memory_20261025/recovery_evaluation_20261028_summary.json)；复现需要本地保留的私有事件缓存和检查点，GitHub不包含原数据。

## 8 秒表现：风险下降伴随漏判增加

在共同 385 个样本上（稳定342、失稳43），A0 的 8 秒稳定风险为 1.6207739755，漏判5/43、误报4/342；A512 为 1.6367144141，漏判6/43、误报7/342；A1152 为 1.1869437293，漏判7/43、误报1/342。A1152 的 8 秒风险较 A0 低约26.8%，但漏判多2例。风险改善不能掩盖关键事件识别变差。

## 保存与成本

旧A训练日志记录1165次实际完成更新，持久检查点为step1152；其后13次没有保存完整模型、Adam及随机数状态。旧正式作业退出原因未知。step1152是本次事前固定并完成评价的最新完整持久检查点。

本次 R0 评价 wall time 为154.5262543秒，其中 Job CPU user 为118.09375秒、kernel 为9.0625秒。这是 R0 的单次成本，不是旧阶段总成本；旧阶段完整总成本仍未知。

## 候选与后续

N/A0、A512、A1152 均保留为科学候选，不构成可用默认模型。下一项结构设计的 source=A512 已在查看 R0 结果前预选，因此本次结果不改变来源，也不切换到 A1152。报告保留8秒风险改善与漏判增加这两项同时成立的证据。
