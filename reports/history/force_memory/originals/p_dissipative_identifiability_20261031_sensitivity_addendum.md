## 2. 精确实数命题与完整证明

以下所有向量范数为Euclidean范数，矩阵范数为谱2范数。A∈R^(m×4)为主Q目标经事件/窗口加权、主Q列缩放后的设计矩阵，v为同权重RHS。γ是实际求解后保存的向量，**无需假定它等于精确最小二乘解**。定义

`r=v−Aγ, r_N=Aᵀr`。

主Q列尺度D固定，L对照用同一D和相同权重。操作性扰动幅值由

`δA=||A_L−A||₂, δv=||v_L−v||₂`

定义。考虑任意E、f满足||E||₂<=δA、||f||₂<=δv，令B=A+E，扰动目标的精确最小二乘解为γ*=B†(v+f)。若

`t=σmin(A)−δA>0`，

Weyl不等式给σmin(B)>=t，因此B满列秩且B†B=I，||B†||₂<=1/t，||(BᵀB)^−1||₂<=1/t²。于是

```
γ*−γ = B†(v+f−Bγ)
      = B†(f−Eγ) + B†r
      = B†(f−Eγ) + (BᵀB)^−1 Bᵀr
      = B†(f−Eγ) + (BᵀB)^−1(r_N+Eᵀr).
```

取范数，得到唯一采用的主界

`||γ*−γ||₂ <= rγ`

其中

`rγ=(δv+δA||γ||₂)/t + (δA||r||₂+||r_N||₂)/t²`。

该式同时包括矩阵扰动、RHS扰动、原目标不相容残差及实际求解的法方程残差。Eᵀf无需另加，因为B†f已整体控制。δA=δv=0时，界退为||r_N||₂/σmin(A)²，仍覆盖实际γ距精确基目标解的误差，不假装r_N为零。

在精确实数前提下，该结论包含扰动球内**任意**矩阵/RHS变化，不仅Q/L两端或其线性插值。这也说明其保守性：表示差只是选择球半径的规则，球还包括不一定来自物理插值的方向。其包含定理不等于实际物理误差落在该球中。

## 3. 为什么在真实读取前选这个界

原正规矩阵路径要求σmin(A)²>2||A||₂δA+δA²，较σmin(A)>δA更严格；它把是否保持满列秩的问题转成更易受条件数影响的正规矩阵扰动条件。本界直接使用扰动后设计矩阵的奇异值下界，更符合“表示变化是否足以破坏估计”的问题。

同时，本界将非零r_N置于扰动后逆矩阵控制中，避免原事后仅加||r_N||/m未论证的放大遗漏。QR/SVD差不等于距精确解的误差，故只保留其独立诊断职责。

这不保证rγ总比原提案数值更小：δA||r||/t²会如实放大残差与近秩退化，结果仍可能很宽或unknown。我们选择的是有完整恒等式依据的单一合同，不是保证R分类出现的算法。未来结果未知不触发换更紧界、球形改椭球或挑另一个表示；如确有新科学理由，须另立前瞻修订，旧结果解释不回写。
