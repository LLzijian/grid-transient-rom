02 / SCIENTIFIC QUESTION要还原的是故障后的动力学，不只是一个分类标签

研究对象是IEEE39系统故障切除后的十台发电机。高阶仿真包含发电机与控制器的动态；低阶模型希望在保留角度、转速和机械功率行为的同时，以少量隐状态表示未显式建模的影响。核心问题是：在100 ms有限历史下，能否发现低复杂度、可自主计算数秒暂态的方程，并让同一方程支持失稳识别和稳定性分析？

研究层级具体交付证据应回答的问题
L1 · 自主暂态预测1/2/5/8 s轨迹、共同转速、机械功率、失稳样本真实区间、轨迹判稳与同精度成本模型是否准确，困难事件是否被识别，合格精度下是否节约计算？
L2 · 结构稳定性同一ODE的储能或证明函数、稳定域内界、初态判据和适用条件哪些初态得到数学支持，是否存在误纳入失稳事件？
L3 · 系统特征可对应的频率、阻尼、物理输出振型和少量结构作用学到的方程保留了哪些有用系统特征？当前为附加成果。

每机物理观测为角度偏差δ、同步坐标转速偏差ω与机械功率偏差p；p=Pm−Pm*。每机再加入一个闭合状态，形成40维。分析时可去共同角度而得到39维，但保留完整共同转速。内部π=Mω用于结构化方程与单位转换，不直接解释为真实机械角动量；q或r也不预先命名为真实器件状态。

04 / MODEL FAMILIES从全局记忆到逐机闭合，再到物理力记忆

0058与C3000：全局三维记忆的33维模型

这两项历史结果采用十机δ/ω/p加3个全局q，共33维。100 ms、11点历史经过20输入、8隐藏单元GRU与3输出线性头；20个输入为十机相对角度和十机转速，末点真实p₀另行进入初态。稀疏特征库包含常数、q、ω、p和工作点中心化边正弦／余弦；记忆动力学写作q̇=ΘΞ，闭合力通过低秩空间方向、幅度与代数特征系数α进入物理方程。

0058固定M3骨架、特征库和拓扑，学习编码器、闭合及辅助电气解码器。C3000从S的稀疏支持出发，继续适配闭合、已有26个耦合、10个阻尼及机械侧rate/gain，固定已知惯性M、工作点和尺度。它不是下述40维逐机储能模型。C3000末端保留Ξ34、α18，有效动力学标量141；该数不含共享观测器／解码器，也不等于全部模型参数数。

符号闭合：q与共享GRU

2026-10-17符号发现研究采用十机各一个q。物理骨架、闭合表达式系数和初始化器共同适配。每台机共享一个7输入、8隐藏单元的单层GRU及线性输出头，得到qᵢ。特征包含惯性中心角度、转速、邻域角度差／转速信息，以及机组惯性、rate和gain相对尺度。共享规律允许不同机器获得不同状态。

编码器不使用历史真实p；物理末点30维状态与q拼接。隐状态采用0.1×[raw(history)−raw(zero_history)]，使零历史对应零隐状态。初始化后神经网络退出预测链，后续由显式ODE推进。

当前力记忆：r与因果积分约束

R_N及A96改用10维有效力r和固定M3骨架，没有联合GRU训练。它们以观测驱动的机械功率／记忆线性系统传播，结合五个20 ms Simpson动量积分约束与10⁻⁴正则估计隐力初态。观测末点δ、ω、p被硬钉，初态求解对参数完整反传。

s = argmins { ‖As−b‖² + 10⁻⁴‖s‖² }
u = Rstars，r₀ = E(0.1)u + v(0)
u表示历史起点r(−0.1 s)；A为五个20 ms区间、十台机动量约束组成的标准化50×10矩阵，b为对应右端。Rstar来自冻结力尺度；E是记忆齐次传播，v是历史转速驱动的特解。使用稳定线性求解，不增加逐事件可训练初态。

R_N恒定传播可用准确矩阵指数；状态依赖传播采用历史线性时变系统，不把“矩阵积分的指数”冒充非对易传播。A96所在共同实现主历史RK4为0.0025 s，细参考0.00125 s；未来主／细步长为0.01／0.005 s。

两种初始化保持相同信息权限，但各自的数值路径不同。共同解析初始化的结构比较，不能单独证明它优于GRU；A96相对R_N还须单列历史求解器差异。旧快速Strang分裂入口与真正RK4是两种算法，报告不能把分裂步进计时写成RK4成本。

06 / SYMBOLIC DISCOVERY从表达式搜索到可独立运行的方程

符号发现以受约束表达式树描述节点储能、边储能和端口作用。语法限制变量、阶次、树深与运算数；边表达式先作端点对称化，再在物理坐标消去平衡点常数和一次项；端口在平衡点归零。储能求导和成对动力学一起生成，删除以整项机制为单位，避免逐行剪枝破坏交换与耗散关系。

08 / MEASUREMENT风险、RMSE与事件计数各自说明什么

原归一化点平方误差同时保留相对角度、相对转速、共同转速与机械功率。设C为惯性中心投影，Δ为预测减真值，sδ=0.47675314588683515、sω=1.0033667249602924，sp为冻结功率尺度：

e(t) = ½{mean[(CΔδ/sδ)²] + mean[(CΔω/sω)²]}
　　　 + (Δωcommon/sω)² + mean[(Δp/sp)²]
ℛ = 0.8 × mean(事件误差) + 0.2 × mean(最差ceil[10%]事件误差)

风险强调困难事件，但它不是RMSE，不能将风险的相对变化写成带物理单位的误差下降。pooled RMSE、事件平均RMSE、尾部统计也采用不同汇总方式；本报告保留原名，避免把平方误差、平方根误差及训练损失混用。

指标解释与必须同时给出的范围
归一化风险基于点平方误差的事件聚合；必须注明稳定／失稳、train/val、时域及样本数。
ω RMSE / p RMSE当前表中ω为共同8 s物理转速RMSE，单位rad/s；p为固定尺度归一化RMSE。
失稳漏检 / 假失步漏检分母为真实失稳事件，假失步分母为真实稳定事件；不能由平均误差抵消。
LOS确认时刻恢复物理角度与转速，机间角差>π且COI相对转速偏差>0.02 pu，连续5点满足条件的首个窗口末端；未触发或不可覆盖保留原因。
同精度成本先通过相应数值资格，再比较同范围推理成本；实现一致性误差不充当预测精度。

当前真实区间≤15 s与8 s分类是两项报告：8 s内检出更多事件，并不保证在每条真实记录结束前就检出。共同确认时机必须用真值与所有比较模型都可定位的相同事件集合，不能比较不同分母的平均时差。

10 / STRUCTURE & STABILITY怎样区分“可解释方程”与“识别了真实机制”

可复查的结构成果已经建立：已保存的方程、初始化器和参数可独立运行；旧S-O向量场重建误差2.22×10⁻¹⁶，三条固定旧train历史8 s的两实现最大归一化单点平方误差2.04×10⁻²⁷。这些是实现一致性证据，不是相对高阶仿真的预测误差。
