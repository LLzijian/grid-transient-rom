# 项目工作与结论审计

审计日期：2026-09-07。模态计算代码提交：`05b8cc8`。

结论：五折重拟合已经完成，模块选择的实现及数值来源明显改善；目前证据
支持有限的开发集相对改善，尚不足以支持稳定泛化、高精度模态辨识或稳定性
保证。主要缺口是结果本身，而不是更多接口或流程规范。

## 1. 已完成的工作及可接受结论

- `e10_refit_v2` 的五折、每折三个阶段均已有结果；15 个阶段的模型哈希、
  上游依赖哈希及逐事件 RMSE/R2 汇总均已复核。
- 模型格式 v4 保存训练归一化尺度，修复了跨阶段载入后采用不同尺度比较
  candidate 与 fresh backbone 的错误。F1 正确改善是 66.3%，旧 96.2% 作废。
- 固定 2% 采用门仅在 F1/F3/F5 通过，F2/F4 回退到主干。
- 严格 H100 指标使用 101 个采样点；事件实际终点约 1 s，不能一律声称精确
  1 s。内部删除审计另按真实 1/5/10 s 观察范围执行。
- 模态重算使用最终模型，保留完整 Hungarian 指派中的所有匹配对，并按事件
  汇总；不再选每个事件的最优匹配。

## 2. 严重结论限制

### A. H100 结果完全没有覆盖不稳定验证事件

212 个验证事件中，177 个达到 H100，且全部为稳定事件；35 个被排除事件全部
不稳定。覆盖率 83.5% 不能转述为“全部事件上的预测能力”。终止长度与结局相关，
这使严格定长评价成为选择后的稳定人群评价。0 次数值滚动失败也不等于准确、
能够预测失稳或安全。数据本身缺少这些不稳定事件的完整 H100 参考轨迹；不能
把模拟预测外推当成参考真值。

### B. 相对改善存在，绝对精度和跨线路稳健性仍不足

| 评价量，177 个稳定合格事件 | 主干 | 最终选择模型 |
|---|---:|---:|
| 合并角度/转速 pooled RMSE | 0.947115 | 0.802558 |
| 事件 RMSE 中位数 | 0.205386 | 0.180801 |
| 合并 pooled R2 | -0.510056 | -0.084279 |
| 角度 pooled R2 | 0.285078 | 0.413923 |
| 转速 pooled R2 | -1.310072 | -0.640956 |

汇总 RMSE 降低 15.26%，但转速预测 R2 仍为负。合并 RMSE 混合角度和转速，
不可当成无量纲物理精度；此处按原指标复算并同时列出分量 R2。

F5 的最终 pooled R2 为 -1.69835，转速 R2 为 -3.02014；它贡献了全部 177 个
事件预测平方误差的 85.37%。最大六个误差来自 Line_35 的稳定近临界事件
`ncunstable_dense_0112/0111/0110`、`ncunstable_0010`、
`ncunstable_dense_0109/0108`。这是待诊断的失效集中区域，尚不能从相关性
推断具体物理原因。

### C. 模态精度有限，且有明确计算失败

177 个稳定且达到 4 s 的合格事件中，167 个成功、10 个失败，成功覆盖率
94.35%。失败全部在 F1，原因是求得的平衡点残差 0.0559–0.2938，远高于
冻结容差 1e-7；优化器返回 success 并不足以证明求解成功。这里的失败也不能
反过来证明真实系统不存在平衡点。

成功事件共 647 个指派对。事件内取所有匹配对的中位数、再对事件取中位数：
频率相对误差 19.49%，阻尼比绝对误差 0.07537，MAC 0.37647。
这些数值以求解成功为条件；内部 assignment coverage=1.0 的分母仅为成功
事件，不能声称原始人群覆盖率 100%。矩形指派也不意味着每个经验模态和每个
模型模态都能配对。旧 7.2%/0.04 标题不能复用。

### D. 结构约束不能推导出稳定性证明

参数非负、互易端口、局部能量恒等式以及某个静态点的正曲率，是受限的结构
检查。它们没有建立全局逃逸能量下界，也没有证明全部事件的稳定域。
现有能量裕度只能作为启发式筛查量。历史 0/51 漏报不等于零风险；该结果仅有
9 个 source/fault-line 组，现有报告给出的单侧 95% 上界为 0.283。

### E. 统计独立性与验证用途限制仍然存在

每折 train/val/test 线路互斥，但验证集用于 ridge 和模块选择，结果是选择后
诊断。近临界源每折仅有一个验证线路组，组自举无法表达跨线路不确定性。
各折训练集重叠，不能把五折当作独立重复实验。315 事件的旧 test build 已被
反复使用，新代码阻止重用并不能恢复其独立性；当前没有新确认性测试结论。

## 3. 验收和接续工作

本审计接受真实负面结果，不接受“普遍有效”“高精度辨识”“稳定性保证”这些
较强表述。`experiments/summarize_refit_v2.py` 从保存的逐事件记录复算汇总，
验证 15 个模型及依赖哈希，并重算全部模态匹配对。它不加载数据集轨迹。
汇总同时保存输入文件 SHA-256，见 `results/e12_refit_audit/summary.json`。

验收检查包括：模态与生命周期回归测试、修改脚本的静态检查、逐事件复算、
模型/依赖哈希、严格 JSON 检查及分母 212=177+35、177=167+10 的核对。
最终全测试 33 项通过；两个修改/新增脚本的 Ruff 及全部源码编译通过；37 个
新 JSON 严格解析通过；模态模型哈希和汇总输入哈希全部一致。
汇总开发时发现不同版本将排除事件放在不同字段，首个未验收草稿误用 177 作
原始分母；已删除该草稿，按 ID 合并并核对每折 declared 数后重新生成。

后续实验优先级：

1. 对 F5 Line_35 与 F1 平衡点失败进行物理残差和输入条件诊断，区分模型
   表达不足、Pm 假设、参数估计与数值求解问题，再决定是否修改算法。
2. 用冻结最终模型完成各事件结构/能量筛查和积分步长敏感性测试；不以一例
   physics_audit 推广到全部事件。
3. 为短不稳定轨迹制定单独、如实限定观察时间的评价；获得完整固定时域真值
   之前不声称具备该人群 H100 能力。
4. 更新论文数值和结论；论文正文/PDF仍基于旧证据，状态文件已明确其过期范围。
5. 算法和终点冻结后取得未使用的测试数据，才能检验确认性泛化结论。
