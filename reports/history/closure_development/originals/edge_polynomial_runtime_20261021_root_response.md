# 独立挑战和首次实现审查决定

root接受有限方案并采纳独立挑战：首次更新/Adam分配/反向与首次完整排名计时保留，科学T取含首次与后3次的最慢值；工程收益仍比较固定后3次中位数。每对操作先恢复共同参数/Adam/全部RNG/批次，恢复开销计入实际作业和单列正式计价，不当作训练更新速度。

冷启动最大×2只覆盖两个科学进程的真实启动/验证/包装，其他30构造、45保存、9恢复、9原始数组/哈希和64JSON仍完整计价。旧整个cost已耗时启动项不沿用到新长benchmark；旧失败结论与费用不改。

新backend采用独立子类，历史源不改；原点c、对称化、export/state_dict、参数/flags/RNG和恢复后新类身份均须实测。首次静态审查后固定稀疏使用轴和图内方向共享，不建立跨更新训练参数缓存。源码和测试完成后统一锁源，当前尚无数值作业。工程收益/科学T双门槛与各类别帽保持，原val/test关闭、TASK4暂停。
