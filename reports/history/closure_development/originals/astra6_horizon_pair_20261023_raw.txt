建议下一轮执行一个固定的“训练时长 × 更新次数”联合比较，直接检验：**当前0.5s拟合窗口是否没有约束住用于结构排名的(2,5]s行为，还是512次更新尚未提供足够适应机会。** 本轮保留原40状态、30观测和100ms一次初始化，不改变潜状态结构。这样能够先排除一个具体、可执行的训练条件解释，再决定是否值得改架构。

读取依据包括AGENTS.md、current_state、engineering_loop、现行协议、selection和evaluate结果。规划时`completion_facts.json`尚未存在，因而不依据尚未取得的学习曲线断言“已收敛”或“仍改善”。现有证据是teacher2最终排名3/6/5，选择3/0/3，所有最终端点数值合格；这支持开展训练条件比较，不支持归因于数值失败或不可辨识。方案文字按anti-defensive-writing的证据范围原则组织。

**唯一执行方案**

| 项目 | 固定设置 |
|---|---|
| 机制 | 原冻结池teacher2与候选3，两者AST和系数参数化不变 |
| 选择候选3的理由 | 它是上轮三个train结果中两次选中的机制；这是明确利用历史结果设计的针对性比较 |
| train数据 | 复用6201/6202/6203已保存、已合格的三组16事件；全部事件参与 |
| 新优化seed | 6301/6302/6303，依次对应三组旧train |
| 训练窗口 | A：0.5s；B：2.0s；均从100ms历史后一次初始化，自主积分，只有前30维监督 |
| 更新数 | 每个模型固定2048次，512与2048为预注册比较端点 |
| 总量 | 2机制×2窗口×3seed＝12模型，24576正式更新 |
| 初始化 | 每个seed下四模型共享可对应骨架、GRU、历史系数初始化；闭合系数均为零，不能注入teacher系数 |
| 优化 | 原分组Adam学习率、batch12、clip100、float64、CUDA不变；逐seed小批次事件索引严格配对 |
| 数据尺度 | 沿用对应旧train前61点冻结尺度；长窗口不得重算尺度 |
| 确认数据 | 不生成新事件，不打开任何val/test；旧合成val不参与选择、归因或确认 |

保留两种机制，而非重跑六候选，是因为本轮回答“teacher相对一个已知竞争机制的排序能否随训练条件改变”。结果不能声称六机制池已经恢复，更不能替代旧三seed一致性门槛。候选0未进入本轮这一事实应直接写入结论范围。

B组损失仍为同一归一化观测MSE，对2s全部观测点取平均，不额外添加长时权重、不加入隐藏状态监督、不重复初始化。A与B的每次更新计算量不同，应同时报告更新数、积分步数和实际wall/CPU；等更新次数不等于等成本。

**固定检查与评价**

1. 开始正式训练前，核验旧train路径/SHA、全部16事件、冻结尺度及原teacher资格；复用有效资格证据，不重生成轨迹。不合格或来源不一致则停止受影响比较。
2. QA验证2s切片准确、初始历史仅100ms、未来观测仅进入损失、平均分母正确、两机制参数配对、四模型批次流一致及有限梯度。一个独立QA seed做两窗口各一次短恢复检验；最多一次明确实现缺陷修复和相关复验。不得依据科学结果修改窗口、学习率或seed。
3. 每模型保存0/512/2048模型、Adam、RNG、计数和完整损失记录；在512真实恢复后继续。不以中间排名淘汰、不选最佳checkpoint。
4. 512与2048均用原数值资格和原排名方法，在全部train事件上报告1s、5s和(2,5]s归一化MSE、弱强组、最差事件、逐事件结果及数值误差区间。最大归一化双步长差仍≤1e-3，原其他资格条件全部保留。
5. 另从同一次已执行的train轨迹汇总(0.5,2]s MSE，用于解释窗口改变作用于何处。这是新增解释指标，不能替换原主指标或旧采用门槛。
6. 数值无效行保留为未决；不删事件、不补尾、不更换seed。某模型数值失败不取消其他预注册可执行模型，但该配对归因不能成立。

**决策规则**

以原区间比较判定teacher与候选3谁更优；区间无法分开则记为不分胜负，不能用tie-break声称结构恢复。

- 同一窗口从512到2048出现一致的teacher相对改善，特别是由明确落后变为明确领先：支持“更新机会影响这一对机制的选择”；不宣称充分优化或全局收敛。
- B在相同端点较A一致改变teacher相对排序，并且2048端点三个seed均明确选择teacher：支持“扩展监督窗口解决了这两个机制在当前train条件下的排序问题”。下一研究应是冻结该训练设置的完整六候选比较，届时另登记未使用的合成数据及其权限。
- 只改善绝对预测误差而未改变结构排序：保留预测收益，结构恢复仍未得到支持。
- 只有部分seed改变：记录配对结果，结论为依赖train条件，不追加seed或更新。
- 两窗口到2048仍不恢复：关闭本轮。若损失仍改善，归为既定更新数内未解决；即使曲线平缓，也不证明观测不可辨识。后续再以一次明确的初始化架构比较研究潜状态估计，不继续叠加同类时长试探。

这里没有“训练到指标通过”的条件。2048是所有合格模型的固定结束点；最多一次按原身份/来源保存的非择优中断恢复，不重置更新计数。无任何进程数量或时长上限，实际费用归入累计账本。

**可复用实现与解释边界**

沿用`bounded_edge_grammar_20261022.py`的冻结池、配对初始化、来源核验、检查点恢复和数值排名；新建独立薄实验入口，显式传递训练窗口，不能改写旧协议、旧目录或全局常量。现有Job/身份与清理机制继续使用。新增代码仅需针对窗口和配对的检查，不重跑旧18×512、384测时或旧全套QA。

这一设计能区分窗口与更新次数的作用，但不能单独证明可观测性：长窗口同时增加监督信息、积分长度与优化难度；潜状态估计与动力学仍联合变化。复用旧train和历史选出的竞争机制意味着本轮是针对性的开发研究。即使全部排序改善，也不能改写旧失败、称为独立确认或默认采用模型。root应在执行前冻结采纳协议；完成后保存全部结果并选择性归档，任何路线采用再做独立范围审查。
