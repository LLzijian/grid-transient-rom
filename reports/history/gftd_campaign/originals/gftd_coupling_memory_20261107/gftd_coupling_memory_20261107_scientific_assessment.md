## 负校准给出的信息边界

66个单测试函数设置全部不能辨别c。每事件3行由其3维指数记忆初态列完全张成，多事件共享c也无法解除这个行空间覆盖；这给出了现有单弱方程接口的确切障碍。四个测试函数增加同11点上的约束，不等于增加独立观测。

两个无噪E0的c_hat均为null，符合沿窗F≡0的平坦负校准。含噪E0却产生非零力列：single_0在sigma=1e-6和1e-4分别估47.5820153716与47.5820153746；single_4相应为3.53508744614与3.53508744619。三阈值秩判断稳定，主细求积没有数值未决，但这些是噪声伪辨识。二者不是同一个E0随噪声幅度从47降到3.5，而是两个不同固定噪声方向，各自在两档幅度下近乎不变。

可用解析小噪声展开解释这一现象，不新增实验。假设真实E0全部零、eta=0、s=0，固定一个噪声方向并按sigma缩放，p_end=0，p/r_f重建为固定线性算子，Z与噪声无关且秩固定；不发生浮点阈值切换。由于正弦力为奇函数，分段线性插值和固定求积不改变阶数，A(sigma)=sigma A1+O(sigma³)，b(sigma)=sigma b1。令P_Z为记忆列投影，a1=(I-P_Z)A1、d1=(I-P_Z)b1，若a1非零，则

    c_hat(sigma) = (a1' d1)/(a1' a1) + O(sigma²)。

profile曲率随sigma²缩小，但估计中心趋于由噪声方向决定的比值，并不趋于真实c；||a_perp||/||A||也趋于非零方向比。因此在有限精度尚未触及绝对数值底噪前，降低噪声幅度或收紧相对秩阈值都不必消除伪辨识。若a1=0或秩发生切换，需另分析高阶项，不能套用上述极限。该推导解释数据中的稳定伪值，不证明对任意噪声分布的具体估计概率。
