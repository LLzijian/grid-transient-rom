# 单共享耦合参数的弱形式辨别结果

在固定边形状、关闭动态调制的人工三机系统中，使用完整功率与记忆端口、四个弱测试函数，可以从 11 点、100 ms 相角/转速历史及末点真实 p 中分开估计一个共享耦合尺度 c 与各事件记忆初态。两个无噪共享批次的 c 绝对误差分别为 0.00003633、0.00004621，均通过事先规定的 0.01 要求。

这一步把已知参数初始化推进到一个未知共享参数的辨别。方法先由合法转速与末点 p 重建功率，再把记忆写成受迫项与自由初态的指数衰减项；在弱动量方程中联合求解 c 和记忆初态。估计器没有使用真实 c、真实记忆轨迹或样本类别。共享批次按预定实验条件组织，不把参数值传给估计器。

| 无噪批次，细积分网格 | 真实 c | 完整端口估计 | 遗漏 p 端口 | 遗漏全部 r 项与初态列 |
|---|---:|---:|---:|---:|
| A：E1/E2/E3 | 0.7 | 0.70003633 | 0.91311153 | 0.78674486 |
| B：E1/E2/E3 | 1.3 | 1.30004621 | 1.51348157 | 1.38643496 |

上述数字为无量纲耦合尺度，不是轨迹 RMSE。两个错误模型的偏差分别约为 0.213 与 0.086，说明这些样例中省略端口会使耦合系数吸收其他物理作用。E3 是 E2 的无噪符号镜像，三事件批次不等于三种独立动态激励，也不保证共享估计优于每个单事件。

单个弱测试函数的全部 66 个设置都不可辨识。原因是每个事件只有三条弱方程，而三维自由记忆初态已能覆盖全部方程；增加具有独立记忆初态的事件仍不能解除这个欠定性。四个测试函数在同样 11 点上形成更多积分约束，没有增加传感器观测。这个结果针对所选弱投影，不表示整个 100 ms 观测必然不含耦合信息。

无噪平衡样本自然返回 c=null；真实零耦合、非平衡样本的估计为 -0.0000008372，绝对偏差 8.37e-7。估计没有强制保留一条边，也没有将负数截成零；本轮检验的是无约束线性估计，尚未采用物理非负约束。

含噪结果揭示了另一种边界：矩阵秩稳定并不等于物理信息足够。

| 观测噪声 sigma | 批次 A 的 c 估计 / 绝对误差 | 批次 B 的 c 估计 / 绝对误差 |
|---|---:|---:|
| 1e-6 | 0.69953537 / 0.00046463 | 1.30009274 / 0.00009274 |
| 1e-4 | 0.65008129 / 0.04991871 | 1.30434665 / 0.00434665 |

相角和转速噪声的实际标准差为 0.1×sigma。每条轨迹使用一个固定人工高斯方向，两档强度配对；这些结果没有噪声成功率含义，0.01 精度要求预先只用于无噪共享批次。

两个平衡样本在非零噪声下分别给出约 47.582 和 3.535 的 c，且在两档强度下几乎不变。它们通过三种相对秩阈值和主细积分检查，却没有恢复真实耦合的依据。噪声同时扰动了系数列与目标，产生了可求解的假信息；不能靠延长优化、仅检查相对秩或把越界值截回物理区间来宣称解决。下一问题应检验相对观测噪声的信息强度，允许证据不足时不输出确定参数。

全部 9 个条件通过真值辅助端口资格；18 份主/细网格检查的最大尺度化弱残差为 4.44e-10，细网格 p/r 重建误差分别不超过 1.69e-8、1.15e-8。这里的真值辅助资格与合法观测估计分开，不能把前者称为部分观测恢复。132 组主细比较无积分未决；c 最大差 2.12e-6、尺度化记忆初态最大差 1.34e-6。264 个输出均无阈值敏感标记，仍需保留上述噪声伪辨识结果。

本轮正式执行一次：9 条人工条件各生成两个历史网格，共 18 份；27 个观测包、54 次合法端口重建、264 个线性问题，运行器耗时 3.686 s。没有迭代训练、未来预测、执行后修复或重放。最终 26 项工程资格通过；释放前两次资格累计 12.46 s。求积在运行前由独立解析检查改为 Boole，原协议与前版实现字节均保留。
