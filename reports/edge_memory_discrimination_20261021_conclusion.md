# 两种边记忆方程：预测通过与机制选择

余弦H项为aΣ kbar(q_i+q_j)[cos(φ+δ_i−δ_j)−cosφ]；正弦项为aΣ kbar(q_i−q_j)[sin(φ+δ_i−δ_j)−sinφ]。两者新增项均不含π，保留运动学。kbar固定为原始边强度除均值。潜变量q及系数可与初始化器、交换和耗散共同适配，拟合系数不能直接对应teacher器件参数。尚无删除整个边闭合后重新适配的对照，因此不声称该项必要。
