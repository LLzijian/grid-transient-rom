**核导数及整球界。** 用c_e表示有效边系数，beta_e=c_e*s_mod,e，避免与核K混淆；K(h)=exp(tanh h)，t=tanh h。直接求导得到

```text
K' = K(1-t²)
K'' = K(1-t²)(1-2t-t²).
```

设b=h_max<=1/4。由|tanh h|<=|h|<=b，可得`1-2t-t²>=1-2b-b²>=7/16`，故K''>=0。又由exp(u)>=1+u、exp(b)<=1/(1-b)，有

```text
1-b <= K(h) <= 1/(1-b)
0 <= K'(h) <= 1/(1-b)
0 <= K''(h) <= (1+2b)/(1-b).
```

最后一项用到`1-t²<=1`和`1-2t-t²<=1+2|t|`，并未把K''误当K。上述界适用于局部球，不能推出K全域凸；旧代码允许h达到1/2，在h=1/2处tanh(h)>sqrt(2)-1，K''已为负。因此旧指数证书直接接收bounded模型并不成立。

边集必须精确使用 `E_K={e:c_e>0}` 和 `E_beta={e:beta_e>0}`，不按浮点阈值将小正数删去。连通性、相角域、Kmin和图谱下界使用E_K；h_max、导数与混合项使用E_beta。对后者取`Gamma_e=|gamma_i|+|gamma_j|`，则在原未归一化5N商空间球内`|h_e|<=R*Gamma_e`。E_beta为空时b=0，点能量直接使用静态系数，跳过核包络。静态边不能因为无关gamma导致exp区间域检查失败。

在舍入中心theta_c处，记delta_e=|phi_c,e-eta_e|、`A0=max_EK(max(|phi_c|,|eta|))`。球内边角变化不超过sqrt(2)R<=1.5R，所以`alpha=A0+1.5R<7/5`给整个phi至eta线段上cos>=1-alpha²/2>0，从而psi>=0及`psi<=(delta+1.5R)²/2`。这些是相角的固定局部坐标条件，不使用角度取模后再拼接证书。

连通图上`ell=4*c_min/[N(N-1)]`是有效下界：相角均值为零时，方差不超过节点值域平方的1/4，而最大最小节点间一条不超过N-1边的路径控制该值域。因此局部块界为

```text
m_theta = (1-alpha²/2)*(1-b)*ell
m_a = min(lambda_amp)
C = sum_Ebeta beta*Gamma*(2R+1.5delta)/(1-b)
det = m_theta*m_a-C²
mu = min(det/(m_theta+m_a), min(mass), min(storage_p), min(lambda_mem)).
```

混合块常数中的2来自两次sqrt(2)，1.5保守包住sqrt(2)；beta和gamma均未遗漏。由于psi>=0、K''>=0，幅值附加Hessian是非负秩一项，H_aa>=diag(lambda_amp)。det>0时，det/trace是正2×2比较矩阵最小特征值的下界。其余块保持原状态坐标，不把归一化历史误差坐标或质量加权观测坐标当成此欧氏球。

Hessian上界中的幅值项必须写成

```text
D = max(lambda_amp)
    + (1+2b)/(2*(1-b))*sum_Ebeta beta*Gamma²*(delta+1.5R)².
A = 2*sum_EK c/(1-b).
L = max(A+C, D+C, max(mass), max(storage_p), max(lambda_mem)).
```

该L依赖已经成立的正Hessian和比较矩阵行和界。旧D漏掉的`1+2b`不能省略；新版草案已修正。它为以后合法的确定性误差球提供上界，不自行产生epsilon；sigma=0、历史残差小或优化器成功都不是隐态误差界。

**舍入中心与真实局部平衡。** 从存储浮点theta、eta转换为精确有理数并作精确算术平均，不会自动满足eta=B^T theta_c。原代码保留delta及

```text
g = 1.5*sum_EK c*delta + 0.5*sum_Ebeta beta*Gamma*delta².
```

这确实上界中心的完整商空间梯度范数：新核在h=0处K=K'=1，原中心相角／幅值误差界仍适用。不能把g设为0，或把H-H(c)未经证明称为正定能量。

若整球强凸下界mu成立且g<mu*R/4，球面径向梯度严格朝外，闭球中H的唯一极小点z*位于内部，且`||z*-c||<=g/mu<R/4`。球面上

```text
H(z)-H(z*) >= mu*(R-g/mu)²/2 > 9*mu*R²/32 > rho,
rho = mu*R²/4.
```

因此真相对能量V=H-H(z*)的球内rho子水平集紧致且不触球面；耗散恒等式保证其正向不变。H(c)>=0由本地角域的psi>=0及正储能给出，强凸性再给`H(z*)>=H(c)-g²/(2mu)>=-g²/(2mu)`，所以原形式`H_upper+g²/(2mu)`仍是V的保守上界。严格球门与该上界小于rho足够认证实际返回点。无需在本轮额外数值求解H(c)或精确平衡能量来成立此充分条件。

LaSalle论证还要求原严格耗散条件：所有damping、rate_p正，幅值和记忆耗散有球上一致正下界。零耗散要求omega=p=r=0、H_a=0；要保持其中还须omega_dot=0，得到H_theta=0，强凸性排除第二个驻点。结论是到真实局部平衡相位轨道的距离趋零，公共theta本身未必收敛到某个指定角；z*也不必正好是舍入中心。构造器允许某些零耗散参数，此时此充分证书应返回未获证，不能直接判失稳。

**真实核的严格有理区间。** 旧`l2_point`包络的是exp(h)，并非exp(tanh h)；例如h<0时tanh h>h，旧指数值会小于真实核，不能当成新核的严格上界。新方案先用有理Taylor界包住E=exp(2h)，验证其下端点为正，再利用(E-1)/(E+1)在E>0上严格递增，将两端点映射为t区间；最后分别包络两个t端点的exp。|2h|<=1/2，且外层端点经检查仍在(-1,1)，所以原19项指数级数及几何余项界可用；三角包络的Lagrange余项界也保持有效。

每次向外量化必须使用有理数的整数floor／ceil，特别是负下端点不能用向零截断。固定2^-128网格分别降低下界、升高上界，再进行区间加／乘和有符号缩放，仍包住真实值。外层指数前及每个完整函数／能量累加后量化，可控制嵌套Fraction分母；不可先转普通float再声称向外舍入。量化误差可能使极小裕度无法认证，这应记未获证，而不是临时提高精度、放宽门或改用点估计。量化后的指数域、E分母正性和区间顺序仍需固定人工有理边界检查。
