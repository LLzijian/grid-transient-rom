## 方程、单位及功率账

沿用当前物理坐标x=(delta,omega,p,r)，内部pi=M omega，40维。令Sp为固定正定对角储能矩阵，G为原jpi_p对角矩阵，Ap=Rpp Sp。源能量中的p与r部分为

    H_pr = p^T Sp p / 2 + r^T r / (2 kappa).

定义能量归一化坐标y=Sp^(1/2)p、z=r/sqrt(kappa)。kappa是全局正标量，不随轨迹时间变化。增加

    y_dot|exchange = +gamma z,
    z_dot|exchange = -gamma y.

gamma单位为1/s，允许正负。转回物理坐标，完整方程为

    delta_dot = omega,
    pi_dot = f_pi,base(delta,pi,p) - r,
    p_dot = -G omega - Ap p + gamma/sqrt(kappa) Sp^(-1/2) r,
    r_dot = kappa omega - Q r - gamma sqrt(kappa) Sp^(1/2) p.

两项必须由同一个gamma与同一个尺度变换自动生成，不能分别拟合或漏掉sqrt(kappa)、Sp。新增功率为

    (Sp p)^T [gamma/sqrt(kappa) Sp^(-1/2)r]
    + (r/kappa)^T [-gamma sqrt(kappa) Sp^(1/2)p] = 0.

因此原连续功率账保持，仅改变内部能量转移；不额外制造耗散或能量。原点仍为新增项的平衡点，原p观测含义及物理单位不变。非单位M的动量转换保留。连续功率恒等式不构成非线性L2证书，也不保证RK4有限步长全能量单调；gamma还可能增加快振荡，必须通过原数值资格。

这是每台机器p_i与r_i同位置的统一交换，gamma一个标量，方向固定I。没有新的空间图或可旋转字典。r通过动量方程的负号固定为物理力坐标，p为观测锚定坐标，不能任意翻转r同时把gamma符号解释成新的物理方向。保留标量kappa与固定Sp排除任意缩放自由度。即使如此，有限数据下gamma与其他参数仍可能相关，不声明唯一真实参数恢复。

## 必须重新推导的耦合历史初始化

原先独立反构p的方程在gamma非零时失效，禁止沿用。只允许原11点delta/omega与末点p0；历史真实p、未来、RHS标签均不读取。整个初始化仍只有10个未知力初态自由度。

把v=(p,r)写成20维受迫线性系统：

    v_dot = T v + B omega,
    T = [ -Ap,                    gamma/sqrt(kappa) Sp^(-1/2);
          -gamma sqrt(kappa)Sp^(1/2),              -Q          ],
    B = [ -G; kappa I ].

以末点0为参考，在t∈[-h,0]、h=.1s上反向传播：

    v(t) = exp(T t)[p0;0] + integral_0^t exp[T(t-s)] B omega(s) ds
           + exp(T t)[0;r0]
         = vbar(t) + Z(t) r0.

积分的方向必须保留；omega仍按每10ms线性插值，使用增广矩阵指数算分段仿射强迫，不以T逆乘小差分实现。vbar与Z的p/r块分别记pbar、rbar和Zp、Zr。这里r0为未知末点物理力，p0为已知末点；不是把20个端点全变为可调参数。

当前base_momentum_field对p为线性：

    f_pi,base = c(delta,omega) + G Sp p,
    c = -grad_delta U(delta) - D omega.

故五个20ms区间的动量积分方程为C_j r0≈b_j，其中沿用同三点Simpson：

    C_j = Simpson_j[ Zr - G Sp Zp ],
    b_j = Simpson_j[ c + G Sp pbar - rbar ] - M(omega_right-omega_left).

关键是C同时包括p随r0改变的贡献；漏掉-G Sp Zp会错误地把耦合当成已知历史输入。C单位为秒，b为力×秒。令Rstar仍取原力尺度，W_j=diag(1/(.02*rstar))，A堆叠W_j C_j Rstar，b堆叠W_j b_j，r0=Rstar s。

为使gamma=0真正退化到原估计器，正则必须仍约束历史起点r(-h)，不能悄悄改成惩罚r0：

    r(-h) = rbar(-h) + Zr(-h) Rstar s,
    F = Rstar^(-1) Zr(-h) Rstar,
    q = Rstar^(-1) rbar(-h),
    s = argmin ||A s-b||² + eta ||F s+q||²,   eta=1e-4.

对应增广最小二乘为[A;sqrt(eta)F]s≈[b;-sqrt(eta)q]，以可微QR或稳定线性解实现，不显式求逆。等价正规方程为(A^T A+eta F^T F)s=A^T b-eta F^T q。F随参数变化，q不假定为零，全部相关反传必须保留。

gamma=0时T分块对角，p反构退化原独立p方程；r(-h)与r0之间是可逆仿射转换，且正则施加同一r(-h)，故新旧初态问题在数学上相同。这一性质需要实际零gammaQA验证，不能凭公式跳过。部署硬钉观测delta0、omega0、p0，只加入求得的r0，随后单次自主推进；反构历史是模型条件估计，不称真实隐藏轨迹。

反向传播的病态性与正则贡献须记录。若20维指数或初态解数值不合格，受影响事件/模型未决；不读真实p修复、不加窗口、不改eta、不把低残差当成参数可辨。初始化矩阵满秩也不证明gamma可辨。

## 采用前程序与已有方法

root在完整当前轮闭合后记录实际选中端点、来源SHA、可学习参数、全部信息暴露和本方案采用/不采用依据。采用前进行一次未负责本设计/实现的有界独立挑战，重点核对交换项单位与符号、耦合初态的边界条件/正则等价、仍改善来源的匹配继续训练、工作量及关键事件停止规则。挑战不需再做全项目认证。

原val/test关闭；本轮train88只作不追加更新的train发展报告，来源曾见全部385。TASK4暂停、新FOM条件0、原指标/真实时间区间及旧科学分类保持。无新物理仿真验证，无真实线路真值主张，无L2自动证明。本补充仅推荐一个结构问题，不重新启用原两图分支。

公开基础：[van der Schaft，Port-Hamiltonian systems: an introductory survey](https://doi.org/10.4171/022-3/65)及[Port-Hamiltonian systems: network modeling and control of nonlinear physical systems](https://research.utwente.nl/files/26331785/CISMpaper.pdf)给出功率保持互联与反对称结构的成熟框架。本方案的+gamma/−gamma结构是该框架的一个最小实例；价值必须由这里的共同自治、因果初态与关键事件对照建立，不凭结构形式声称首创。历史线性未知量的消去仍属成熟变量投影思想，[O’Leary与Rust](https://www.cs.umd.edu/users/oleary/software/varpro.pdf)提供相关原理；此处具体贡献待检验的是满足已知末点p0、未知10维r0及原历史起点正则的耦合实现。

最终建议：不执行原二图筛查。等待当前轮完整结果，在预定来源与能力触发成立时，检验共同40D系统内单个p–r互易交换，并以同初始化器、同原参数继续训练的零gamma模型作为主要对照。该试验能够直接回答新增状态连接是否改善关键事件，而不以事件模式位替代共同物理系统的结构表达。
