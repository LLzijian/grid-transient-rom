## 为什么不能只给输出加一个小修正

在精确算术中f_parent(theta)=f_joint(theta,0)，因此f_parent+[f_joint(theta,gamma)-f_joint(theta,0)]确实是同一数学函数。完整保留theta的三条计算路径，gamma只作用于第一个joint项，也可以保持正确导数。

但当前history_system不仅输出r0，还输出s、A、F、q、历史轨迹及驻点条件。若只给r0加偏移，而其余量仍来自原QR解，则r0不再等于Rstar s；若同步改s而不改系数，则原(A^T A+eta F^T F)的驻点残差增加H delta_s。1e-12量级的r0差可被H放大，不能凭“最终J变化很小”忽略。单独把残差报告也改成基准差分，会使报告与实际返回历史/系数不一致。这种局部修饰不合格，禁止以它把旧断言变绿。

新单位区间指数消除了1/dt斜率的数值放大，并通过独立反向流参考；旧父路径使用另一组矩阵指数、时间方向、坐标和正规方程。数学等价不保证float64下逐位一致。现有结果符合舍入路径差异，但尚未用高精度证明全部差异由父指数单独导致，报告应保留这一因果边界。

## 本次曾分析、最终不执行的统一实现

记高精度单位区间联合反构为

    [p(t);r(t)] = [pbar_g(t);rbar_g(t)] + [Zp_g(t);Zr_g(t)] r0.

取h=.1，L_g=Zr_g(-h)、d_g=rbar_g(-h)，改用原父估计器的未知量u=r(-h)。若L_g可解，则r0=L_g^(-1)(u-d_g)。不用显式逆，以线性solve生成下面的仿射系数：

    P_g(t) = Zp_g(t) L_g^(-1),
    R_g(t) = Zr_g(t) L_g^(-1),
    p_g^*(t) = pbar_g(t)-P_g(t)d_g,
    r_g^*(t) = rbar_g(t)-R_g(t)d_g.

于是p(t)=p_g^*(t)+P_g(t)u，r(t)=r_g^*(t)+R_g(t)u。归一化表达中的F、q依赖完全包含在L_g和d_g及其solve里，禁止detach。若L不可数值求解则未决，不换边界条件或增加未知量。

gamma=0时，这四个精确数学量分别为父模型的p历史、0、r前向特解v和E。在同一参数theta、同一实际历史下，分别计算父数值版本(p_parent,0,v_parent,E_parent)、joint(gamma)及joint(常量0)。定义一套统一系数：

    P_hat = 0        + (P_g - P_0),
    R_hat = E_parent + (R_g - R_0),
    p_hat = p_parent + (p_g^* - p_0^*),
    r_hat = v_parent + (r_g^* - r_0^*).

所有gamma均走同一公式，不写if gamma==0，不按样本或测试点分支，不使用近零阈值。zero上下文使用独立常量0而保留同一theta；不能把整个实际gamma分支复用为zero分支后让gamma梯度相消。gamma=0时两个joint值计算可逐位一致，但计算图仍不同：实际分支必须保留gamma导数，zero分支不含gamma。

接着从这同一套历史系数生成唯一拟合问题，而非对输出打补丁：

    C_hat = Simpson[R_hat-G Sp P_hat],
    b_hat = Simpson[c(delta,omega)+G Sp p_hat-r_hat]-M Deltaomega,
    A_hat = stack(W C_hat Rstar),
    beta_hat = stack(W b_hat),
    a = argmin ||A_hat a-beta_hat||²+eta||a||²,
    u = Rstar a,
    r0 = r_hat(0)+R_hat(0)u.

全部物理历史用p_hat+P_hat u和r_hat+R_hat u重建，残差和正则直接由这个实际拟合问题计算。为了零gamma沿用父数值语义，这次唯一实现使用父模型的正规方程solve及相同算术排列；不在gamma非零时切QR，不再扫描求解器。零gamma原父正规方程已用于已登记模型；新gamma范围仍须检查条件数、驻点与独立参考。

此坐标的正则是eta||Rstar^(-1)u||²，与addendum的eta||F s+q||²完全相同。未知量仍10维，终点p0仍硬约束，数学方程和估计器没有变化。P_hat(0)=0、p_hat(0)=p0，历史起点R_hat(-h)=I、r_hat(-h)=0，均应在原数值容差内实际验证。不能以强行覆盖某些节点掩盖不一致。

父计算必须作用于当前theta的同一张自动微分图，不能创建脱离theta的参数副本。父history_system内部有动态方法分派，直接super().history_system可能调用子类_history_context并混淆语义；应使用明确限定父实现的无状态算术helper或等效functional调用，且父源码文件保持不动。缓存分别标记parent、joint(gamma)、joint(0)，必须包含所有参数/输入和梯度模式依赖。

## 梯度、成本和后续动作

数学上hat函数=joint函数；theta导数为parent_theta+joint_gamma_theta-joint_zero_theta，gamma导数来自joint_gamma的完整路径，包括L/d、F/q、p历史及拟合解。任何no_grad/detach、零点硬返回父值、只补前向不补反向或人为规定gamma梯度均不允许。有限精度差分会消去接近量，可能降低极小gamma增量的相对精度；这是需要上述同一次中心差分与残差检验的原因，不能称基准差分普遍提高精度。

初始化新增父路径和joint(0)路径，实际成本必须计入。矩阵/线性系数可在同一参数上下文缓存，事件特解仍按各自历史计算；不减少自主轨迹成本口径。该修正不改ODE场及RK4，不采用当前未合格fast入口，不修改科学预算。检查为CPU合成算术输入、0optimizer、0真实事件访问，不取得训练、CUDA或真实来源资格。

## 最终复议：不同比较主张成立，不是旧门槛通过

1. 旧门槛针对的是“新初始化器作为旧来源的严格drop-in替代”。这项主张仍失败，不替换来源，不把6FAIL改成PASS，旧实现和结果都保留。新的主张是“同一联合估计器下增加gamma是否有效”，其主要对照是C1与C0，不再用F与C1的差直接归因于gamma。

4. 当前正式科学比较、来源选择与训练尚未开始；因此这属于在独立挑战后对未来协议的明确修改，而不是在新科学结果后移动胜负门槛。已有prototype检查当然已经提供实现证据，其失败不隐藏、不改编号救回；本次改变的是不再追求失败的替换主张及其应用范围。若未来任务仍要求drop-in替换，该阻碍依然存在。
