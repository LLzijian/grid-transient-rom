## 2. 数学结论

| 命题 | 审查判断与精确范围 |
|---|---|
| 完整图相角方向无下界 | 固定a后，周期项有界，线性项为 `-theta' d(a)`。`d(a)!=0`足够；单边斜率非零不能替代完整图条件。简报正确区分了边差约束和节点相角。 |
| 负活跃边导致幅值方向无下界 | 简单图中两端gamma非零时，该边沿指定方向增长为负常数乘 `exp(2t)`；其他相邻边为 `O(exp(t))`，二次项为 `O(t²)`。推导成立。缓存符号是该条件的实例见证，不能据此认定五条实际轨迹爆破。 |
| N=2有限时间逃逸 | `sin(phi)=sin(eta)`使theta固定且omega、p、r零子空间不变；a对称子空间给出 `x_dot=(pi/2)exp(x)-x`，`H_dot=-2 x_dot²`。从x=0起的比较不等式确证有限时间逃逸，范围是允许参数族中的一个精确反例。 |
| 新核正性、二阶一致 | `Phi_b=(1-s)+s exp(tanh h)`在 `0<=s<=1` 时位于 `[exp(-1),exp(1)]`，其一阶导数有界。关于h的零点值、一阶、二阶导数为1、s、s；这是零点二阶一致，不是有限h下与原核等价。 |
| 静态父极限 | s=0时调制恒为1，耦合对a的梯度为0；再取a=0不变子空间，保留原父模型映射。任意非零a仍携带独立幅值储能与衰减，不应把任意5N状态都称为原4N父状态。 |
| 任意有限初态全时间存在 | 有界Phi使 `H_theta` 有界；有界 `Phi_b'` 与 `psi=O(1+||theta||)`使 `H_a=O(1+||theta||+||a||)`。现有耗散门有界且局部Lipschitz，其余端口线性，因此完整RHS满足线性增长界；有限时域延拓论证成立。 |
| 局部证书与初始化 | 去除共同相角后的相位Hessian正定、其余储能块正定以及交叉块为0的条件正确。给定相角线段位于 `[-r,r]`、r小于pi/2时，可用cos(r)给出psi二次下界；仍须验证子水平连通分支、前向不变性和收敛条件。没有为268颁发证书。 |

新核的全时间存在性不依赖H全域下界。它也不推出长期幅值一致有界、展开相角有界、目标平衡吸引域、固定步长精度或浮点求值一定成功。保留相角势的线性倾斜与证明全局存在并不矛盾。

引用的Roth等论文定理已与原文核对：Theorem 3.1针对无输入端口系统，以凸C²储能、原点函数值与梯度为0、原点Hessian正定等条件推出有界性，并在耗散矩阵正定时给出全局渐近稳定。简报没有把该结论套用于当前非凸中心化势，引用范围合适。[论文原文](https://proceedings.neurips.cc/paper_files/paper/2025/file/48cf746df45ef6f74f53805136b4b348-Paper-Conference.pdf)

## 3. 科学释放前的阻断项

**R1：固定跨核比较的时间范围，并取消或定义增长布尔标签。** 协议v1第5节的主要量包括A、h、Phi范围，但原stage2的三参考合格终点为0.92 s，候选目标为1 s。若分别在各自完整区间取范围后直接比较，会同时改变核和统计时长，不能解释为同一时域的核替换效应。

每个保存初态应前瞻固定 `T_pair=min(t*_old,t*_new,1 s)`，跨核范围与变化比较使用共同0.01 s网格上的 `[0,T_pair]`；每个核自身完整合格区间、终点及是否完成1 s另外报告。`T_pair<0.10 s`时保持比较未决。原核历史增长窗口作为原证据单列，不因新核区间更长而改写。

v1中的“A是否翻倍”“原h是否增长”还未给出基线、窗口与A(0)=0的处理。可以明确这些规则，也可以删除布尔标签，仅报告固定窗口内的A(0)、A(T_pair)、最大A及差值；A(0)=0时比率为null。后者已经足够服务本轮估计对象，不需要增加判据或轨迹。

补充实施边界：求解器调用计数和失败后输出前缀的单元检查仅使用mock；不得为测试计数器或输出保全而增加人工ODE。v1已经禁止人工ODE，建议在修订稿中把这两类检查也写明。

Root已在审查过程中接受R1，由Scientist保存v1字节并修订协议；本报告保留此次阻断，不以之后的修订覆盖原判断。

- 八个人工候选单点固定了状态、门配置、差分步长及验收门。极大正负幅值只用于候选单点，原核不在这些点求指数。无人工ODE，N=2反例不数值重演。
