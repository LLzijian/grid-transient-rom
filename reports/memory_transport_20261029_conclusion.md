# 固定平面记忆转运：共同128步结果

**任务已完成，科研按用户要求暂停。** 固定二维平面上的保守转运S已激活，但在登记的共同128步比较中没有获得关键事件或失稳风险收益，原决定为 **NOT_RETAINED**。A/S/P均不延长，不启动第二种子。三组端点、曲线及不利证据保留；本轮不晋升模型。

## 问题与比较

本轮检验：在40维力记忆模型中，加入一个固定平面的反对称交换，能否改善自治预测和关键事件识别？来源为N_M192→SGM A_28311 step96（A96），冻结源码为`181d7f8bba2eb530a0ad5afe0130035755e974a2`，保护参照为R_N。三组使用同一来源、seed30311和登记的训练计划。

- A：原对称传播续训，47个可训练标量，`rdot = kappa*omega - Q*r`。
- S：增加`s*K`，48个标量；`K = uv^T-vu^T`，平面在来源上固定。
- P：增加非负`d*P2`，48个标量；`P2 = uu^T+vv^T`。该项可能由原图的对称系数表示，因此P不构成独立容量匹配。

完整定义、停止门和实现证据见[协议](memory_transport_20261029_protocol.md)、[Astra设计](astra6_force_structure_next_20261029.md)、[独立挑战](force_structure_next_20261029_challenge.md)和[最终公开包](../results/memory_transport_20261029/completed_stage_public.json)。

## 优化、机制与停止决定

三组均完成128次更新。固定train48面板含36稳定、12失稳，0/64/128曲线和原延长门见公开包；64→128不足以同时满足收益与不恶化保护门，因此均不延长。A的5s稳定风险从64步的0.479956到128步的0.510258，超过原105%保护线。三组128步的`optimization_unresolved=false`，无最后64步裁剪或大幅参数跳变；这项程序诊断不等于证明已达到最优或整个模型族收敛。

S端点`s=-0.2294914241 /s`，说明转运项已被优化激活；P端点`d=0`。CPU数学与人工资格34项、真实CUDA配对3项、三组完整数值资格及六次固定性能配对均通过，108次Adam恢复QA参数/Adam差均为0。恢复QA使用两条17/23个时间点人工记录、每次0.02s，不能描述成108次完整8s训练任务。原守卫首次失败、修正和启动身份门失败均保留，见[资格与QA包](../results/memory_transport_20261029/qualification_and_qa_public.json)及[恢复记录](memory_transport_20261029_prelaunch_recovery.md)。

支持的判断是：**这一来源、固定平面、单种子与登记优化范围内，未观察到S的能力收益。** 非零s不构成真实物理结构识别；本轮没有跨来源或多种子证据来否定一般非互易记忆机制。

## 方向审计
