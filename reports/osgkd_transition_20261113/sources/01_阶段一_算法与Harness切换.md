# 阶段一：从 GFTD 切换到 OSGKD 的最小控制面重构

## 1. 本阶段只完成一件事

让下一位接手的 agent 读完活动入口后，不再自动返回“固定旧机械方程，继续调制补偿探针”的路线，而是进入三部分作用的联合辨识。

这是用户作出的研究优先级调整，不是对 GFTD 整个模型族的否证。不得以“先把旧问题全部证明清楚”为切换前置条件。

不新增调度平台、证据评分框架或全套安装器。保留既有 Campaign → Run → Job、五轴证据、三个决定和四指针。以下文件是有理由的局部修改清单，不意味着把每个文件整篇重写。

## 2. 先做一次真实状态对账

- 核对最新科研 HEAD、工作区未提交变更、真实 host 作业、锁、待归档产物及现有活动源码冻结。
- 基线 `9dec0976` 下，固定线性补偿界工作仍未释放科学执行；活动状态写的是 implementation_only，不能简单把 RUNNING 当成正在跑科学计算。
- 若实际仍未执行：撤销其下一科学动作排队，保留已采用设计、实现和审查，记录“因用户转向而暂存，科学问题仍未决”。
- 若已有实际执行：不在未知状态下杀进程或重跑；保存输出并在安全边界收尾。只能对已实际完成的内容写 COMPLETED。
- 未用工作量关闭，不自动转入新 Run；新计划登记自己的有限工作量。
- 旧 GFTD 源码、checkpoint、结果、反例与数值资格保留。仅改变活动指针和后续投入，不重写冻结协议、结果状态或身份哈希。

### 一页收束总结必须保留的事实

1. 有限 K4 条件下静态结构恢复有正面证据，不能外推为任意网络恢复。
2. 原无界指数调制有储能无下界与有限时逃逸反例；有界核与同步梯度修订是可复用成果。
3. 最新匹配预测已实现297/297初始化原六门通过，不能再拿旧46/297与1/297描述现状；长时资格和预测收益另算。
4. 有界调制在真实区间多检出4个失稳事件，但完整可比risk未支持整体收益；三个稳定事件的数值未决不能写成误报修复。
5. 24包历史目标的0.135%改善不是未来预测收益。
6. 96.8%的补偿是某个局部方向的观测变化范数消减，不是预测改善或不可辨识性证明。
7. 旧模型的机械方程、初值信息、调制/记忆假设和训练范围写清，不能自动赋给新算法。

将这份总结放入已有 GFTD Campaign 的当前综合或一个关闭报告，并链接原证据；不要再复制整库。

## 4. kiki中建议采用的新核心条款

### 新部署合同：motion_only_v1

- 输入：11点、100 ms的相角与完整转速历史，以及事前已知并冻结的系统常数/图候选约定。
- 不输入真实末点机械量p0、历史机械轨迹、未来电压/负荷、故障身份或逐事件参考曲线。
- 初始化器输出机械侧、耦合幅值和环境记忆初态；观测末点角度/转速不被随意改写。
- 未来用同一共享ODE推进，不重读真值、不逐事件拟合动力学参数。
- 当前预测以数据来源核实的固定外部参考/既定策略为条件。未知未来调度、控制切换不能由任意隐变量“预知”。
- `known_p0_reference`仅为明确标注的信息增强对照；其真实p0权限不自动传到motion_only。
- 训练可使用fit297内已允许且实际存在的端口标签和未来轨迹；字段缺失保持缺失，不生成新FOM补齐。

### 开放物理合同

- 用作用/转矩坐标写动量方程，明确与电功率、速度、标幺基准的映射。
- 内部互易交换可以零和；环境输出不得被强制零和；总负荷不等于逐机负荷分配。
- 守恒/供能关系优先于全系统储能非增；已证明的被动子模块可保持耗散，不强迫所有控制与负载偏差被动。
- 动态耦合的参数变化供能或内部反作用必须入账；不能漏掉相关项再声称功率守恒。
- 正的实际消耗可以有负的相对平衡变化；不对所有增量环境作用施加非负约束。

### 科研优先级

第一目标是一个能可靠初始化和自主预测的完整候选；第二目标是删组重拟合后的必要结构；理论分析服务于这两个目标。稳定证书、精确可辨识证明和跨系统论文实验不作为首个候选的前置流水线。
