# 阶段二：在 IEEE39 上完成一个三端作用辨识算法

## 1. 一个主问题，不再展开研究树

在相同fit297与合法观测条件下，OSGKD能否把机械驱动、内部耦合和环境交换更合理地分工，并由100 ms角度/转速历史启动可靠的未来预测？

本轮首先做完整能力模型，然后解释和简化。人工小系统只做实现单测；标准藏本基准、跨系统实验、完整文献复现和论文排版暂缓。旧GFTD补偿界不作为本轮依赖。

## 2. 第一项工作：打通数据—作用—状态接口

这项工作并入同一首轮准备，不拆成一串独立Campaign。

### 需要核对的最小数据表

| 类别 | 使用方式 | 不允许的替代 |
|---|---|---|
| theta/omega时间序列 | 历史输入与未来监督 | 不用未来辅助输入、故障ID、长度标签决定模型行为 |
| tm或原Pm字段 | 机械侧训练标签，经统一映射 | 不自动称SI功率，不进入motion_only输入 |
| te/torque、Pe及既有来源 | 总电气侧训练标签及平衡核对 | 不把端口Pe直接当te，不把未存字段写成已覆盖 |
| 负荷、电压、网络、损耗或对应已冻结派生记录 | 有来源时用于分解和监督 | 不新增FOM，不把总量均分成虚构逐机标签 |
| 已保存基线及评价器 | 参照与共用评分 | 不将不同历史合同的数字直接合并排名 |

数据缺项分两类：核心theta/omega和必要标签映射缺失时，先完成本地来源修复；可选环境分项缺失时，按02中明确的有效分解继续，不伪称唯一物理恢复。读取权限限fit297及既有获准来源；不自动读取全部train385或原val/test。

产物只需一张端口映射表和一个可复用adapter，说明单位、符号、参考、已知/估计/未识别、样本覆盖以及恢复父基线的必要变换。

## 3. 完整候选与最小比较

### C0：同信息的静态耦合基线

OSGKD同样的三端分工，机械侧参数允许辨识，环境作用保留；只关闭动态耦合调制。使用与C1同类型初始化器，无真实p0。

### C1：三端完整候选

同一静态/环境作用合同、同一数据及初始化类型，允许已定义的有界动态耦合。机械方程不冻结为旧M3，环境不强制零和。

C0/C1是两套完整的、合理适配后的方法，不能声称参数完全相同的单项因果干预。应报告实际参数数、可训练范围与适配机会。

### 历史参照

保留A512_M192、R_N、A96或最新确有可复现产物的相应参照，绑定准确hash与评价器。它们使用真实p0时标注为信息增强参照，不作为同输入对照。M3/C3000仅作必要历史背景，不重复弱基线复现或旧恒定/真实未来机械输入实验。

若要判断“减少传感器”本身的代价，可先只为一个冻结成熟ODE训练同信息初始化器；不要对三个历史模型各建一套新架构。

## 4. 研究实施顺序

### 任务 A：最小实现和资格

建议新增或集中修改：

- `src/kiki/data/osgkd_ports.py`：分项数据映射与白名单；
- `src/kiki/models/osgkd.py`：三端共享ODE、初始化、输出和导出；
- `src/kiki/models/osgkd_identification.py`：积分初估、统一联合目标、有限删组重拟合；
- `experiments/osgkd_ieee39_pilot/run.py`：薄实验入口；
- 对应定向测试。

这些是建议路径，落地时优先复用现有模块，不搬动冻结旧实现。不要让src依赖旧实验runner；可复用公共函数才抽取。

资格检查：端口单位/符号/平衡；相移与节点重编号一致；机械和环境不得相互复制相同自由项；有界调制静态极限；固定参考中心化；动态耦合供能项；因果泄漏；求解器和梯度；保存恢复与独立导出。只做支持本轮接口的有限单测，不建立新论文基准。

单元测试通过后就进入训练，不等完整吸引域或全部可辨识性定理。

### 任务 B：一次完整训练—评价循环

1. 将fit297按故障组预先固定内部拟合/检查划分；缺少足够组时披露，不把同组窗口拆到两侧。
2. 只在内部拟合部分校准参考、尺度、静态分解和动态初估。
3. 训练小型初始化器，估计p/a/e初态。重点同时记录净作用误差，不能只看p或e各自误差。
4. 联合适配共享动力学与初始化器，训练目标直接包含自主未来运动及允许端口监督。
5. 保存学习曲线和多个登记检查点；选择依据预定内部检查规则，不固定取末步，也不在最终全体评分后挑最好步。
6. 在原分母上评价C0/C1完整1/2/5/8 s、共同频率、机械/电气侧误差及失稳真实区间；所有失败事件保留。

训练可使用同一100ms宽度的滑动窗口，窗口之后真实序列只作为目标；原启动窗口与局部窗口分开记录。未来未知控制不是由真实输入喂入的隐性teacher forcing。

主工作窗口与有限续训触发在执行前按实际成本冻结，不能简单继承旧192/200步上限作为充分性。每次续训须针对明确解释，并同时给对照合理机会。

### 任务 C：重复性与必要结构

完整候选有可用结果后，固定方法与训练规则，使用预定三个种子报告全部结果。三个种子只衡量优化随机性，不构成独立泛化确认。

选择最有决策价值的一个删组比较开始：通常先删调制或驱动非线性；删除后重新训练方程与初始化器。若收益清楚，再检验另一个重要组。不要一次排列机械×耦合×环境×阶数×初始化器的笛卡尔积。

未改善的候选也可安排有理由的重复或优化诊断，不只给首轮赢家确认机会。

## 5. 失败后只沿这一顺序处理

| 现象 | 下一动作 | 不允许的结论 |
|---|---|---|
| 源端口积分平衡本身不一致 | 核对同一字段/尺度/参考与积分；保留所有事件 | 直接发明隐藏状态掩盖数据映射 |
| 较充分端口信息下，有限字典仍有大失配 | 审查静态项、动态闭合单值性与必要状态；一次最小结构修订 | 自由加多项式阶数直到拟合 |
| 端口可解释，history-only初态误差显著 | 改进同一因果估计器；必要时做固定模型的真实初态敏感性诊断 | 一次GRU失败就宣布100ms信息不足 |
| 历史很好、未来差 | 先看共同目标、梯度/步长、错误反馈与自由响应；保持首个完整候选 | 又转成只研究历史目标微小下降 |
| 增益只来自少数事件，失稳恶化 | 明确权衡，检查目标与真实时机，不删困难样本 | 用稳定均值替代整体能力 |
| 数值主细不一致 | 在冻结模型和初态上区分求解器/时间尺度与连续动力学问题 | 将失败自动归为真实系统失稳或模型族无效 |
| 所有合理适配后仍无法分开作用 | 报告有效净作用/等价类，停止强机制解释 | 输出看似物理但无证据的唯一结构 |

有界调制避免了旧指数逃逸通道，不意味着新增机械/环境动力学继承原全时存在证明。实际解与离散求解分别检查；必要的更合适求解器可在新协议前瞻固定，旧结果不追改。

## 6. 评价和采用规则

### 完整分母优先

原fit297=267稳定+30失稳。初始化失败、数值未决、无足够历史、未判定分别列出；不计算不同子集的“总体排名”。原risk不是RMSE。真实失稳窗口与固定8秒分类分开，时机只在共同可比事件上比较。

先完成数值有效的完整候选，再谈比值。允许记录达到合理适配后仍失败的完整尝试，不为通过而改门、裁剪状态或填补真值尾段。

### 两条独立判断

1. **算法收益**：C1与同信息C0比较；可用预先规定的稳定5/8秒风险改善界值（例如5%，须在Run发布前确认）和关键事件保护，报告端口误差、时机、共同频率和成本。不能由单指标晋升。
2. **工程能力**：与使用真实p0的既有强参照比较，明确少测量的收益/代价。未超过信息增强参照不自动否定算法；有关键风险退化也不得以信息少为理由采用。

保持default none和受保护模型，研究候选只有完成约定确认和审查后才讨论采用。L2/L3暂作有需要时的解释，不作为每个训练trial都要重算的门。

方法固定后用全部fit297重拟合时，重做全部仅限训练的校准；新r/e坐标随静态部分变化时同步更新标签和初始化，不能混用旧分解。结果仍是开发成绩，不伪称独立测试。

## 7. Agent组织与持续推进

- Scientist/root：集中确定三端分解、动态假设、统一目标、对照和何时适配。先一次架构审查，之后小改动引用它。
- Modeler：负责模型、估计器与导出；端口adapter可由另一个worker在接口冻结后并行开发。
- Experimenter：使用同一个冻结runner进行数据准备、训练和评价，保留恢复状态。
- Reviewer：冻结接口后一次数学/泄漏挑战，正式结论前一次结果复核；不让每个函数单独走科学审判。
- Coordinator：单点整合、登记作业、接收完成事件并推动下一个已授权动作。角色按阶段启停，单GPU重任务是否并行由实际资源决定。

正常续行不依赖定时“继续思考”。等待真实作业时可用回调或轻量轮询，状态无变化不调用高成本Scientist。中断后先对账job_id和产物，不重做已完成训练；只在已知资源/权限阻塞时停止。
