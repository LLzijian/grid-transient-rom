# GFTD 路线首轮推进报告

本轮完成了可执行的 5N 数学核心修订和首个有界科学探针。最有价值的结果是：在三个开启调制的非平衡人工算例中，100 ms 合法观测包含数值可分的局部方向，但条件数约为百万。下一项算法工作应解决这些方向能否在观测误差下被可靠初始化，而不是直接开展图恢复排行榜。

用户“按照此方案开始研究和推进”恢复了本路线。原始 val/test 关闭、新 FOM=0、TASK4 暂停、default none 和受保护模型指针均保持原合同。此次没有真实事件数据读取或参数训练。

**方程与工程已经落地。** [冻结设计](../docs/gftd_repair_design_20261107.md)将状态明确为展开绝对角 theta、omega、独立机械功率 p、幅值 a 和力记忆 r。同一储能产生实际相角力、幅值反作用及机械功率端口；指数核与真实导数一致，浮点越界明确失败。关闭调制且 a=0 时，显式映射包含既有 RMemoryROM，保留其合法初始化。COI 用于报告，不再把半正定投影写成全系统动力学解耦。

执行前的[43 项冻结测试](../results/gftd_repair_20261107/qualification_receipt.json)通过，覆盖父模型 RHS、储能、初始化、双步长多步推进、梯度/功率及输入和存取。父映射覆盖环图、环加弦图各 8 个状态；原梯度测试覆盖环图，收尾时单独补齐两图梯度与功率，并保留逐项残差。补充检查属于执行后的覆盖补齐，不回写原资格和释放记录。非零调制初始化、部分观测拟合以及筛选系数到部署核的映射尚未实现，接口明确报未实现。

**局部观测探针完成了 8 个基准、48 组数值诊断。** [协议与源绑定](../results/gftd_observability_20261107/execution_release.json)在启动前冻结；[执行回执](../results/gftd_observability_20261107/execution_receipt.json)记录单次执行、源字节不变、耗时 76.36 s。历史末点真实 p 以线性硬约束消去，比较两种积分步长和三种差分步长。

| 人工三机条件 | 观测结果 | 可支持的判断 |
|---|---|---|
| 关闭调制，4 个状态 | a 的灵敏度列全部为零 | 幅值不可观的解析负校准成立 |
| 开启调制，同步平衡 | a 与调制参数列为零，秩为 3 | 平衡观测不提供这些方向的信息 |
| 开启调制，3 个非平衡状态 | 三个秩阈值、六种数值设置均为 7 秩；细步条件数 1.24e6—1.82e6 | 登记尺度下局部满秩，同时存在很弱的敏感方向 |
| 关闭调制，相角扰动 | 第四奇异值约 1e-11，秩随阈值从 3 变 4 | 该额外方向保留数值未决，不计为新增可辨方向 |

7 列分别是历史起点 a 的 3 维、r 的 3 维及调制参数 s，辅助未知为历史起点 p。共享参数 s 的单事件灵敏度不等于跨事件共享参数恢复。奇异值依赖冻结的参数与输出尺度，不是与单位无关的可辨识证书。

在三个非平衡调制算例所选最弱方向上，尺度化扰动幅度为 1e-3；细步历史响应 RMS 为 1.95e-11—1.14e-10，1 s 未来响应 RMS 为 8.14e-8—1.74e-7。未来与历史的比约 1,020—4,470，但绝对未来响应仍小，不能由放大倍数判断实际预测风险。这些数值是固定尺度下混合角度/速度差异，不是物理单位 RMSE。有限扰动的末点 p 漂移范数为 2.43e-12—2.33e-11，因此不能称严格同 p 的有限扰动事件；结论只覆盖所选方向。

[Scientist 判读](gftd_observability_20261107_scientific_assessment.md)与[独立 Reviewer 复核](gftd_observability_20261107_result_review.md)支持上述范围。复核检查了源码、源哈希、回执和保存的数值，未增加独立实验证据。模型配置按既有角色绑定；宿主未返回服务端解析的模型身份，相关字段记 null。

| 判断轴 | 本轮结论 |
|---|---|
| 证据有效性 | 固定人工方程、输入与源绑定明确，48 组诊断完整；保留有限差分和局部范围 |
| 优化健康 | 不适用，没有优化 |
| 优化充分性 | 不适用，没有恢复或拟合 |
| 机制可检验性 | 负校准通过；局部方向能否被有噪声的观测可靠区分仍待检验 |
| 效应与确认 | 局部敏感度与所选方向时间放大成立；没有真实 train 收益、结构恢复或 L2 证书 |

root 的三个决定为：代码 **retain_branch**，模型 **retain_evidence**，科学 **continue**。本次 Run 工作量关闭，未用余额不转移；Campaign 保持 active，不晋升模型。

下一 Run 应先冻结观测误差尺度、允许未来误差、有限适配机会与停止条件；固定已知共享参数，用相同合法历史和真实末点 p 比较 a=0 简单初始化与 a/r 推断。推断端须隔离隐藏状态和未来真值，报告观测拟合、未来误差及噪声敏感性。若历史拟合相近而未来明显分歧，优先收缩可推断状态或引入有依据的约束；若两种初始化等效，按预先规定的实际意义范围判断。此后再决定是否进入未知结构筛选与 IEEE39 train 条件内辨别。该下一 Run 尚未释放。
